## Приоритетные проблемы (полный список — admin_audit.md, БЛОК 21.2, D1–D15)

- **[P0] D1** Санкцию нельзя выдать по ID/@username: только через список участников чата, где разработчик состоит. Досье находит любого — но кнопки санкции нет; на «Ограничениях» нет «+ Выдать».
- **[P0] D2** Апелляции со статусом closed исчезают из UI (фильтров и API-валидации для closed нет).
- **[P1] D3** Поиск в досье — точное совпадение (SQL `=`), подстрочного/глобального поиска игрока нет нигде.
- **[P1] D4** Наплыв: «Ограничения» без поиска/пагинации/счётчиков, гигантские карточки; апелляции без счётчиков в фильтрах.
- **[P1] D5** Таб-бар обрезан без индикатора: «Штат» и «Консоль» невидимы; вложенность вкладок 2 уровня; путь до досье — 5 переходов.
- **[P1] D6** Нет «пульта дежурного» (инбокс модерации со счётчиками и свежими событиями).
- **[P2] D7** Штат: списка хелперов нет — только форма назначения по ID.
- **[P2] D8** Таблица участников на 390px: колонка действий (⚡) за экраном.
- **[P2] D9** «Снять санкцию» — золотая primary на карточке апелляции (опасный дефолт).
- **[P2] D10** Причина глобальной санкции необязательна (в экономике консоли — обязательна).
- **[P2] D11** Фото-доказательства: API принимает photo_ids, в веб-форме санкции загрузки нет.
- **[P2] D12** Три «Журнала» без кросс-ссылок; журнал выдач без фильтра/пагинации.
- **[P3] D13** Контент-вкладка — стена 86 контролов без аккордеонов.
- **[P3] D14** «до: 2026-08-01 00:00» — текст вместо datetime-local.
- **[P3] D15** Форма санкции: «Выдать» активна до выбора типа.

## Anti-patterns
LLM: не выглядит AI-генерённым; единый словарь (карточки/чипы/золото), айдентика в админке сохранена. Detector (index.html): 1 false positive (em-dash — русская типографика); admin-разметка живёт в JS-шаблонах, детектору недоступна. Браузер-оверлей не поднимался (headless-прогон скриншотами через puppeteer MCP + мок-сервер :8402).

## Персоны
- Разработчик-оператор: разбор наплыва = десятки переходов; санкция по известному ID недостижима с сайта.
- Дежурный хелпер (ранг 1–2, телефон): не видит очередь апелляций без захода вглубь; кнопка действий у участников за горизонтальным скроллом.
- Riley (стресс): closed-апелляции пропадают; 25+ санкций = 10 экранов скролла; поиск с опечаткой = 404 без подсказки.

## Сильные стороны
1. Айдентика «Золото в темноте» в админке выдержана (запрет «серого дашборда» соблюдён).
2. Микрокопия-подсказки в формах консоли — образцовые.
3. Процессная безопасность: confirm на опасном, SQL-мутации с журналом, тест рассылки себе, обязательные причины в экономике.
4. Паттерн досье (клик по валюте = ±, по предмету = выдать/забрать) — отличный, его и надо развивать до «Центра игрока».
