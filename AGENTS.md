# Общие правила для всех ИИ-агентов (любой вендор)

## IESA: действующее хранилище сайта

С 2026-11-01 production-медиа сайта работают на Cloudflare R2, а не DigitalOcean
Spaces. Перед изменениями хранения, загрузок, QR-карт, резервных копий или деплоя
прочитай `docs/agent/03-hosting-and-deploy.md` — это источник актуальной конфигурации.
Имена `SPACES_*` сохранены для совместимости и в компоненте `iesa-root` содержат
настройки R2: регион `auto`, публичный бакет `iesa-media`, закрытый `iesa-backups`,
публичный hostname `iesa-media.iesa-157.workers.dev`. Не возвращай старый endpoint
Spaces и не создавай платную подписку Spaces по старым примерам.
Не отправляй объектные ACL в R2 и не публикуй резервные копии через media Worker.
Старые скрипты обслуживания Spaces, перечисленные в документе хостинга, нельзя
запускать против production R2 без отдельной адаптации. При конфликте со старой
документацией следуй этому разделу и документу хостинга; секреты в git не добавляй.

До первой правки кода в Предвестнике прочитай `predvestnik_v2/AGENTS.md` (точка входа:
слои, маршрутизация по документам) и `predvestnik_v2/CLEAN_CODE.md` (обязательный
стандарт кода: анти-мусор, git-гигиена, Definition of Done). Для инструментов,
понимающих импорты, они подтянутся ниже; для остальных — это явное указание прочитать.

@predvestnik_v2/AGENTS.md
@predvestnik_v2/CLEAN_CODE.md
@predvestnik_v2/AUTONOMOUS_MODE.md
@predvestnik_v2/AUTONOMOUS_AGENT_POLICY.md
@predvestnik_v2/docs/PLAYER_COPY.md

## Домовой: домашний бот (domovoy/)

До правок `domovoy/` прочитай `domovoy/AGENTS.md` — слои, реестры настроек и прав,
запуск и проверки (`python -m pytest tests -q`, `python -m ruff check .` из каталога
`domovoy/`). Замысел продукта и статус — `domovoy/DESIGN.md`. Секреты — только в
`domovoy/.env` (в гит не попадает).

## Предвестник: патч-ноуты в официальный канал (обязательно)

Каждое обновление Предвестника, которое заметит игрок, выпускается вместе с пунктом в патч-ноуте дня:
`predvestnik_v2/FastAPI/static/patch-notes/<ГГГГ-ММ-ДД>.json` и скриншот в `patch-notes/img/` (или `"image": "cover"`).
Пишем для обычного игрока: польза, где найти, без технических слов; картинка — реальный экран без личных данных.
Отправляет создатель кнопкой в админке («Патч-ноуты»), сам бот ничего не публикует.
Полные правила и формат: `predvestnik_v2/docs/PATCH_NOTES.md`. Проверка: `python predvestnik_v2/tools/test_patch_notes_contract.py`.
