## 🟠 Средний приоритет

### B1. Санкции и апелляции 2.0 ✅ СДЕЛАНО (049b32b9; пороги кнопок — 42e31338).
Ограничение реализации: при ВЫДАЧЕ санкции прикрепляется 1 фото (команда ответом на фото); несколько фото — по одному сообщению в диалоге апелляции.
**РЕШЕНИЕ (согласовано, полный текст ответа пользователя):**
- Кнопки вердикта в досье/«Суде Присяжных»: «Бан» = `rank_ban`, «Кик» = `rank_kick` (вместе с A2).
- **При получении санкции игрок сразу понимает, что делать**: бот шлёт в ЛС инструкцию
  «как подать апелляцию», а в чат — уведомление «инструкция выслана в ЛС».
- **Апелляция в любой момент, любым способом**: через сайт ИЛИ через ЛС бота; можно
  прикреплять фото (одно или несколько) — удобно и там, и там.
- **Диалог, а не одноразовое обращение**: игрок пишет → модератор отвечает → игрок снова
  пишет → ... до бесконечности, пока модератор не выставит статус «Закрыто» — после этого
  диалог закрывается.
- **Всё фиксируется**: клик по игроку в списке забаненных → вся история дел с этим игроком
  (санкции, переписка апелляций, вложения, вердикты).
- **Фото при выдаче санкции**: модератор может прикрепить фото-доказательства к санкции.
- **Каналы уведомления о санкции — выбор модератора**: все чаты / выбранный чат / только
  текущий чат (текущий явно показывается, чтобы было понятно куда уйдёт) / ЛС; можно
  несколько вариантов или один.
- Причина санкции: лимит 9999 символов; поле ввода на сайте — большое и удобное.

### 🔴 P0 — блокирует работу

**D1. Санкцию нельзя выдать по ID/@username.** ✅
Единственный путь: Все чаты → чат → участники → ⚡. `GET /admin/global/chats` показывает
только чаты, где актор состоит (JOIN по user_chat_stats) — игрока из «чужого» чата с сайта
санкционировать невозможно. Досье (Консоль→Игроки) находит любого, но санкций-действий там
нет; на вкладке «Ограничения» нет «+ Выдать».
**Предложение:** (а) кнопка «➕ Выдать санкцию» на вкладке Ограничения с полем ID/@username
(реюз openGlobalSanctionForm); (б) в досье блок «Модерация»: активные санкции с кнопками
Снять/Срок, кнопки ⚠️/🔇/🚫 и «📁 История дел» (openUserCase уже существует).

**D2. Апелляции 'closed' исчезают из UI.** ✅
`/appeals/{id}/close` ставит status='closed', но фильтры фронта и валидация
`GET /admin/global/appeals` знают только pending/accepted/rejected → 400. Закрытые дела
видны только через «История» санкции.
**Предложение:** добавить 'closed' в валидацию бэка + вкладку «📪 Закрытые» (или объединить
в «Решённые» с бейджем статуса).
