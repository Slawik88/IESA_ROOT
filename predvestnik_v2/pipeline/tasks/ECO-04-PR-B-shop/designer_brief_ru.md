# Файл для дизайнера · Магазин, подарки, ключи по звёздам (ECO-04)

Стилизуешь по своим правилам Mini App (токены, темы, размеры касаний, состояния). Здесь только что должно быть на экране и какие данные приходят.
Решено владельцем: цены платных ключей (Серебро 120✨, Платина 300✨), шлифовка 60 Эссенции, ключ за алмазы 6★. Остальное — черновик (`shop_catalog.json`), могут поменяться после решения владельца. Цифры в макетах брать из данных, не зашивать.
Тон текстов: коротко, по-русски, без давления на покупку. Никаких «выгодно», «успей», «только сегодня».

## 1. Экран «Магазин»
Вход: кнопка в нижнем меню/из профиля (решай по своей навигации). Сверху — баланс всех живых валют: 🪙 Мора, 💎 Алмазы, ✨ Зарники, 🔮 Эссенция, 🗝 Ключи (число ключей по тирам).
Вкладки-разделы: **Ключи · Эссенция · Обменник · Подарки**. Внизу ссылки-плитки: Сезонный пропуск, VIP, Скины (ведут на готовые экраны).

Карточка товара (одна на все разделы):
- иконка/картинка, название, тир (если есть);
- что получаешь одной строкой («ключ: сундук от 4★»);
- цена: одна или несколько валют (например 300 🪙 + 200 🔮; 5 💎 + 3000 🪙). Если чего-то не хватает — недостающая валюта подсвечена, кнопка неактивна, под ней «Не хватает: 120 🪙»;
- способ: «Купить» / «Скрафтить» / «Обменять» (надпись на кнопке);
- лимит: «Осталось 2 из 3 на этой неделе» / «до сброса 4 ч» (для суточных);
- состояния: доступен, не хватает валюты, лимит исчерпан, загрузка, ошибка сети, успех (короткое подтверждение, баланс обновляется на месте).

Окно подтверждения перед списанием: что отдаёшь, что получаешь, баланс до и после. Для ✨ и 💎 — отдельная строка «Это необратимо».
Разделы:
1. **Ключи.** Пять позиций. Ключи имеют цвет по тиру: Бронза 3★, Серебро 4★, Платина 6★ (+ 1★ как базовый, 5★ и 7★ только для наград). Цвета свои. 
   Серебро есть в двух видах (крафт, за ✨) — одна плитка с переключателем способа. Лимиты в ключах: Бронза 3 в неделю, Серебро за ✨ 2 в сутки, Платина за ✨ 1 в сутки, крафт и алмазная Платина по 1 в неделю.
   Над списком честная подсказка про шансы: «Ключ 4★: примерно 89% выпадет 4★, остальное выше», «Ключ 6★: около 97% выпадет 6★». Цифры приходят из данных, не зашиты.
2. **Эссенция.** Одна позиция (шлифовка): 600 🪙 + 1 💎 → 60 🔮.
3. **Еда** в магазине не продаётся (остаётся наградой из сундуков).
4. **Обменник.** Две строки: ✨ → 🪙 (10 за 1✨) и ✨ → 💎 (0,01 за 1✨, то есть 1💎 за 100✨). Поле суммы, подсказка «Лимит 50✨ в сутки, осталось N», предупреждение «Обмен необратим». Экран уже есть в коде логикой, UI нужен.
5. **Подарки.** Четыре подраздела по тирам (§2).

## 2. Подарки: выбор и отправка
Тиры: 1 «Знак» (Мора), 2 «Тёплый» (Мора), 3 «Редкий» (Алмазы), 4 «Легендарный» (Зарники). Три подарка в каждом (список в `shop_catalog.json`).
Каждый тир выглядит заметно богаче предыдущего (рамка, свечение, анимация появления — по твоим правилам), тир читается и без подписи.
Первый релиз: подарки только партнёру по браку (как сейчас), тиры и полка новые. Позже — любому игроку: тогда добавятся отказ от подарков и жалоба на подпись.
Отправка: выбрать получателя (поиск по имени/@username, последние адресаты) → подарок → необязательная подпись до 60 символов → подтверждение с ценой.
Ограничения в тексте ошибок: «5 подарков в сутки», «Одному человеку не больше 3 в сутки», «Нельзя подарить себе».
Успех: короткая анимация, у получателя приходит уведомление в бота.

## 3. Полка подарков в профиле
**Свой профиль**, раздел «Подарки»: четыре полки по тирам, на каждой слоты; пустые слоты — силуэты. Над полками счётчики «получено / отправлено».
Нажатие на подарок → карточка: кто подарил, когда, подпись, тир. Можно **закрепить до 3 подарков** на витрине (звёздочка).
История: список полученных и отправленных, фильтр по тиру.
**Чужой профиль / публичная карточка**: показываются закреплённые (до 3) и общее число; полная полка не раскрывается. Подарок высшего тира даёт значок рядом с именем (по твоим правилам для значков).
Пусто: «Пока нет подарков» + кнопка «Подарить» только в чужом профиле.
(Сегодня экран подарков в профиле недостижим, нет якоря `#pro-marriage-card`; нужен новый блок в профиле.)

## 4. Питомцы: улучшение уровня
Кнопка «Улучшить» на карточке питомца (выйдет первой, до платных тиров ключей) показывает стоимость шага: 🃏 карты (нужное/есть), 🪙 Мора, и на уровнях 5/10/15 ещё 🔮 Эссенция. Полоска прогресса карт. Если не хватает чего-то одного, это видно сразу.
Макс. уровень сейчас 16. На ступенях 5/10/15 небольшая «веха» (иконка/рамка).

## 5. Данные (предполагаемые поля, точные имена зафиксируем при реализации)
- `GET /api/shop/catalog` → `{balances, items:[{id, section, mode, name, icon, tier, cost:{mora,dia,zar,ess}, gives, limit:{period, max, left, resets_in}, affordable, missing:{...}}]}`
- `POST /api/shop/buy {item_id, qty}` → `{ok, balances, receipt}` или `{error:{code, message}}` (`not_enough`, `limit`, `disabled`)
- `POST /api/gifts/send {to, gift_id, note}`; `GET /api/profile/gifts` (своя полка), публичная карточка отдаёт закреплённые.
- Иконки/картинки для 12 подарков и ключей — нужны ассеты, пока эмодзи-заглушки из каталога.

## 6. Не делать
- Не показывать «экономию», таймеры-давилки, красные бейджи «осталось N штук» (кроме реальных лимитов).
- Не выводить Тёмную Мору и Осколки Эха нигде: они выведены из игры.
- Не менять формулировки валют: Мора, Алмазы, Зарники, Эссенция, Карты, Джокеры, Ключи.
