# Генератор промо-видео Предвестника

Делает вертикальные ролики 1080×1920 для TikTok / Reels / Shorts из сценария в JSON.
Что и как писать в сценарии (аудитория, крючки, список фич, запреты) — **`BRIEF.md`**, читать первым.

```
promo_video/
  BRIEF.md          бриф: кто смотрит, боли и решения, как устроен ролик, все фичи бота, чего нельзя
  render.cjs        рендер: сценарий → out/<имя>.mp4
  engine/           страница, которая рисует кадр в момент t (HTML/CSS/JS)
  scenarios/*.json  готовые ролики
  assets/           настоящие материалы бота: texts.json, карточки card_*.jpg, экраны screens/*.jpg
  capture/          как эти материалы получены (пересобрать, если бот поменялся)
  out/              результат (в git не попадает)
```

## Запуск

Нужны Node 18+, ffmpeg и Playwright с Chromium (`npm i -g playwright && npx playwright install chromium`).

```bash
cd predvestnik_v2/tools/promo_video
node render.cjs                                    # все сценарии → out/*.mp4
node render.cjs scenarios/02-one-bot.json          # один ролик
node render.cjs scenarios/02-one-bot.json --stills 0,1.5,8   # только кадры PNG — быстро проверить вид
node render.cjs --workers 8 --crf 18               # больше потоков / чуть меньше файл
node render.cjs --audio-only                       # только пересобрать звук у готовых out/*.mp4
```

Живой предпросмотр в браузере: `npx http-server .` и открыть
`http://localhost:8080/engine/index.html?s=../scenarios/01-dead-chat.json` (клик — с начала).

Выход: H.264 High + AAC, 30 к/с, `+faststart` — грузится в TikTok как есть. В ролике только тихие мягкие
звуки интерфейса (пузырьки, уведомления, удар на крючке): пик не выше −10 dBFS, средняя громкость около −30 dB,
верха срезаны — это фон под музыку, которую ставят в TikTok при публикации.

## Настоящие материалы бота (`assets/`, `capture/`)

Ролик показывает бота таким, какой он есть: тексты, карточки и экраны берутся из кода и стенда, а не рисуются заново.

| Что | Откуда | Пересобрать |
|---|---|---|
| `assets/texts.json` — ответы бота (топ, топ чатов, досье чистки, мут, лимит варнов, подключение, профиль и стрик в скине, анонс SSS, мафия, брак, «бот сайт») | функции оформления из `bot/chat/*` на демо-данных | `BOT_TOKEN=0:promo DATABASE_URL=postgresql://none@127.0.0.1:1/none python3 tools/promo_video/capture/real_texts.py` (из `predvestnik_v2/`) |
| `assets/card_<скин>_<тир>.jpg` — карточка «бот я» с графиком в оформлении скина | `bot/chat/activity_graph` + `skin_card` | то же окружение, `capture/cards.py` |
| `assets/screens/*.jpg` — экраны мини-приложения в SSS-скинах, чистка, веб-админка владельца чата | стенд `tools/ui_stand.py` + подмена ответов чистки (`capture/mocks/`), админка на демо-данных | `capture/screens.sh` (нужен локальный PostgreSQL, см. `docs/UI_STAND_AND_SMOKE.md`; демо-игроки — `capture/seed_demo.sql`) |

Все имена, ники и чаты в материалах вымышленные. Если бот поменял текст или экран — пересобери материалы, сценарии
менять не нужно: они ссылаются на тексты по имени (`"real": "top_chats"`) и на снимки по файлу.

|---|---|---|

| `02-one-bot.json` | «Один бот вместо пяти 🤯» | Спидран 1/5…5/5 по всем направлениям + бонус для админа |
| `03-pov-admin.json` | «POV: ты админ флуда» | Спам и хаос → бан одной фразой → арсенал → чат играет сам |

настоящие тексты и экраны бота.

## Сценарий

```json
{
  "fps": 30,
  "palette": ["#7b3fe4", "#ff5fa8", "#3a4cff"],
  "people": { "Лиза": { "emoji": "🦊", "color": "#ff9fcf", "tag": "VIP" } },
  "scenes": [ { "type": "hook", "dur": 2.2, ... }, ... ]
}
```

- `dur` — длительность сцены в секундах; все `at` внутри сцены считаются от её начала.
- `start` в сцене не задавать — его ставит движок.
- В подписях `*слово*` — выделение плашкой, `\n` — перенос.
- `palette` — цвета фоновых пятен; `people` — аватар-эмодзи и цвет имени (иначе подберутся сами).

### Типы сцен

**`hook`** — крючок крупным текстом.
`lines: [{text, at, accent?, size?}]` (строка ужимается до ширины кадра), `emoji`, `emojiAt`,
`sub: {text, at}`, `ghost: false` — без размытых пузырей на фоне.
Строка с `at: 0` видна уже на кадре 0.

**`chat`** — группа в Telegram.
- `title`, `members`, `chatEmoji`, `caption` (строка или `[{at, text}]`).
- `messages: [...]`, у каждого `at` (отрицательный — сообщение уже было на экране) и `from`:
  имя игрока, `"bot"` (Предвестник) или `"service"` (серая плашка по центру).
  - `real: "имя"` — настоящий текст и кнопки бота из `assets/texts.json` (в сценарии нужно `"texts": "../assets/texts.json"`);
    иначе `text` — простой текст (`@ник` подсветится) или `html` — разметка как у бота: `<b> <i> <code> <blockquote>`, `\n`.
  - `img: "../assets/card_starheart_SSS.jpg"` — картинка в сообщении (карточка «бот я»).
  - `edit: {at, real | html, buttons}` — бот правит своё сообщение (как после нажатия кнопки); `buttons: []` убирает кнопки.
  - `me: true` — своё сообщение справа; `typed: 0.8` — перед отправкой набирается в поле ввода.
  - `reply: {from, text}` — ответ на сообщение (так в чате вызывают варпы).
  - `buttons: [["💍 Да", "Нет"]]`, `press: {at, row, col}` — палец нажимает кнопку.
  - `react: {at, items: [["🔥", 12]]}` — реакции под сообщением, счётчик бежит.
  - `card: {tier: "S"|"SS"|"SSS", title, subtitle, total, today}` — карточка активности с графиком.
- `bursts: [{at, emoji: ["❤️","💍"], count, from}]` — салют эмодзи от сообщения №`from` (или `[x, y]`).
- `camera: [{at, scale, x, y, dur}]` — наезд камеры.
- `grayUntil: 2.3` — до этого момента чат серый и тусклый, потом вспыхивает цветом.
- Сцена с тем же `title`, что и прошлая, продолжает её переписку (последние 6 сообщений уже на экране);
  `"carry": false` — начать с чистого чата.

**`chapter`** — переход к новой теме: `num` или `emoji`, `title`, `sub`. Ставь перед каждой новой темой (1.4–1.6 с),
чтобы зритель понимал, что сейчас покажут.

**`compare`** — «как сейчас / с ботом»: `before: {title, items}`, `after: {title, items}`, `interval`, `caption`.

**`members`** — боль ручной работы: список участников листается, счётчик «проверено N из …» и бегущий таймер. `total`, `speed`, `caption`.

**`screens`** — настоящие экраны в телефоне: `shots: [{src, dur, scroll: [y0, y1], scrollAt, scrollDur, fade, ring: {at, x, y, w, h}, tap: {at, x, y}}]`.
Координаты — в пикселях снимка (ширина 1080). `ring` — подсветка области (остальное притемняется), `tap` — палец нажимает.

**`grid`** — плитки фич: `items: [{emoji, title, sub}]` (до 8), `cols`, `interval`, `delay`, `caption`.

**`stat`** — большая цифра: `value`, `suffix`, `label`, `countLen`, `chips: [...]` (до 12), `caption`.

**`app`** — мини-приложение в телефоне, страницы листаются:
`pages: [{kind, title, sub}]`, `kind`: `rhythm` · `pass` · `pets` · `skins` · `family`.

**`image`** — свой скриншот в телефоне: `src` (путь от файла сценария), `pan`, `caption`.

**`cta`** — финал: `handle`, `title`, `button`, `sub`, `caption`.

## Как сделать новый ролик

1. Прочитай `BRIEF.md`, выбери крючок и сюжет.
2. Скопируй похожий сценарий из `scenarios/`, поменяй тексты и тайминги.
3. `--stills` на ключевых моментах → посмотри PNG в `out/`.
4. Полный рендер, проверь чек-лист из `BRIEF.md`.
