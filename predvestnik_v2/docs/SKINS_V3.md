# Скины Shell V3: палитра, тир и эффекты

Скин состоит из трёх независимых частей. Разметку и JS при добавлении скина менять не нужно.

| Часть | Где | Что делает |
|---|---|---|
| **Каталог** | `core/global_skins_v1.py` (`SKINS`) | id, название, `css_class` (`skin-…`), `tier`, цена, VIP-условие |
| **Палитра** | `FastAPI/static/skins-v3.css` | один блок `body.skin-…` с токенами `--v3-*` |
| **Тир** | поле `tier` в каталоге | потолок эффектов; включает уровни из `fx-tiers-v3.css` |

Тир влияет только на вид. Цены, правила игр и награды от тира не зависят.

## Тиры и эффекты (накопительно)

Эффекты накапливаются: у скина тира A есть всё, что у D, C и B.
Класс `fx-N` на `body` значит «уровень N и выше».

| Тир | Класс | Что добавляется |
|---|---|---|
| D | `fx-1` | Статичная палитра, быстрый переход экранов |
| C | `fx-2` | Дрейф ауры за профилем (loop) |
| B | `fx-3` | Дыхание фона (loop), каскад секций при входе на экран, блик на кнопках при нажатии |
| A | `fx-4` | Зерно, блик на кольце уровня (loop), стеклянная кромка дока |
| S | `fx-5` | Плывущие частицы (loop), блеск на крупных заголовках (loop), щедрее эффект награды |
| SS | `fx-6` | Параллакс по наклону телефона или указателю, боковой переход экранов, световое пятно на доке |
| SSS | `fx-7` | Вращающиеся ленты света (loop), круги от касаний, ударная волна при награде |

## Как добавить скин

1. В `core/global_skins_v1.py` добавить запись в `SKINS` с `css_class: "skin-<имя>"` и `tier`.
2. В `skins-v3.css` добавить блок `body.skin-<имя> { … }` с токенами (список в шапке файла).
3. По желанию задать `--v3-fx-a` и `--v3-fx-b` (цвета частиц и лент), `--v3-dur`/`--v3-ease` (темп переходов), `--v3-loop` (множитель длительности loop-анимаций: 1.4 медленнее, 0.8 быстрее).
4. Для уникальных деталей SSS-скина писать правила вида `body.skin-<имя>.tier-sss .v3-id::after { … }`.
   Доступны классы `tier-d … tier-sss` (номинальный тир) и `fx-1 … fx-7` (фактический уровень).
5. Проверить вид: в консоли разработчика `v3SkinPreview('skin-<имя>', 'SSS')` показывает палитру и эффекты без покупки.

## Защита от тормозов

Фактический уровень = `min(тир скина, возможности устройства)`:

- слабое устройство (`deviceMemory ≤ 2` или `hardwareConcurrency ≤ 3`) ограничено уровнем B (`fx-3`);
- `saveData` ограничивает уровнем C;
- «Спокойный режим» в настройках и `prefers-reduced-motion` сводят эффекты к `fx-1`, палитра остаётся;
- через 2,5 с после показа замеряется частота кадров; медиана кадра больше 30 мс снижает потолок на две ступени (сохраняется в `localStorage`, ключ `v3_fx_cap`);
- когда вкладка скрыта, все анимации приостанавливаются (`.v3-paused`).

## Правила для эффектов

- Анимируются только `transform` и `opacity`.
- Новый слой фона создаётся в `app.18.js` (`_v3BuildFx`) и живёт в `.v3-fx`; контент поверх не перерисовывается.
- Классы тира не должны начинаться с `skin-`: `global-skins-v1.js` удаляет все такие классы при смене скина.

## Косметика, видимость и публичный профиль

Правила (решение владельца, 2026-10), код: `core/appearance_v3.py`.

- Косметика и скины тиров D, C, B, A, S и SS доступны **без VIP**. Владелец всегда видит свой образ.
- **Другие игроки видят образ, стиль ника и скин, только пока у владельца есть VIP.** Без VIP публичная
  карточка показывает, *что надето* (название и тир), но не рисует это, а скин показывается в базовой палитре.
- Тир косметики берётся из редкости её коллекции: forest D, threshold и frost C, inferno и hanami B,
  celestial A, void S, artifact, moon_lotus и ryujin_tide SS. Таблицу по каждому предмету вести не нужно.
  Тир SSS пока только у скинов приложения.

| Слой | Где |
|---|---|
| Политика (тиры, кто что видит) | `core/appearance_v3.py` |
| Публичная проекция образа и стили ников в списках | `services/appearance_public_v3.py` |
| Публичная карточка игрока (allow-list полей) | `services/public_profile_v3.py`, `GET /public-profile-v3/{ref}` |
| Визуал предметов: цвета коллекции + богатство по тиру | `FastAPI/static/appearance-v3.css`, `app.20.js` |
| Экран карточки | `app.21.js` (`openPublicProfile` ведёт на неё) |

Визуал слоя внешнего вида задан не по предметам, а по паре «коллекция × тир»: `ap-l-<коллекция>` задаёт цвета,
`ap-t1…ap-t6` (D…SS) задаёт богатство слота (ник, титул, рамка, ореол, фон, частицы). Новая коллекция это одна
строка с цветами в `appearance-v3.css`; предметы из каталога подхватывают её сами. Циклы включаются при `fx-2` и выше.

Строка рейтинга, любой чужой ник и ссылки `startapp` открывают карточку. Старый `/profile/public/{ref}`
тоже скрывает образ владельцев без VIP.
