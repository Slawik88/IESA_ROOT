# Тексты для игрока — как переводить на понятный язык

> **Обязательно для любой ИИ-модели и любого человека, который пишет или правит текст, видимый игроку:**
> подсказки, «Как играть», справка, Путеводитель, описания даров и наград, тексты кнопок и пустых экранов,
> ответы бота в чате, патч-ноуты. Читай до первой правки текста, а не после.
>
> Правило владельца (25.10.2026): *«Игроки не понимали описания, и я два часа сидел — сам всё объяснял. Читатель не знает
> терминов, не знает, где какая вкладка, не знает наших валют. После подсказки у него не должно остаться ни одного вопроса.
> И помни: монотонный текст никто не читает.»*
>
> Патч-ноуты для канала — отдельный, более короткий формат: [`PATCH_NOTES.md`](PATCH_NOTES.md). Этот документ — про всё остальное.

## 1. Для кого пишем

Для человека, который **сегодня впервые открыл бота**. Он не знает:

- слов «Пропуск», «Следы», «Тропа», «тир», «окно», «серия», «дар», «ключ 3★+», «Эссенция»;
- где какая вкладка, что такое «Ещё» и что прячется за значком рюкзака;
- чем Мора отличается от Зарников и зачем нужны Алмазы;
- что значит «рейтинг», «сезон», «обычный режим».

Если без этих знаний текст не читается — текст написан не для него.

## 2. Правило «ноль вопросов»

Перед тем как отдать текст, задай ему семь вопросов. На каждый ответ должен быть **в самом тексте или в одном нажатии от него**:

| # | Вопрос новичка | Чем отвечаем |
|---|---|---|
| 1 | Что это? | Одна строка «что это» в начале |
| 2 | Зачем оно мне? | «Что даёт» — конкретно: «открывает сундуки», а не «развивает прогресс» |
| 3 | Что мне нажать? | Шаги: глагол в начале, одно действие в шаге |
| 4 | Где это находится? | Путь словами экрана + кнопка «Открыть» |
| 5 | Что я получу и что потеряю? | Награда и цена рядом; необратимое — прямо словами |
| 6 | А если не вышло или не хватило? | Одна строка: что делать (подождать, заработать, написать) |
| 7 | Что дальше? | Ссылка на следующую тему или действие |

Незнакомое слово объясняется **там же, где встретилось** (в скобках или после тире), либо ведёт в «Словарь» Путеводителя.
Нельзя отсылать к другому месту словами «см. выше», «как обычно», «стандартным образом».

## 3. Форма: не простыня

Сплошной абзац — запрещён. Текст всегда собран из блоков, и каждый блок читается отдельно:

| Блок | Для чего | Размер |
|---|---|---|
| **Что это** | суть темы | 1–2 строки на телефоне |
| **Шаги** (нумерованные) | как сделать | 3–5 шагов; шаг = жирное действие + одна строка пояснения |
| **Что даёт** (значок + слово + строка) | награды, выгоды, цены | 2–5 пунктов |
| **Слова** (словарик темы) | термины, которые встретятся | термин — одна строка |
| **Где найти** | путь + кнопка «Открыть» | 1 строка |
| **Совет** | как не ошибиться, что делает опытный игрок | 1–2 строки |
| **Осторожно** | необратимое: траты, обмен, потеря прогресса | 1 строка |
| **Список** (`list`) | карта или перечень: вкладки, источники опыта | до 12 коротких строк |
| **Сравнение** (`pair`) | два режима рядом: «Обычный» и «Рейтинг» | по 2–5 пунктов |

Размеры, которые проверяет `tools/test_player_copy_contract.py`:

- абзац — не больше **180 знаков** (это две строки на телефоне); предложение — не больше 22 слов;
- у шага: заголовок до 60 знаков, пояснение до 200;
- у темы Путеводителя: «Что это», хотя бы один блок «Шаги» или «Что даёт», блок «Где найти» с кнопкой;
- заголовок темы — до 40 знаков, вводная строка (`lead`) — до 120.

Длинную тему делим на несколько тем или прячем детали в раскрывающийся блок **ниже** главного. Главное видно без прокрутки.

## 4. Язык

**Говорим «ты».** Дружелюбно и спокойно, без канцелярита и без восторгов («невероятно», «революционный»). Глагол в начале шага: «Нажми», «Открой», «Выбери».
На старых экранах приложения ещё встречается «вы»: когда правишь текст такого экрана, переводи на «ты» весь экран целиком, а не одну строку.

**Слова-замены** (левое — не писать игроку, правое — писать):

| Не пишем | Пишем | Почему |
|---|---|---|
| окно нажатия, окно | время на нажатие | «окно» — внутренний термин |
| чанк, блок тактов | 20 нажатий подряд (блок) | объясняем число |
| такт, сигнал | нажатие, руна | |
| серия (без пояснения) | серия — верные нажатия подряд | при первом употреблении |
| темп | скорость (темп) | |
| дроп, лут, выпадает с шансом | достаётся, можно получить | |
| кулдаун, таймер перезарядки | можно снова через … | |
| лимит | не больше N в день | число и срок |
| ресурс | валюта, предмет — называем какой | |
| буст, баф, дебаф, нерф, имба | усиление, цена, слабее, слишком сильный | |
| апгрейд, прокачка | улучшение, усиление | |
| ачивка | достижение | |
| профиль игры, аккаунт-бинд | называем экран | |
| сервер, база, кэш, API, флаг, эндпоинт, синхронизация | не пишем; «результат сохранится и отправится, когда появится связь» | |
| сезонный рейтинг, лестница | рейтинг: уровни со звёздами | |
| Лига | не пишем (режим называется «Рейтинг») | решение владельца |
| ранг/тир (без пояснения) | уровень образа (D…SSS) — от слабого к самому редкому | |

Названия игровых вещей пишем так же, как они выглядят на экране: **Мора, Алмазы, Эссенция, Зарники, Жетоны, Звёздная пыль, Ключи, Следы**. Вкладки — в кавычках-ёлочках: вкладка «Игры», кнопка «Забрать».

**Что нельзя оставлять без расшифровки:** сокращения (VIP — «платная подписка с удобствами»), значки (🗝 — «ключ»), обозначения (3★+ — «не меньше трёх звёзд»), единицы (мс — «тысячных долей секунды», лучше «секунды»).

## 5. Где что находится — всегда словами экрана

Путь пишем так: **вкладка внизу › раздел › кнопка**. Например: «Внизу вкладка «Игры» › Ритм › кнопка «Начать забег»».

- Рядом с путём — кнопка «Открыть …», которая ведёт туда прямо из подсказки (в Путеводителе это блок «Где найти»).
- Если вкладка спрятана в «Ещё» — так и пишем: «Внизу «Ещё» › Магазин».
- Не обещаем того, чего у игрока может не быть (закрытый флагом раздел): «Если в «Играх» есть строка «Казино»…».

## 6. Числа

- Число, которое может поменяться (цены, лимиты, награды), пишем **только если оно проверено по коду сегодня** и рядом сказано, что оно значит («300 опыта — один уровень Пропуска»).
- Не уверен — отправляй к экрану: «сколько именно — видно на кнопке».
- Число в Путеводителе должно быть в `has(...)` в `tools/test_player_copy_contract.py` рядом с константой из кода: изменится правило — тест покажет, какую тему поправить.
- Единицы и срок всегда рядом: «до 300 опыта **в день**», а не «лимит 300».
- Проценты объясняем делом: не «очки выше на 35%», а «очки выше на 35% (из 100 станет 135)», если это не очевидно по контексту.

## 7. Типовые шаблоны

**«Как получить X»** — самый частый вопрос.
```
Как получить Мору
Что это: основная монета игры — на неё улучшаешь питомцев и берёшь жетоны.
Откуда берётся: 1) задания … 2) игры … 3) Пропуск …
Куда потратить: …
Где посмотреть, сколько у тебя: сверху в шапке и в «Кошельке».
```

**«Как играть»** — четыре шага: что делаю → что происходит → чем заканчивается → что получаю. Правила-исключения — отдельным блоком «Слова».

**Описание награды/дара** — две строки: «＋ что получишь» и «− чем заплатишь». Обе — о том, что игрок увидит в игре, а не о внутренностях правил.

**Пустой экран** — одна строка «что здесь будет» + одно действие («Сыграй первый забег»).

**Ошибка** — что случилось, что с данными, что сделать. Без кодов и слов «ошибка сервера».

## 8. Где живут тексты и как их менять

| Что | Где | Как проверяется |
|---|---|---|
| **Путеводитель** (темы, словарь, быстрые ответы) | `FastAPI/static/guide-v3.json` — только данные, без кода | `tools/test_player_copy_contract.py` (жаргон, размеры, ссылки) |
| Подсказки-плитки (кнопка «Подсказки 💡») | `FastAPI/static/app.47.js` (`guideDefine`, поле `topic` ведёт в Путеводитель) | тот же тест |
| «Как играть» и «Как копить опыт» внутри игр | `FastAPI/static/league-help.js` (рейтинг, Пропуск), блоки «Как играть» в `rhythm-v2.html`, `minesweeper-v2.html`; стили блоков — `league-games.css` | `test_player_copy_contract.py` (числа и слова) |
| Названия и описания даров Ритма | `core/rhythm_gifts.py` (`bonus`, `cost`) | `test_player_copy_contract.py` (жаргон) |
| Команды и справка бота | `summary` и `example` у команд (`bot/chat/…`), «бот помощь» собирается сама | `test_chat_framework.py` |
| Патч-ноуты | `FastAPI/static/patch-notes/` | `PATCH_NOTES.md`, `test_patch_notes_contract.py` |

Тест читает все строки в списке файлов (`for name in (...)` в `test_player_copy_contract.py`) и ищет в них слова из таблицы замен. **Новый файл с текстами игрока — добавь его в этот список.**
Путь правки Путеводителя: поправь `guide-v3.json` → `python tools/test_player_copy_contract.py`. Список даров Ритма в теме «Дары» повторяет `core/rhythm_gifts.py` (поля `name`, `bonus`, `cost`, порядок тот же): поменял дар в коде — обнови строку в блоке `gifts` файла `guide-v3.json`, тест подскажет, если разошлось.

**Новая механика, видимая игроку = новая или обновлённая тема Путеводителя в том же коммите** (и строка в словаре, если появилось новое слово).
Старый текст не оставляем «рядом»: заменяем, иначе игрок прочитает два разных объяснения.

## 9. Чек-лист перед коммитом

1. Прочитай текст так, будто это первый вход в игру. Остался хоть один вопрос — допиши (раздел 2).
2. Нет сплошного абзаца длиннее двух строк; шаги пронумерованы; есть «Где найти» с кнопкой.
3. Нет слов из таблицы замен (раздел 4); каждое новое слово объяснено на месте или есть в «Словаре».
4. Числа проверены по коду (раздел 6); единицы и сроки на месте.
5. `python tools/test_player_copy_contract.py` — зелёный. Для поиска и навигации Путеводителя также запусти `node tools/test_guide_navigation.js`: реальные вопросы, возврат к месту чтения, обрыв связи и повреждённая сохранённая справка.
6. Игроку заметно изменение? Тогда ещё и патч-нот (`PATCH_NOTES.md`).
