# Мафия — реестр элементов для дизайнера

> Файл ведёт агент по **логике** Мафии; по нему работает агент по **дизайну**.
> Логику (правила, callback-данные, переходы фаз) дизайнер не трогает. Всё, что можно и нужно
> стилизовать, перечислено ниже: где лежит, кто видит, что менять можно, а что нет.
> Каждый новый элемент добавляется в раздел 6 «Журнал» в том же коммите, где он появился.

## 0. Как устроен интерфейс Мафии (важно понять до работы)

Мафия идёт **внутри Telegram-чата**, поэтому «дизайн» здесь двух видов:

| Где | Что это | Чем стилизуется |
|---|---|---|
| **Telegram** (группа и личка с ботом) | сообщения бота + inline-кнопки | **только текстом**: эмодзи, HTML-разметка, порядок строк, подписи кнопок, раскладка кнопок по рядам. Цветов, шрифтов и CSS в Telegram нет. |
| **Mini App** (модалка «Мафия — моя история») | обычная веб-страница | CSS в `FastAPI/static/app.css`, разметка в `FastAPI/static/app.04.js` |

**Ограничения Telegram, которые нельзя нарушать** (симулятор `tools/mafia_sim` ловит их автоматически):
текст сообщения ≤ 4096 символов; всплывающее окно (alert) ≤ 200 символов и **без HTML**; кнопок ≤ 100 на сообщение, ≤ 8 в ряду;
подпись кнопки читаема на телефоне ≤ 40 символов (тест `newbie_copy_lint`); допустимые теги: `<b> <i> <u> <s> <code> <pre> <a> <blockquote> <tg-spoiler>`;
имена игроков вставляются через `safe_html` (экранирование) — не убирать.

**Принципы для новичков — их менять нельзя, только улучшать подачу:**
1. В каждой карточке партии есть строка `👉 Что делать:` (на неё опираются тесты) — человек всегда знает следующий шаг.
2. Простые слова, без терминов («фракция», «тай-брейк» и т.п.). Тест `newbie_copy_lint` проверяет список запрещённых слов.
3. **Роли секретны** до конца партии: ни в групповых карточках, ни в сообщениях «рассвет/итог голосования» роли не появляются.
4. Игроки в большом чате (40 человек, играют 7) не должны тонуть: карточки короткие, игроков пингует блок `🔔`.

**Как посмотреть всё это вживую без Telegram:**
```bash
# (из predvestnik_v2/, нужна локальная dev-БД, см. docs в конце)
PYTHONPATH=. python tools/mafia_dev_sandbox.py --dsn postgresql://predvestnik_preprod@127.0.0.1:55432/predvestnik_preprod
```
Готовый снимок целой партии (7 игроков в чате на 40): `docs/mafia_sample_game.md` — там видны все тексты и кнопки так, как их увидят игроки.

## 2. Личные сообщения игроку (видит только он)

Файлы: `core/mafia_copy.py` (все тексты — **главное место для правки формулировок**), `bot/handlers/mafia_dm.py`, `mafia_card_views.py` (клавиатуры).

| Экран | Функция | Когда | Кнопки | Заметки для дизайна |
|---|---|---|---|---|
| **Карточка роли** | `role_card` | старт игры (один раз) | у ролей с ночным действием — список имён `#N Имя` | роль, 🎯 цель, 🧭 что делать, 👥 команда (только мафии), 🤫 предупреждение. Роль можно оформить, например, `<tg-spoiler>` — но она должна читаться |
| Ночное приглашение | `night_prompt` + `night_keyboard` | каждую ночь, роли с действием | `#N Имя`, выбранное — `✅ #N Имя` | под текстом после выбора появляется строка `✅ Выбрано: …` (`night_chosen`) |
| **Табло мафии** | `team_board` | ночью, если в команде ≥ 2 живых | нет | редактируется на месте, когда кто-то меняет выбор |
| Результат проверки (Детектив) | `check_result` | утром | нет | «МАФИЯ 🔫» / «не мафия ✅» |
| **Бюллетень** (голос в личке) | `vote_prompt` + `vote_dm_keyboard` | начало голосования | `#N Имя`, `🚫 Никого`, выбранное с `✅` | дублирует кнопки группы, чтобы они не терялись в потоке сообщений |
| «Ты выбыл» | `eliminated_dm` | когда игрока убрали (не в конце игры) | нет | |
| **Правила** (4 страницы) | `rules_page`, `RULES_TITLES`, `rules_keyboard` | «Как играть» / `бот мафия правила` | `🎯 Что за игра` `🎭 Роли` `🔁 Как идёт партия` `💡 Подсказки` (2×2, текущая с «•») | каждая страница < 1500 символов |

## 3. Mini App (веб, настоящий CSS)

Модалка «🕵️ Мафия — моя история» открывается кнопкой «Мои партии» в хабе активностей (`FastAPI/static/app.04.js`, `openMafiaStats`).
Новый блок **«Как играть в Мафию»** — `mafiaHowTo()`; стилей у него **пока нет** (только семантическая разметка):

```html
<details class="mafia-howto card">
  <summary class="mafia-howto-title">Как играть в Мафию</summary>
  <ol class="mafia-howto-steps">
    <li class="mafia-howto-step"><b>Заголовок шага</b><span>Пояснение</span></li> …
  </ol>
  <dl class="mafia-howto-roles">
    <div class="mafia-howto-role"><dt>🔫 Мафия</dt><dd>Ночью выбирает, кого убрать.</dd></div> …
  </dl>
</details>
```
Хуки для CSS: `.mafia-howto`, `.mafia-howto-title`, `.mafia-howto-steps`, `.mafia-howto-step` (внутри `b` и `span`), `.mafia-howto-roles`, `.mafia-howto-role`.
Нужно: нумерация шагов, сворачивание/раскрытие (`details[open]`), отступы под 320/390/430 px, единый стиль карточек с остальными (`.card`, `.pcard`). Существующие `.pcard`, `.empty-state` в этой модалке — без изменений.

## 5. Что менять нельзя (сломает игру или тесты)

- `callback_data` и его префиксы (`mf`, `mfs`, `mfc`, `mfr`, `mfa`, `mfh`) — классы в `bot/handlers/mafia_cb.py`.
- Слова-маркеры, на которые опираются тесты: `Что делать`, `Цель:`, `Кто кем был`, `набор игроков`, `НОЧЬ`, `ОБСУЖДЕНИЕ`, `ГОЛОСОВАНИЕ`, `ПАУЗЕ`. Если нужно переименовать — одновременно правится `tools/mafia_sim/*`.
- Экранирование имён (`safe_html`, `html.escape`).
- Команды: «бот мафия», «стоп», «правила» и т.д. разбираются в `core/mafia_command.py`.

После любой правки текстов/клавиатур запускать (из `predvestnik_v2/`):

## 7. Решения по правилам, которые принял логик-агент (владельцу — подтвердить)

1. **Тишина в большом чате:** зрители не ограничены никогда; живые игроки молчат только ночью; выбывшие — только днём (обсуждение и голосование). Раньше днём удалялись сообщения всех, кто не играет.
2. **Старт без «Я готов»:** доступность личной переписки проверяется Telegram'ом «вживую» при входе и при старте.
3. **Роли «Авто»** (по умолчанию): до 5 игроков — Мирные+Мафия; 6–7 — +Доктор+Детектив; от 8 — +Дон. В настройках можно задать вручную.
4. **Ничья ночью:** решает Дон, без Дона — кто выбрал раньше. Раньше при ничьей никто не погибал.
5. **«Никого» в дневном голосовании** считается как вариант: один голос против нескольких воздержавшихся никого не выгоняет.
6. **Мест по умолчанию 12** (было 8), чтобы компания не упиралась в «лобби заполнено».
7. Детектив видит Дона как «мафию» (как и раньше). Если нужно «Дон невидим для Детектива» — это правка одной строки в `services/mafia_phases.py::_close_night`.
8. Выбытие игрока **не раскрывает его роль** до конца партии (как и раньше).
