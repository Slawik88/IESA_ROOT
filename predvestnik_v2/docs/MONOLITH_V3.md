# Монолитный вид Mini App

Экран читается как одна сцена. Нет плашки вокруг каждого абзаца, цифры и строки: группы держатся на отступах, крупном шрифте, заголовках-«нитях» (`.v3-eyebrow`) и тонких линиях между строками (`--v3-faint`).
Это требование владельца: «у нас монолит», а карточки на каждый элемент выглядят как типичный шаблон. Критерии приёмки: `DESIGN_IMPLEMENTATION_GATES_2026-09-27.md`, раздел «Monolithic composition».

## Что можно, что нельзя

- **Можно:** строка списка (`.v3-row`, `.v3-line`, `.st-row`, `.sv-opt`) с линией сверху; крупное число прямо на холсте; текстовые вкладки с подчёркиванием (`.sv-tabs`, `.v3-tab`, `.lk-seg`, `.quest-tabs`); одна поверхность на экран, если она несёт смысл (выбранная строка выбора, превью «С VIP», образ на сцене).
- **Нельзя:** скруглённая рамка с заливкой вокруг абзаца, цифры, значка, группы кнопок; сетка карточек 2×2 или 3×1; плитка под значок; «плашка-герой» с градиентом вместо заголовка.
- Выбранное состояние одно и заметное: у строки выбора это подсветка и тонкий контур плюс заполненная отметка справа. Остальные строки без фона.
- Контролы остаются контролами: главное действие одной пилюлей (`.v3-pill`), второстепенное пилюлей-контуром (`.v3-pill--ghost`) или текстовой ссылкой (`Открыть ›`, `.v3-link`), поле ввода с контуром (`.v3-field`).

## Словарь классов игрока

| Нужно | Класс | Не использовать (старое) |
|---|---|---|
| Кнопка | `v3-pill`, `v3-pill--sm`, `v3-pill--full`, `v3-pill--ghost`, `v3-pill--danger` | `btn`, `btn-gold`, `btn-ghost`, `btn-red`, `btn-sm`, `btn-full` |
| Поле ввода, список, текстовая область | `v3-field` | `num-input` |
| Ошибка загрузки | `v3-err` | `err` |
| Приглушённый текст, подсказка | `v3-dim` | `cx-dim`, `set-hint` |
| Строка «название — значение/действие» | `v3-line` (или `v3-row` с иконкой) | `irow`, `ik`, `iv` |
| Пустое состояние | `v3-empty` (+ `<b>` для заголовка) | `empty-state`, `es-*` |
| Заголовок раздела | `v3-eyebrow` | `card-title` |
| Подвал окна (`OM(title, body, [{l, c, f}])`) | `c: 'primary' \| 'ghost' \| 'danger'` | `c: 'btn-gold' \| 'btn-ghost' \| 'btn-red'` |

Страж: `tools/test_shell_v3_contract.py` падает, если экран игрока (любая часть `app.NN.js`, кроме `app.07/08/09`, или `index.html` вне страниц админки) снова использует старый класс из левого столбца.
Малая зона нажатия при компактном виде делается псевдоэлементом `::after { inset: -Npx }` (чипы, `.mclose`, `.v3-marks`, `.v3-seal`, `.v3-pill--sm`); `tools/ui_smoke.py` считает её.

## Где что лежит

| Что | Файл |
|---|---|
| «Зарники и VIP»: строки пакетов и сроков, крупный баланс, список «что даёт», превью «С VIP» | `FastAPI/static/store-v3.css`, разметка `app.30.js` |
| Старые экраны (сундуки, питомцы, достижения, справка, строки «Образов», лист подтверждения): снимает коробки, раскладку не трогает | `FastAPI/static/monolith-v3.css` |
| «Подробнее о профиле», брак и кошелёк, перенос | `FastAPI/static/monolith-player-v3.css` |
| Базовые правила (токены, герой, рамки, аватары, остатки старых экранов игрока) | `FastAPI/static/app.css` |
| Старый вид консоли, глобальной модерации и админки чата (**не трогать**, переписывается отдельно) | `FastAPI/static/admin-legacy.css`: удалить целиком вместе с подключением (`index.html`, `_SHELL_V3_CSS` в `FastAPI/main.py`, `test_static_delivery_asgi.py`, `test_shell_v3_contract.py`), когда админка переедет на `v3-*` |
| Новый экран | строки `.v3-row` / `.v3-line`, секции `.v3-eyebrow`, без собственных карточек |

Админка (`app.07/08/09.js`, `#pg-admin`, `#pg-global`, `#pg-console`) в «монолит» не переводилась намеренно: подвал окна с `btn-*` в `c` рисуется по-старому целиком, остальное ей отдаёт `admin-legacy.css`.

## Как проверять

`tools/ui_smoke.py` (стенд как прод, `tools/ui_stand.py`, Chromium в мобильной эмуляции): каждый экран игрока × ширины 320/390/430 и каждый образ × тир (D, SSS) × ширины с переключением вкладок нижнего меню. Падает на JS-ошибке, HTTP-ошибке, раздвинутом окне, горизонтальной прокрутке, уехавшем нижнем меню, серой кнопке браузера; предупреждает о нажимаемом меньше 32 px и о «карточках на каждый элемент».
