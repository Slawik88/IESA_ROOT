# Чат-бот: заметки для дизайнера

Все сообщения бота в чате сейчас оформлены «на коленке»: работают, но без единой
стилистики. Задача — привести их к правилам Предвестника. Логику не менять,
меняются только тексты, эмодзи, порядок строк и подписи кнопок.

## Ограничения Telegram (важно)

- Разметка — HTML-подмножество Telegram: `<b> <i> <u> <s> <code> <pre> <a> <blockquote> <tg-spoiler>`. Никакого CSS и цветов.
- Читают в основном с телефона: строка ≲ 32–35 символов до переноса, кнопок в ряду не больше 3 (лучше 2), подпись кнопки ≲ 20 символов.
- Моноширинный `<code>` — единственный способ выровнять числа; в топе так выровнены счётчики.
- Ник `@​name` (с невидимым пробелом) выглядит как упоминание, но **не пингует** — так сделано в топе, «ранги», профилях. Убирать невидимый пробел нельзя.
- `<a href="tg://user?id=…">` — настоящий пинг; используется только там, где он нужен (пинг админов, досье).
- Данные кнопки ≤ 64 байт — длинные подписи не влияют, только `callback_data`.
