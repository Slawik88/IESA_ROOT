# «Тропа» питомцев: экраны игрока

Экраны питомцев v2 по `docs/PETS_V2_DESIGNER_SCREENS.md`. Сервер и правила описаны в `docs/PETS_V2_DESIGN.md`, поля ответов в `docs/PETS_V2_DESIGNER_SCREENS.md`. Здесь только то, как это устроено в интерфейсе.

## Что где лежит

| Файл | Что в нём |
|---|---|
| `FastAPI/static/app.40.js` | вход, загрузка `GET /pets-v2/me`, главный экран (Следы за день, занятия, питомцы), листы (окна), отправка, развилка экспедиции, награда, один путь для всех действий |
| `FastAPI/static/app.41.js` | подэкраны: карточка питомца, сборка, кормление, Лагерь с перековкой, Выслеживание, Испытание недели; каталоги имён (призвания, черты, талисманы) |
| `FastAPI/static/trail-v3.css` | стили, все классы `tr-*`; движение только `transform` и `opacity` |
| `FastAPI/static/app.01.js` | `_backHooks`: системная кнопка «Назад» Telegram сначала закрывает окно или подэкран Тропы |
| `tools/test_trail_v3_contract.py` | статическая проверка: подключение, откат на прежний экран, один `action_id` на действие, экранирование, тон, стили |

Части подключены в `_APP_JS_PARTS` (`FastAPI/main.py`) после `app.12.js` (прежний экран питомцев): порядок 12, 40, 41. Стили лежат в `_SHELL_V3_CSS`, ссылка есть в `index.html`, путь записан в `tools/test_static_delivery_asgi.py`.

## Вход и откат

Вкладка «Питомцы» вызывает `openPetsV1`. Обёртка в `app.40.js` открывает Тропу, только когда `_sysFlags.pets_v2 === true`; иначе работает прежний экран (`app.12.js`).
Если флаг выключили, пока приложение открыто, сервер отвечает 404 «Тропа пока закрыта»: клиент гасит `_sysFlags.pets_v2` и показывает прежний экран.
**Флаг по умолчанию выключен.** Включает владелец в консоли разработчика админки. Занятия, начатые на прежнем экране, при включённом флаге в интерфейсе не видны (данные не трогаются, выключенный флаг возвращает их).
Запись «Тропа: питомцы уходят в путь» в `FastAPI/static/updates.json` помечена `"flag": "pets_v2"`: лента «Что нового» показывает запись с таким полем, только когда модуль включён (`_wnShown` в `app.02.js`). Текст о Тропе появляется у игроков вместе с экранами, а не раньше; так же можно прятать записи о любых модулях за флагом.

## Экраны

Подэкраны лежат внутри `#pg-pets`, переключаются через `trailGo(view)`, «‹ Тропа» возвращает на то место главного экрана, где игрок был. Окна (`#tr-sheet`, основа `lk-sheet`) закрываются по «Закрыть», тапу вне окна, Esc и системной кнопке «Назад»; Tab держится внутри окна.

| Экран | Где | Что видно |
|---|---|---|
| Тропа (главный) | страница | «Следы за сегодня X из 625» с чертой «по полной ставке до N», три слота занятий с таймером, список питомцев (уровень, силы, состояние), входы в Лагерь, Выслеживание и Испытание недели |
| Отправка | окно | питомец, тип (поход, экспедиция, дозор), длительность, маршрут (у дозора нет), Спутник; цена в силах и «Остаток сил» до нажатия |
| Развилка | окно | три пути, знак и диапазон или точный шанс ровно как пришли от сервера; награда ×, потеря сил при провале |
| Награда | окно | итог (удача, часть награды, неудача), находки, шкала Следов, уровень до и после, «Эссенция за ступень», ключ |
| Карточка | подэкран | уровень и шкала до следующего, потолок ступени и «Дальше N ур.: ещё N дней Связи», силы, Выдержка, Привязанность вида (звёзды), «Любит», сборка (призвание, черты, талисманы) |
| Сборка | подэкран | призвание с 10 уровня, черты по слотам, талисманы (2); цена до сохранения, подтверждение, когда она больше нуля |
| Кормление | окно | еда с остатком, любимая отмечена, «+2 к Выдержке до конца суток», Следы за кормление раз в сутки |
| Лагерь | подэкран | три постройки по 5 уровней, цена (Мора, Эссенция, часы), таймер стройки, перековка талисманов |
| Выслеживание | подэкран | сетка 3×3, подсказки клеток, очки внимания, попытки сегодня |
| Испытание недели | подэкран | теги недели, у каждого питомца сколько тегов закрывает сборка (до отправки), награда по сложности |

Пустой случай: «Питомцев пока нет, их можно получить в сундуках.»

## Данные

Один запрос `GET /pets-v2/me` кормит все экраны. После любого действия клиент перечитывает его (`_trRefresh`) и перерисовывает экран.
- Цифры правил (цены сил, Следы, пути, цены замены, тексты призваний, слоты, постройки) берутся из `me.rules`, клиент их не хранит. Исключение: `_TR_CALL`, `_TR_TRAIT`, `_TR_TAL` в `app.41.js` хранят названия и значки призваний, черт и талисманов; тексты «плюс и минус» призваний сервер присылает в `rules.calling_texts`, черт в `rules.traits`.
- Таймеры считаются от `me.now`: поправка `_tr.skew` = время сервера минус время телефона. Секундомер тикает раз в секунду, правит только текст таймеров и стоит, пока приложение скрыто (`document.hidden`); когда время вышло, а сервер ещё не отметил занятие готовым, просит свежий ответ (не чаще раза в 4 секунды, не более шести раз).
- Баланс Моры и Эссенции для подсказок «На счёте / Останется» берётся из `_profileData` (его обновляет сокет `balance_changed`); неизвестный баланс не блокирует кнопку, решает сервер.

## Действия

Все записи идут через `_trPost(path, body, ...ключ)`: к телу добавляется `action_id` (`tr-<вид>-<uuid>`, далеко меньше 96 символов).
- Номер живёт, пока сервер не ответил: при обрыве связи повтор уходит с тем же номером и не списывает второй раз; любой ответ сервера, в том числе отказ правил, номер снимает.
- Одно действие за раз (`_tr.busy`): второе нажатие не отправляет второй запрос.
- Отказ правил (409) показывается дословно: в окне строкой над кнопкой (`.tr-err`), на странице тостом. Данные при этом тихо обновляются.
- Подтверждение (`v3Confirm`) стоит перед платным и необратимым: улучшение постройки, перековка, платная сборка, сдача Испытания; в нём «На счёте» и «Останется».

| Действие | Запрос |
|---|---|
| Отправить | `POST /pets-v2/start` |
| Забрать награду | `POST /pets-v2/claim` (`path` для экспедиции) |
| Сохранить сборку | `POST /pets-v2/build` |
| Покормить | `POST /pets-v2/feed` |
| Улучшить постройку | `POST /pets-v2/camp/upgrade` |
| Перековать талисман | `POST /pets-v2/talisman/reforge` |
| Начать Выслеживание / открыть клетку | `POST /pets-v2/track/start`, `/track/open` |
| Сдать Испытание | `POST /pets-v2/trial` |

## Тон

Из `docs/PETS_V2_DESIGNER_SCREENS.md`, проверяется тестом:
- Следы за день видны всегда; на потолке спокойная строка «На сегодня питомцы устали расти. Награды остаются.» без красного.
- Шанс экспедиции печатается как пришёл (знак слов, диапазон или точный процент), клиент ничего не округляет и не додумывает.
- Неудача не наказывает: «Часть награды сохранена», уровни, Связь и питомец остаются.
- На экранах питомцев нет баннеров, кнопок покупки и ссылок в магазин.
- Цвет несёт смысл вместе с текстом: плюс и минус черт с невидимым словом «плюс» и «минус» для чтения с экрана, состояние питомца словом, а не только цветом.

## Проверка

```
python tools/test_trail_v3_contract.py                     # статически, без базы и браузера
python tools/test_pets_v2_pg.py                            # сервер: нужна база; стенд оставляет флаги ВКЛ, перед тестом set_game_flags(DEFAULT_DSN, False)
python tools/ui_stand.py --flags on --trail default        # стенд: живой лагерь (empty, capped, none)
python tools/ui_smoke.py --only pets,trail-pet,trail-camp  # смоук: экраны trail-* × 320 / 390 / 430
```

Смоук экранов `trail-*` ничего не отправляет (кнопки действий пропускаются по подписи). Стенд и тесты с базой не запускать одновременно: оба пересоздают данные игрока.

## Известные границы

- Данных о том, сколько осталось до следующей звезды Привязанности, сервер не присылает: показываются текущие звёзды и их бонус.
- Чипы «факторов» в развилке (при `detail` выше `sign`) собираются на клиенте из полей питомца: любимый маршрут, «сыт любимым», Хранитель, доля сил. Это составляющие Выдержки по правилам сервера (`core/pets_v2.resilience`); черты в чипы не входят. Числа шанса клиент не считает.
- Цена сборки и улучшений в окне до нажатия повторяет правила сервера (`rules.swap`, `rules.reforge`, `camp.next_costs`) только для показа; списывает и решает сервер.
- Уведомления о возвращении питомцев, «Витрина» и рейтинг не рисовались (см. `docs/PETS_V2_DESIGNER_SCREENS.md`, раздел «Что пока не нужно рисовать»).
