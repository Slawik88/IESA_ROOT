## 2. Что мешает (по коду)

1. **Шесть равноправных вкладок** в чат-админке и до десяти в консоли —
   сгруппированы по внутренним модулям, а не по задачам админа.
2. **ЧС и «Ушли» — отдельные экраны**, хотя это срезы людей, а не другие сущности.
3. **Действия размазаны**: у человека 3–5 кнопок в строке, у части действий нет
   подтверждения и указания срока/причины.
4. **Дашборд — простыня карточек** и не отвечает на вопрос «что делать сейчас»:
   нет блока «требует внимания» и быстрых действий.
5. **Настройки** — плотный список тумблеров без пояснений; текущие пороги не
   видны рядом с модулями.
6. **Журнал** — строки-коды: чтобы понять запись, нужно знать жаргон.
7. **Нет поиска человека** с уровня «Обзор»: чтобы найти игрока, нужно угадать
   вкладку и прокрутить список.
8. **Термины расходятся**: мут/ограничение, варн/предупреждение, ЧС/блокировка.
9. **Сеть — список названий**: не видно, в каком чате что происходит.

## 3. Новая структура (что во что превращается)

| Было | Стало |
|---|---|
| 📊 Дашборд | **📊 Обзор**: статус фразой, 3 числа, «требует внимания», быстрые действия, последние события |
| 👥 Участники + 🚫 ЧС + «Ушли» | **👥 Люди**: поиск + фильтры (Все / Модераторы / В муте / Чёрный список / Ушли) + карточки с фото |
| ⚡ Модерация | **⚡ Модерация**: муты, предупреждения, жалобы + быстрая выдача |
| ⚙️ Настройки | **⚙️ Настройки**: «Что включено / Правила / Доступ / Опасная зона», у каждой строки пояснение и значение |
| 📋 Журнал | **📋 Журнал**: фильтры + фразы вместо кодов |
| 10 вкладок консоли | **📥 Сводка / 👥 Игроки / 💰 Экономика / 🎫 Контент / 🖥 Система** — по задачам, опасное отдельно |
| Вкладки сети | **💬 Чаты / 🚫 Санкции / 📨 Апелляции / 👮 Команда / 📋 Журнал** |

Плюс сквозные вещи на всех трёх поверхностях:
- **🔍 поиск человека** в шапке (ник, @username, ID) → сразу карточка;
- **шторка действий** «⋯» вместо частокола кнопок;
- **подтверждение опасного**: срок + причина, кнопка называет последствие.

---

## 4. Принципы

1. Один экран = один вопрос.
2. Не глубже двух уровней от вкладки.
3. Действие рядом с объектом, а не в шапке экрана.
4. Текст объясняет, а не называет («Предупреждение», а не «варн»).
5. Опасное — явно: отдельный цвет, срок и причина, подтверждение.

## 7. Что не трогаем

- Права и гейты (`gp/gpAny`, `admin_permissions`) — только переиспользуем.
- Идентификаторы контейнеров и функции `swAdmin/swGlobal/swDev` — на них
  ссылаются «Что нового», тесты навигации и входы из бота.
- Правый dev-оверлей (`app.devmode.js`) — отдельный трек.
- Бэкенд-контракты ответов: обогащение `avatar_url` уже сделано, поля
  добавляем только аддитивно.
