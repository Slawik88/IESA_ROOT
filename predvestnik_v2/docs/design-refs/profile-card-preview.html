«бот я» — концепт «Таблицы» · компактная версия

Правки по вашим замечаниям: убраны серые плашки-код у чисел — это у них в Telegram неустранимый отступ в начале строки, из-за которого читался «пробел» в цитатах. Значения теперь просто жирным, как во всех остальных сообщениях бота, и строка начинается с подписи.

И больше воздуха: каждый смысловой блок отделён пустой строкой — нижняя часть больше не выглядит стеной текста. Карточка по-прежнему укладывается в экран телефона вместе с графиком (≈20 строк).

Что изменилось в этой итерации

  • Пробел в начале цитат: его давали серые плашки-код (в Telegram у <code> свой паддинг, который нельзя убрать). Теперь строки начинаются с подписи без плашек, значения — жирным.
  • Больше воздуха: пустая строка между всеми блоками — нижняя часть (дни, брак, кошелёк) больше не «слипается» в одну стену.
  • Компактность: «Сообщения» — 5 значений в 2 строки; «Прогресс» — 4 значения в 2; «Кошелёк» — 4 в 2. Итог: ≈20 строк, влезает в экран вместе с графиком.
  • Сохранено: цитаты-группировки, эмодзи-якоря, жирные числа, порядок «кто → активность → прогресс → личное → кошелёк».
