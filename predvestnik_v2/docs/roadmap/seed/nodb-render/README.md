# Стенд образов без базы данных (заготовка для S16)

**С S16 (31.10.2026) рабочий инструмент — `tools/skin_compare.py`, инструкция в
[итоге S16](../../sessions/S16-stend-i-audit-obrazov.md#итог-заполняет-сессия).**
Эта ранняя заготовка сохранена для истории: она всегда ставит `fx-7` и объединяет
CSS сцен, поэтому не служит эталоном тиров и загрузки после S06. Новый стенд берёт
настоящий профиль, строку топа с общим аватаром, карточку Telegram и ленивую карту сцен.

Рендерит профильную сцену любого образа и тира (рамка, ореол, фон, сцена, ник, титул) из CSS и JS самого проекта в Chromium. База, бот и сервер не нужны. Проверено 2026-10-27: 42 образа, ошибок в консоли нет.

```bash
cd predvestnik_v2/docs/roadmap/seed/nodb-render
python3 -I dump_skins.py                 # каталог образов -> build/skins.js
node build.js                            # CSS и JS Mini App -> build/
node shot.js hanami,void D,B,S,SSS до    # out/до-hanami-D.png ...
```

- Каталог читается из `core/skins_v3_catalog.py`, разметка и стили — из `FastAPI/static/app.20,22,32–38,48,53.js` и CSS образов. Если в проекте появятся новые файлы сцен, добавь их в списки в `build.js`.
- Скриншоты 390 px, масштаб 1.5, режим `fx-7` (максимум эффектов). Для проверки слабых телефонов в S16 добавить режимы `ap-lite`/`ap-low`.
- Playwright берётся из `/opt/node-tools/node_modules/playwright`, Chromium из `/opt/pw-browsers` (переменная `PW_NODE` меняет путь к модулю).
- `build/` и `out/` в `.gitignore`: собираются заново.

## Что умеет и чего нет

Умеет: лестница тиров «до/после» между двумя ревизиями кода (запустить `build.js` и `shot.js` на двух ветках с разными метками, потом сравнить `PIL.ImageChops`). Не умеет: профиль целиком, топы,
Telegram-карточку (`bot/chat/skin_card_draw.py`, Pillow), движение (кадры); для этого основной инструмент — `tools/ui_skin_lab.py` с базой (см. `../../../UI_STAND_AND_SMOKE.md`).
