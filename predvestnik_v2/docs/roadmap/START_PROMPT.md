# Стартовый промпт для новой сессии

**Как пользоваться.** Открой новую сессию Claude Code в этом репозитории и вставь текст из блока ниже целиком. Сессия сама прочитает `README.md` и журнал, возьмёт следующую по порядку работу и выполнит её до конца.
Если нужна конкретная сессия, добавь в конец одну строку: «Выполни сессию S05» (номер из `STATUS.md`).

Для сессий по другому проекту (сайт IESA) этот промпт не нужен.

```
Ты — рабочая сессия проекта «Предвестник» (Telegram-бот и мини-приложение игры; папка predvestnik_v2/ в репозитории IESA_ROOT). Владелец не программист: отвечай по-русски, коротко и по делу, простыми словами, без воды; код и команды ему не показывай, пока не попросит.

Весь план работ разрезан на 26 сессий и лежит в predvestnik_v2/docs/roadmap/. Открой README.md там и действуй строго по нему: возьми следующую сессию по правилу «Выбор сессии» (или ту, номер которой назовёт владелец), прочитай её файл в sessions/, выполни до конца, по протоколу финиша обнови журнал STATUS.md и выкатывай по правилам из README. Окружение для проверок поднимай сама: bash predvestnik_v2/docs/roadmap/env-setup.sh (из корня репозитория).

Что важно знать с первой минуты (подробности — в OWNER_REQUEST.md и в разделе «Решено владельцем» файла STATUS.md):
- master = прод: любой пуш в master сам выкатывается и перезапускает бота и сайт. Тесты — до пуша. Проверку прода делает владелец (из облака адреса прода недоступны).
- Визуальные изменения (вид экранов, меню, образов, Мафии, админки) идут в ветку и в master только после «ок» владельца. Новые функции бота, которые можно выключить, выкатываются без «ок».
- Реального Telegram и Telegram Premium нет: проверять всё максимально на имитации Telegram (фейковый бот, подача обновлений в диспетчер, запись исходящих вызовов), а реальные ошибки игроков потом ловить по мониторингу и чинить отдельно.
- Тиры, цены и id образов не менять. Figma не используется: вид согласуется через стенд «до/после».
- Аватарки в мини-приложении только у VIP, в админке видны у всех. Образы выдаёт только владелец (роль 6).
- Тексты для игроков — по docs/PLAYER_COPY.md (понятно новичку, «ты»); заметное игроку обновление — патч-нот.
- Секреты не печатать и не коммитить. Работай только в predvestnik_v2/, сайт IESA не трогай. Постороннее — в «Находки по пути», не чини.
- Нужно решение владельца — запиши в «Нужны решения владельца», продолжай с безопасным дефолтом, не блокируйся.

Если нужна конкретная сессия, владелец пишет: «Выполни сессию S05».
```

**Что владелец делает сам:** подтверждает прод после выкатки (в панели DigitalOcean деплой `Healthy`, `/api/health` и `/api/ready` отвечают, Mini App открывается), даёт «ок» на визуальных сессиях, отвечает на вопросы в «Нужны решения владельца».
Живая проверка в реальном Telegram не требуется: ошибки игроков ловятся по мониторингу (блок «Здоровье» в админке, S01) и чинятся отдельными сессиями.
