# E5 · Чек-лист владельца: уведомления в личке (необязательный)

Нужен только если захочешь проверить сам. Реального Telegram у ассистента нет: всё остальное проверено на имитации. Шаги простые, ничего включать на сервере не нужно.

1. В личке с ботом напиши **уведомления**. Ожидаем: список из шести пунктов (Питомцы, Задания, Пропуск, Биржа, Сезон, VIP), у всех значок ▫️ (выключено), кнопки «Тихие часы: вкл» и «План дня».
2. Нажми **Питомцы** — значок станет ✅, сверху «Включил.». Нажми ещё раз — выключится.
3. Включи «Задания». Утром (после 09:00 по Москве) должно прийти сообщение «Новые задания дня» с кнопкой «К заданиям». Ночью бот молчит.
4. Напиши **план**. Ожидаем: сколько заданий дня сделано; если награда готова, появится кнопка «Забрать». Нажми её два раза подряд: первый раз «Забрано…», второй «Эту награду ты уже забрал».
5. Открой Mini App › Профиль › Настройки › Уведомления: те же шесть переключателей, все выключены, пока не включишь.
6. Отправь питомца на короткую вылазку при включённых «Питомцах»: когда он вернётся, придёт сообщение «Питомец вернулся».
7. (Если у бота включён режим тем) Сообщения придут в отдельные темы «Задания», «Питомцы». Если тем нет, всё идёт в общий чат, ошибок быть не должно.
8. Заблокируй бота и разблокируй: после блокировки уведомления перестанут приходить; напиши боту «привет» — снова будут.

Что-то не так — пришли скриншот и время: по нему найдём событие в «Состояние › Здоровье › Ошибки бота».
