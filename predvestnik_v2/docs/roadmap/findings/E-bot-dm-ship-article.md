# E · Чат-бот: личка, «шипперим», «моя статья» (исследование 2026-10-27)

Пути — от `predvestnik_v2/`. Номера строк на 27.10.2026: сверять с текущим кодом.

## 1. Группа и личка сейчас

- **Единый конвейер:** `bot/chat/__init__.py` (`on_message`) → `framework.dispatch`.
- **В группе:** команда начинается с «бот …». Если у команды `bare=True`, то и без слова «бот».
- **В личке** (`framework.parse(private=True)`): «бот» не нужен только для точного названия без значений («баланс», «топ»); команды с `private=False` отвечают «только в группе» и
  кнопкой «Добавить бота в чат»; неизвестный текст получает подсказку `DM_HINT` не чаще раза в 10 минут (`bot/chat/onboarding.py:506-528`).
- **Что в ЛС уже есть:** `/start` (`bot/chat/payments.py:228`) с глубокими ссылками `buyzarniki`, `m*` (Мафия), `miniapp_<раздел>`, `setup_<чат>`; `/help`, `/site`, `/setup`, `/paysupport`;
  мастер подключения чата; картинки приветствия; кнопка меню «Сайт», команды лички в `set_my_commands`; роли и ночные действия Мафии; покупка Зарников за Stars; меню питомцев;
  звёздопад и VIP за пыль.
- **Не учитывается в ЛС:** сообщения, достижения чата, чистка, мафия-ворота.
- **В коде нет:** обработчиков `business_*`, inline-режима, топиков в личных чатах.
- **aiogram 3.22.0** (`requirements.txt:60`) = **Bot API 9.2** (`aiogram/__meta__.py`). Проверено в облаке 2026-10-27 по самим пакетам с PyPI:
  - **Business есть уже в 3.22.0:** события `business_connection`, `business_message`, `edited_business_message`, `deleted_business_messages`; типы `BusinessConnection`, `BusinessBotRights`; методы `get_business_connection`, `read_business_message`, `delete_business_messages` и др.
  - **Темы в личных чатах** (`User.has_topics_enabled`) появляются в **aiogram 3.24.0 = Bot API 9.3**; 3.23.0 (API 9.2) их не имеет. Последняя версия на PyPI на сегодня 3.31.0 (Bot API 10.3).
  - Подъём версии = правка общего `requirements.txt` (сайт aiogram не использует, но деплой пересобирает оба компонента): отдельный коммит, полный прогон тестов бота. **Владелец решил поднимать (2026-10-27)**: выполняет отдельная сессия S23а.
  - Нужен ли Premium игроку для Business и какие права запрашиваются — **сверить с официальной документацией** (`core.telegram.org/bots/api` из облачной среды недоступен: HTTP 000; PyPI доступен).

## 2. Команды чат-бота (≈76 основных + 122 варпа)

- **Основное:** помощь, сайт, настройка, админка (скрытая). **Статистика:** топ.
- **Профиль и валюта:** я, кто, баланс, перевод, вип, промокод, купить зарники (донат), стрик, достижения, тег, теги, отменить удаление, восстановить аккаунт.
- **Семья:** брак, семья, древо, усыновить, семья роль / выйти / выгнать / положить / снять, развод. **Взаимодействия:** варпы, 18+.
- **Игры:** игры, ритм, квесты, мафия, мафия онлайн, слова, слово.
- **Питомцы:** питомцы, отправить / покормить питомца, лагерь, вылазка, выслеживание, испытание питомцев, бестиарий. **Звёздная пыль:** звездопад, пыль, вип за пыль.
- **Модерация, чистка, настройки:** см. `B-guide-player-and-admin.md`, раздел 2.
- «Варны» — предупреждения модерации (только группа). «Варпы» — 122 RP-команды вроде «обнять» (только группа, `private=False`).
- **Работает в ЛС:** помощь, сайт, настройка, топ, я, кто, баланс, перевод, вип, промокод, купить зарники, стрик, достижения, семья и древо, ритм, квесты, мафия, питомцы, звёздная пыль, 18+.
- **Только группа:** модерация, чистка, ранги, жалоба, санкции, теги, брак, усыновить, варпы, слова, игры, косметика, админ-чат.

## 4. Уведомления игроку сейчас

- WebSocket в мини-приложении (`FastAPI/notifications.py`): шину кормят PostgreSQL-триггеры (`balance_events.py`); явных вызовов `notify` для игровых событий почти нет.
- Копилка «Welcome Back»: `web_notifications`, `/notifications/pending`.
- Telegram-личка: роли и ночные ходы Мафии; рассылки из админки; напоминание тем, кто добавил бота в чат (раз в 10 минут, `services/scheduler.py`); перевод получателю; ответ автору жалобы;
  тревоги и итоги дня владельцу; VIP-напоминание (`scheduler.py:151`); статусы платежей.
- **Нет push:** возврат питомца, сброс заданий, награды Пропуска, ордера биржи, конец сезона, события (Эхо по умолчанию выключено).
- **Находки:**
  - В «Настройки › Уведомления» одна категория `vip_expiry` (`core/constants.py:555`), и `notifications.is_enabled` нигде не вызывается.
  - Условие VIP-напоминания требует `dm_confirmed_at`. Его ставит только `mark_private_contact`, который вызывают одни тесты: напоминание, вероятно, сейчас никому не уходит (проверять на проде).
  - Образец «согласие + backoff» уже есть в `vip_v2_preferences` (`reminder_enabled`, `missed_reminders<2`, `dm_disabled_at`): копировать для новых push.

## 6. «Шипперим» и «моя статья»

**Есть ли:** нет — ни шиппера, ни «пары дня», ни «моей статьи», ни УК РФ, ни «кто сегодня». Ближайшее — варпы (`bot/chat/warps.py`) и брак (`bot/chat/family.py`). ИИ-помощник отключён.

**Как устроены тексты в проекте:**
- Банк фраз: `bot/chat/warp_texts/{warm,playful,actions,conflict,adult}.py`, список в `warps_data.py`. 122 варпа, ≈1310 фраз (по 10–12 на варп), длина 15–82, в среднем 46 знаков, 1 дубль.
  Формат: `Warp(name, emoji, aliases, adult, responses=("{a} … {b} 🤗", …))`.
- Подстановка: `template.format(a=…, b=…)` (`warps.py:32`): в тексте нельзя `{` и `}`. Выбор: `random.choice` (`warps.py:69`), без защиты от повторов и без «стабильности на сутки»
  (для суточного результата образцы: `core/retention_v3.py` (hash); звездопад — раз в сутки на аккаунт).
- Тон: дружеский, шутливый, глагол в настоящем времени (чтобы не зависеть от пола, комментарий в `warp_texts/__init__.py`), эмодзи в конце. Выбрал сам себя — особая строка
  «пытается… сам(а) себя» (`warps.py:66`).
- Упоминания: `warps.link()` — `tg://user?id=` (настоящий пинг); `Target.label()` — ник с невидимым пробелом, без пинга (`targets.py`); `profile_link` — ссылка `t.me/ник`, без пинга (`style.py`).
  Для случайных пар разумнее второй или третий вариант.
- Антиспам: кулдауна на игрока нет; единственный тормоз — исходящий троттлинг 1,05 с на чат (`bot/middlewares/outbound_throttle.py`); без «бот» фраза длиннее 6 слов не считается
  командой (`warps.py:51`); в зачёт достижений идут первые 10 варпов в день (`achievements.py:112`).

**Куда добавить модуль:**
- `bot/chat/ship.py` и `bot/chat/article.py`, тексты в `bot/chat/ship_texts/` и `bot/chat/article_texts/` по образцу `warp_texts`.
- Регистрация: импорт в `bot/chat/__init__.py:5`; callback-кнопки — в цикл `for sub in (...)` на строке 80; алиасы — `aliases.py`; синонимы — `framework.SYNONYMS`; раздел справки — `help.SECTIONS`.
- Триггеры без «бот»: `bare=True`, `private=False`; двухсловное имя «моя статья» разбирается по самому длинному совпадению (`framework.parse`); «кто сегодня» не конфликтует с командой «кто».
- Выключатель: группа в `feature_switches.GROUPS` и `catalog()` (строки 42, 154); либо ключ в `core/chat_modules.py` и команда «бот шиппер вкл/выкл» по образцу «бот косметика»
  (`chat_module_audit.set_chat_module`, право `rights`).
- Источник «случайного участника»: `user_chat_stats` (`is_left=FALSE`, `is_bot`, `last_message_at`) и `daily_user_stats`. Боты отсеиваются через `services/chat_bots.py`. Мало писавших бот не знает
  (`NOT_FOUND`, `targets.py`).
- Попутно по правилам проекта: тема Путеводителя (PLAYER_COPY §8) и патч-нот; строка в каталоге `docs/CHAT_BOT_DESIGN_HANDOFF.md`; новый файл в список текстов
  `tools/test_player_copy_contract.py` (сейчас из бота сканируется только `word_chain`); тест на фразы (для варпов проверяется лишь `len(WARPS) >= 120`, `tools/test_chat_bot_pg.py:491`).

**Ограничения и переключатели:**
- Возраст: минимум 13 лет (`core/legal.py:30`); проверки возраста нет.
- 18+ только у варпов: личное согласие `users.allow_adult_warps` (по умолчанию выключено) и флаг чата `nsfw_warps_allowed` (по умолчанию включено; у флага чата в админке только чтение,
  `admin_people.py:537`, `update_chat_settings` нигде не вызывается).
- Выключатели: `all`, `section:`, `group:warps`, `cmd:<имя>` через «Функции» (роль 5+), глобально или по чату. Владелец чата сам их не двигает; у него своё — только «бот косметика» (`cosmetics.py`).
  Столбец `module_warps` в БД есть, но варпы им не гейтятся.
- Риски контента: подсказка «бот варпы 18+» печатает в общий чат нецензурные алиасы (`warps.py:102`); для «моей статьи» нужен отбор статей (исключить половые преступления, наркотики,
  терроризм и подобное, подавать как шутку про себя, не как обвинение другого); для шиппера нет «не выбирать меня» — нужен личный отказ, образец `allow_adult_warps`.

## 7. Риски

1. Тексты: устаревшие `_showWelcome` и дубли «Как играть» противоречат PLAYER_COPY.
2. Права: две шкалы ролей (`services/roles.py` старая 0–3 и `bot_rank` 0–6).
3. Мёртвый код и данные: `services/ai_assistant.py` не подключён; `ai_knowledge/*.md` описывает несуществующее (кланы, гача, «Суд присяжных»); `vip_expiry` и VIP-напоминание.
4. Новые фичи в чате: без кулдауна один игрок засыпает чат, а троттлинг 1,05 с на чат даст очередь; `.format` падает на фигурных скобках в фразах; пинг через `tg://user?id=`
   для случайных людей неуместен; владелец чата не может отключить новую функцию сам, если не добавить свой переключатель.
5. Бот в ЛС: push строить по образцу `vip_v2_preferences` (согласие + затухание); бизнес-режим и топики в ЛС потребуют новых хендлеров и проверки версии aiogram.
