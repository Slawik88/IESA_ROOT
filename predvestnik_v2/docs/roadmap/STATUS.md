# Журнал конвейера сессий

Правила — в [`README.md`](README.md). **Обновляет каждая сессия при финише** (при старте журнал не правится: статуса «в работе» в master нет). Статусы: `не начата` → `ждёт ок` → `готово`. Недоделанное оформляется
новой строкой `SNNб` (см. README, «Протокол финиша»).

**Колонка «Ок»:** `нет`; `да` (владелец смотрит снимки до выкатки в master); `включение` (код выкатывается выключенным, владелец включает сам по образцу); `да (экран)` / `да (интерфейс)` (серверная часть без «ок», интерфейсная — с «ок»).

**Порядок выполнения** (сессию берут по этому порядку, если все её зависимости `готово`; S16 раньше S15, так как S15 зависит от неё):
