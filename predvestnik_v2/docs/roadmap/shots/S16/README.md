# Стенд S16 — только для согласования

Открой `index.html`. Нажми на уровень образа: появятся крупное сравнение и предложение.
Сейчас «до» и «после» одинаковые: S16 не перерисовывает игровые образы.

42 образа, семь уровней, 2646 измеренных пар. Матрица и настройки браузера без движения
показаны снимками; ник, топ и Telegram-карточка доступны в крупном живом просмотре.
Все данные тестовые. Твои заметки хранятся только в этом браузере — отправь их в чат.

Пакет хранится только на ветке `codex/roadmap-s16-stand`; не переносить его в master.
Инструмент повторной сборки, аудит и журнал находятся в master. Базовая ревизия —
`aec31c33c0d1ab6a5a7551adcc4f3f931855d01a`, метаданные в `manifest.js`.

`before/` содержит точные копии нужных исходных CSS/шрифтов и собранный renderer,
а не новые игровые правки. Даже прежние завершающие пробелы в исходном `app.css`
сохранены: это снимок базовой линии, который нельзя «чистить» в задаче стенда.
RGB-сравнение выполнено до сжатия WebP; компактная публикация не меняет его результат.
