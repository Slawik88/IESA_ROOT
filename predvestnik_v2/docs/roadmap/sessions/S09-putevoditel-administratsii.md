# S09 · Путеводитель для администрации бота

**Блок B** · **Зависит от:** S07 (приёмы навигации и поиска Путеводителя) · **Нужен «ок» владельца:** да (новый раздел в админке) · Ветка `feat/roadmap-S09-admin-guide`.

> **Промпт:** Выполни сессию S09 из `predvestnik_v2/docs/roadmap/sessions/S09-putevoditel-administratsii.md`. Начни с протокола старта из `predvestnik_v2/docs/roadmap/README.md`.

## Цель

Владелец: «для игры путеводитель уже плюс-минус сделан, а для админов — нет». Нужна справка для администрации бота: что умеет админка и команды бота, кому какие права, как делать типовые задачи. Должна быть удобной с телефона и не показывать то, что роль не может.
Контекст: `findings/B-guide-player-and-admin.md`, раздел 2 (роли, функции, команды, что переиспользовать).

## Границы

**Делаем:**
1. **Данные.** `FastAPI/static/bot-admin/guide-admin.json` (или рядом с серверным роутером) в **том же формате**, что `guide-v3.json` (группы → темы → блоки, глоссарий, FAQ), плюс поле `min_rank` (и при необходимости `owner_only`) у тем/блоков. Источник фактов — код: `FastAPI/routers/bot_admin/auth.py` (`SECTIONS`),
   `bot_admin/people.py` (`ACTIONS`, `_guard_target`), `services/admin_access.py` (`CONFIGURABLE`, FLOOR=2, CEILING=5), `core/chat_rank_policy.py:48` (пороги команд), `bot/chat/global_ranks.py`.
2. **Темы** (язык администратора, без внутренних слов; по `docs/PLAYER_COPY.md` с поправкой «читатель — новый модератор»): роли и ранги (глобальные 0–6, в чате 0–9, владелец чата), быстрый старт («что делать в первый день»), найти игрока, предупреждение/мут/кик/бан и когда что,
   снять санкции, бан во всех чатах, жалобы (очередь, массовая обработка), чистка чата, рассылки, промокоды, выключатели функций, права и матрица, журнал и «на контроле», заметки, метки (регалии), VIP и баланс, команды бота для админов чата (список с примерами), типовые ситуации («рейд», «спам», «спор»),
   что нельзя (себя, выше по роли, создателя), как обратиться за помощью.
3. **Рендер** в `FastAPI/static/bot-admin/` (новый файл `admin-guide.js`, стили `admin.css`/отдельный): **заново на примитивах админки** (`$`, `esc`, `sheet`, `open(key)`, `ME.sections`/`ME.rank`), а не копией `app.57.js`, который завязан на `v3Head`, `switchPage`, классы `gv-`/`v3-`. Фильтр по рангу вошедшего: тема,
   которую роль использовать не может, не показывается (или помечается «нужен ранг N»). Кнопка «Открыть» ведёт в соответствующий раздел админки через `open(sectionKey)`.
4. **Входы:** пункт «Справка» в доке админки и в «Ещё» админки; «?» в шапке каждого раздела с контекстной ссылкой на тему; в окнах опасных действий — ссылка «Что это значит?»; команда бота «бот админ-помощь» (`bot/chat/help.py` секция), доступная по рангу; клавиша «?» на компьютере остаётся.
5. **Поиск и навигация** — приёмы из S07 (крошки, оглавление, опечатки), адаптированные под админку. Новые файлы внести в `_TYPES` в `FastAPI/routers/bot_admin/page.py`; отдача с ETag по образцу `guide_v3.py`.
6. **Тест соответствия кода и справки:** для каждой записи `SECTIONS`, `ACTIONS` (веб) и команды модерации чата (`core/chat_rank_policy.py`) в справке есть тема или явное исключение; пороги рангов и числа в тексте берутся/сверяются с кодом (как `test_player_copy_contract.py`).

**Не делаем:** редизайн самой админки (S10–S11), игрокский Путеводитель (S07–S08).

## Критерии готовности

- Все разделы и действия админки, а также команды модерации чата описаны (тест).
- Роль видит только свои темы (тест + снимки).
- До справки не больше 2 касаний из любого раздела админки.
- Справка читается на 320 px без горизонтальной прокрутки; цели ≥44 px.
