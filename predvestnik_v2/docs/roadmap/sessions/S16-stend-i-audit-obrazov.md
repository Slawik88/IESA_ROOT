### Как воспроизвести

Из корня сначала `bash predvestnik_v2/docs/roadmap/env-setup.sh`; Python — из `ENV.md`.
На Windows этой сессии Linux-скрипт остановился без python3.12; использованы Python 3.11.9,
локальный Chromium 1248 и отдельная PG17/ICU/UTC на 127.0.0.1:55416 для сверки с Mini App.
Сам стенд не требует базы, бота, входа или Telegram. Подробности — [ENV.md](../ENV.md#s16-сравнение-образов-без-базы).

1. Получить отдельный worktree базовой ревизии выше. Для будущего «после» сначала
   закоммитить правки образов: грязный runtime не подписывается именем коммита.
2. Из `predvestnik_v2/` запустить следующий пример с тремя путями вне репозитория:

```python
from pathlib import Path
import json, subprocess, sys
before = Path("/absolute/path/to/baseline-worktree")
after = Path.cwd().parent
out = Path("/absolute/path/to/s16-evidence")
ids = list(json.loads(Path("docs/roadmap/findings/D2-cosmetics-plan.json").read_text(encoding="utf-8")))
parts = []
for start in range(0, len(ids), 14):
    part = out / f"part-{start // 14 + 1}"
    subprocess.run([sys.executable, "tools/skin_compare.py", "--before-root", str(before),
                    "--after-root", str(after), "--out", str(part),
                    "--only", ",".join(ids[start:start + 14]), "--matrix"], check=True)
    parts.append(str(part))
subprocess.run([sys.executable, "tools/skin_compare_merge.py", "--parts", *parts,
                "--out", str(out / "gallery"), "--compact"], check=True)
```

3. Открыть `gallery/index.html` или раздавать эту папку локальным HTTP-сервером.
   Полная матрица содержит 2646 пар; `--compact` оставляет изображения профильной
   лестницы и reduced-motion, остальные виды открываются настоящим renderer в iframe.
   Исходные RGB-хеши и проценты **всех** проверок остаются в `manifest.js`; сжатие
   публикации не заменяет и не пересчитывает сравнение. Версия упаковщика записана отдельно.
4. Аудит собирается `tools/skin_compare_report.py --manifest <gallery/manifest.js>`.
   Проверки — `tools/test_skin_compare.py`, `tools/test_skin_compare_ui.py --gallery <gallery>`;
   `--dsn <loopback>` дополнительно сравнивает DOM сцены и топа с живым Mini App.
   Выходные каталоги должны быть пустыми; смешанные ревизии, неполная матрица и пакет >16 МиБ отклоняются.
