# S07 · Путеводитель игрока: входы и навигация

**Блок B** · **Зависит от:** — · **Нужен «ок» владельца:** да (видно игроку) · Ветка `feat/roadmap-S07-guide-nav`.

> **Промпт:** Выполни сессию S07 из `predvestnik_v2/docs/roadmap/sessions/S07-putevoditel-vhody-navigatsiya.md`. Начни с протокола старта из `predvestnik_v2/docs/roadmap/README.md`.

## Цель

Владелец: путеводитель есть, но игрок видит его не сразу. «Не пихать в лицо, но чтобы был в лёгком доступе и виден», а навигация внутри не должна быть «пыткой». Сейчас до него минимум три касания через «Ещё», а из бота входа нет. Контекст:
`findings/B-guide-player-and-admin.md` (разделы «Как игрок добирается», «Куда добавить вход», «Навигация внутри: проблемы»).

## Принципы (от владельца)

Без всплывающих окон поверх игры и без навязчивых баннеров. Заметно, но спокойно: постоянный маленький вход + контекстные подсказки там, где игрок вероятнее всего в тупике. Текст по `docs/PLAYER_COPY.md`.

## Границы

**Делаем (входы):**
1. **Профиль:** строка «Путеводитель» в списке разделов (`FastAPI/static/app.15.js:75-84`, рядом с «Моя семья»). Для новичка (мало действий/дней) — карточка «Дальше» (`renderV3Next`, `app.16.js:75`) с темой `first-day`; исчезает после прочтения.
2. **Первый вход:** переписать устаревшее `_showWelcome` (`app.02.js:132`: «кланы, экономика… будут добавляться», нет Путеводителя); кнопка «Первый день» → `openGuide('first-day')`; тон «ты» (сейчас в соседнем TOS-гейте «вы/ваш»: привести к единому).
3. **Кнопка 💡 на 9 экранах** через уже готовый `guideDefine` (`app.47.js`): «Игры» (`app.04.js:91`), Кошелёк (`app.02.js:314`), Зарники и VIP (`app.30.js:10`), Инвентарь (`app.39.js:8`), Топ (`app.19.js:6`), Биржа (`app.14.js:39`), Промокоды (`app.46.js:7`),
   «Моя семья» (`app.06.js:67`), Настройки (`app.26.js:38`). Для экранов без подходящей темы пока указывать ближайшую существующую (полные темы — S08).
4. **«Ещё»:** поднять группу «Помощь» выше или добавить верхнюю карточку-ссылку (не ломая S12: нижнее меню переделывает следующая сессия; здесь только содержимое «Ещё»).
5. **Пустые состояния и ошибки:** ссылка «Что это?» там, где пусто/недоступно из-за непонятного условия (например, закрыто флагом).
6. **Из бота:** web_app-кнопка с `miniapp_web_url("guide_first-day")` на `home_screen` (`bot/chat/onboarding.py:312`, `_site_btn` принимает URL); пункт в `help.main_text` для лички; команда «бот путеводитель» (синонимы `framework.py:187`, `help.SECTIONS`); пункт в меню команд (`bot/__main__.py`, `set_my_commands`).

**Делаем (внутри Путеводителя, `FastAPI/static/app.57.js`, `guide-v3.css`):**
7. **«Назад» из внешней темы** сразу возвращает на исходный экран, а не в хаб (`gvBack`, `app.57.js:179-184`; история пуста после `openGuide`).
8. **Хлебные крошки** «Путеводитель › Группа › Тема» со ссылками (сейчас текст «Тема N из 32 · Группа», `:150`).
9. **Оглавление и якоря в длинных темах** (gifts, pass, xp, keys, pet-growth): сворачиваемый список блоков; диплинк на блок `guide_<тема>_<блок>`.
10. **Поиск везде:** строка поиска видна и на странице темы; поиск не сбрасывается при «Все темы» (`gvHome`).
11. **Поиск умнее:** терпимость к опечаткам (расстояние по словам/нормализация ё/е, раскладка), «возможно, вы имели в виду», расширенные алиасы (бп, bp, xp, хп, вип, мора…); при пустой выдаче — три ближайшие темы. Запросы без результата — в телеметрию S01 (анонимно) для будущего пополнения.
12. **FAQ по категориям** и «Быстрые ответы» по смыслу, а не первые 6 (`slice(0,6)`, `:102`).
13. **«Открыть» без перезагрузки** там, где цель внутри SPA; для Ритма/Сапёра/Лиги (`location.href`, `:11-12`) — по крайней мере с экраном-загрузкой и возвратом в ту же тему.
14. **Поле поиска 16 px** (сейчас 15, `guide-v3.css:26`): iOS перестаёт зумить.
15. **Хаб:** 32 темы ≈3 экрана: свернуть группы по умолчанию кроме «Начни отсюда» и последней открытой; «Продолжить чтение» оставить.

**Не делаем:** новые темы и тексты (S08), админский справочник (S09), общую переделку нижнего меню (S12).
