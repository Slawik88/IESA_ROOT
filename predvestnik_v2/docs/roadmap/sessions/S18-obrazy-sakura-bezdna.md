## Цель

Два образа-примера, названных владельцем: **Сакура** («цветочки — просто многоугольники») и **Бездна** («очень странный образ: только цветовая палитра напоминает бездну, больше чёрная дыра, и то слабо»). Довести до уровня лучших (celestial, ruby, chrono, личные). Контекст: `findings/D-cosmetics.md`
(«Два конкретных случая», таблица образов), `findings/D2-cosmetics-audit.md` (концепты S16).

## Границы

**Сакура-набор** (набор «Сад Сакуры»: `sakura_bud` C, `hanami` B, `sakura_storm` S; плюс сакуроподобные `moon_lotus` SS, `rose_letter` A, `lotus_*` по концепту):
- **Ханами** (`hanami`): цветки дерева сейчас круги случайного цвета (`tools/scene_art_b.py:126-146`, `blossoms` → `circ`), «лепестки» сцены — точки (`FastAPI/static/app.36.js:42-49`, `dot rise`), частица `petal` — прямоугольник с `border-radius` (`appearance-stage-v3.css:72,75`), силуэты — полигоны. Нарисовать дерево с
  ветвями, настоящими цветками (5 лепестков с выемкой, тычинки), падающие лепестки разных размеров с вращением и боковым дрейфом, пруд/васи по концепту; показать на каждом тире, **что добавляется** (C земля/вода → B небо/свет → A предметы → S живое → SS редкие события → SSS всё).
- **Бутон** (`sakura_bud`), **Лепестковый Вихрь** (`sakura_storm`: сцена хорошая, частицы и деталь — «линза»), **Лунный Лотос**, **Письмо с Розой**: по концептам S16; согласованный язык форм со всем набором.
- Telegram-карточки набора (Pillow, кривые, суперсэмплинг из S17).

**«Бездна»** (`void`, редкость S; `core/skins_v3_catalog.py:89-92`, «Свет падает в воронку, и её край едва мерцает»):
- Сейчас: D–C — общий фон `.ap-bg-vortex` (размытый conic-градиент + чёрный круг, `appearance-stage-v3.css:34-36`), ореол eclipse, штриховая рамка; B — слой `i-spiral` (5 рукавов-полигонов `ribbon`, `FastAPI/static/app.37.js:12`, `tools/scene_art_c.py:23-39`); A — обломки; **настоящая чёрная дыра только с тира S** (`FastAPI/static/app.22.js:32`, `skin-signatures-v3.css:11-29`, дуги линзы).
  В Telegram-карточке: 8 дуг по 2 px и 8-конечные звёзды (`bot/chat/skin_card_draw.py:76-79`).
- Нужно: воронка должна **читаться с тира D** (тонкий горизонт событий и искривлённый свет линзы), затем с каждым тиром усложняться (аккреционный диск, джеты, обломки на орбитах, красное смещение по краю диска, звёзды, искажённые линзой, пульсация горизонта) — **не только палитра**. Аватар как центр воронки: рамка и ореол «втягиваются» в него.
  Передвижение детали вниз по тирам согласовывается с владельцем (см. S17, решение по `signature_tier`).
- Ник и титул «Бездны»: эффект искажения/поглощения (в рамках гейтов: цвет/эффект, не геометрия и не порядок), строка в топе: тонкий горизонт у аватара.

**Не делаем:** другие образы (S19–S20), смену тиров/цен/id.

## Критерии готовности

- Дерево Ханами и цветки читаются как цветы на тирах B–SSS; на каждом тире есть заметное отличие (самопроверка по ладдеру).
- «Бездна»: воронка видна с тира D, диск и линза появляются по тирам; без движения читается; не только палитра (снимки ладдера D…SSS приложены).
- Бюджеты движения, вес, скорость Telegram-карточки в пределах; `ap-lite`/`ap-low` не ломают вид.
- Владелец принял («ок»).
