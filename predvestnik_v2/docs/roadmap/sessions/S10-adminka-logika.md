Владелец: найти места админки с плохим UI/UX, нелогичные штуки, места с лишними кликами и места, где сложно что-то делать (раньше искали только по username, теперь есть аватарки; чистка была «в жопе», сейчас удобнее). Это сессия про **логику и удобство**; внешний вид и телефон — S11.

## Границы

**Делаем:**
1. **Поиск игрока** (`services/admin_people.py:97-100,256-262`, `FastAPI/routers/bot_admin/people.py`): по ID, @нику, имени, тегу, названию чата **и** по «не был N дней», «писал/не писал», связанным аккаунтам; страницы у всех фильтров (сейчас первые 30, текст 20); недавние и закреплённые игроки; результаты с аватаркой, рангом, статусом (бан/мут/варн), последней активностью.
2. **Быстрые действия в карточке игрока:** кнопки «Предупредить», «Мут», «Бан», «На контроль», «Написать» (в личку от бота, сейчас `message` только для чата) прямо в карточке; последние санкции и «история кошелька» там же; нижний ряд типовых действий вместо «Действия → строка → форма → Далее → подтверждение» (было 4–7 касаний).
3. **Подтверждения по риску:** мут/варн/снятие санкций сейчас без подтверждения (`bot-admin/admin.js:426 DANGEROUS`): лёгкое «подтвердить» с возможностью **отмены в течение нескольких секунд** вместо вводов ID; ввод ID оставить только для необратимого (глобальный бан, крупные суммы).
4. **Выдача и отзыв образа и просмотр инвентаря/надетого образа** в карточке игрока (сейчас нельзя: только метки, VIP-дни, промокод). Минимальный ранг — **по умолчанию только роль 6 «Создатель»**, любая выдача идёт в журнал действий; отдельное решение владельца о понижении ранга
   (`STATUS.md`). Использовать существующие сервисы владения образами, не новые правила выдачи.
5. **Бан во всех чатах** (`services/global_moderation.py:92-120`): если S03 вынесла в фоновое задание — показать прогресс «N из M» и итог; иначе сделать здесь с использованием интерфейса S05.
6. **«Чистка» без выхода из админки** (`admin.js:1106,2289`): встроить экран в SPA (использовать серверный интерфейс S05), не перезагружая страницу.
7. **Единые названия:** «Метки»/«Регалии» (`admin.js:824`), «Роль» (глобальная) и «Ранг» (в чате) с разными иконками, «Чистка», «Функции»/«switches»: один термин на механику в UI админки и справке S09; согласовать с игроком-стороной.
8. **Паритет бот ↔ Mini App:** «защита» и «иммунитет» (`bot/chat/moderation.py:436,462`) добавить в `ACTIONS` веба; глобальный бан командой бота — только если это согласуется с правами (иначе записать в «Находки»).
9. **Журнал:** действия чистки попадают в ленту (`FEED_KINDS`, `admin_people.py:371-382`); индекс по `created_at` (проверить, что сделан в S04); фильтры по игроку/чату из карточки в один тап; экспорт ограниченного периода.
10. **Бейдж жалоб** обновляется через уже существующий WS вместо раз в минуту (`admin-boot.js`).
11. **Массовые действия:** добавить «снять мут/варн», «закрыть жалобы по правилу» и пр. по списку из выборки; предел остаётся 50, ограничения и журнал сохраняются.

**Не делаем:** цвета, токены, тему образа админа, размеры касаний (S11); цены/экономику; новые права вне пункта 4.

## Критерии готовности

- Клики на типовых задачах «до/после»: минимум −40% в среднем (цель), каждая задача ≤3 касания от карточки игрока.
- Поиск находит по всем перечисленным полям; страницы работают; время ответа поиска на синтетике 100k игроков в пределах бюджета из S04.
- Выдача образа проходит через сервис владения, виден в журнале и доступна только заданному рангу (тест).
- Все опасные действия либо с отменой, либо с вводом ID; тесты прав зелёные.
