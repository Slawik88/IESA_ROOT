>

## Цель

Темы в личных чатах с ботом (`User.has_topics_enabled`, Bot API 9.3) появляются только с **aiogram 3.24.0**; в проекте стоит **3.22.0 (Bot API 9.2)** (`requirements.txt`). На 27.10.2026 новейшая на PyPI — **3.31.0 (Bot API 10.3)**. Поднять версию так, чтобы бот работал **ровно как раньше**, а S23 мог строить темы в личке.
Это самая рискованная сессия по зависимостям: девять минорных версий. Контекст: `findings/E-bot-dm-ship-article.md` (раздел 1, факты о библиотеке).

**Делаем:**

2. **Разбор изменений.** Прочитать список изменений каждой версии между 3.22.0 и целевой (GitHub-релизы/`CHANGES` пакета; `core.telegram.org` из облака недоступен, PyPI доступен). Выписать **ломающие изменения** и всё, что касается используемого проектом: `Bot`, `Dispatcher`, роутеры, `types.*`, `FSM`, `ChatMemberUpdated`, `Message` (`business_connection_id`, `message_thread_id`), клавиатуры, `ReplyParameters`/`reply_to_message_id`, `allowed_updates`, `Bot.session`/таймауты/прокси, `parse_mode`/`DefaultBotProperties`, `CallbackQuery`, `web_app` кнопки, платежи Stars (`LabeledPrice`, `successful_payment`), `delete_messages`, `get_chat_member`.

4. **Подъём и совместимость.** Изменить строку aiogram в корневом `requirements.txt` (и зависимые пины `pydantic`, `aiohttp`, `magic-filter` и др. по требованию пакета); **`requirements.txt` общий с сайтом IESA**: сайт aiogram не использует, но деплой пересобирает оба компонента → отдельный коммит, дифф только эти строки; перед пушем убедиться, что установка из `requirements.txt` на **Python 3.12** (как на проде, `runtime.txt`) проходит (`env-setup.sh` ставит подмножество; полную сверку зависимостей сделать `pip install --dry-run -r requirements.txt` для строк бота).
