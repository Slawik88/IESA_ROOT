## Цель

Владелец: «в Telegram появилась функция, что бота можно подключить к ЛС, и он будет работать в ЛС у игроков. Какие функции мы можем туда добавить: предложи большой список, не только варпы». Здесь — режим **Telegram Business**: бот работает внутри личных переписок игрока с **другими людьми**. Список идей (пункты 1–10) — `findings/E-bot-dm-ship-article.md`, раздел 5.

## Факты о библиотеке

К началу S24 в проекте aiogram версии из `requirements.txt` (после S23a — не ниже 3.24.0; Business есть уже с 3.22.0): события `business_connection`, `business_message`, `edited_business_message`, `deleted_business_messages` и методы `get_business_connection`, `read_business_message`, `delete_business_messages` и др. (проверено в облаке 27.10.2026). Нужен ли Telegram Premium игроку, какие права бота запрашиваются
(`BusinessBotRights`) и как включается («Настройки Telegram → Telegram для бизнеса → Чат-боты») — **проверить по официальной документации Bot API при старте** (из облачной среды `core.telegram.org` может быть недоступен: тогда по исходникам aiogram и релизным заметкам на PyPI) и записать результат в журнал **до разработки**.

## Границы

**Делаем:**
0. **Исследование возможностей (первый шаг, результат в журнал и владельцу):** что именно доступно боту в переписке игрока; что видит бот (только сообщения, на которые игрок разрешил ответ, или всё); какие права нужны; ограничения по Premium; лимиты; как игрок подключает и отключает; как это совместить с политикой данных.
   По итогам — **предложить владельцу финальный перечень функций** (из списка 1–10 и новых) с оценкой пользы/риска; реализовывать **только** согласованное. Если ответа нет — минимальный набор по дефолту (см. ниже).
1. **Подключение:** обработчик `business_connection` (создание/отключение связи, хранение id связи и прав; схема идемпотентная), экран «Бизнес-режим» в «Настройки» и команда бота; игрок **сам** включает/выключает бота **для каждой переписки** (тумблер), по умолчанию выключено.
2. **Приватность (жёстко):** бот **не хранит** содержимое чужих сообщений и не отвечает в переписке, где игрок не включил режим; обрабатываются только явные команды (префикс «бот …» или кнопка); логи без текста сообщений; удаление всех данных связи при отключении; пункт в политике (`core/legal.py`): согласовать формулировку с владельцем, текст сам не придумывать.
3. **Минимальный набор по дефолту:** (а) «перевод Моры другу» командой в чате с ним (через существующий сервис переводов, те же лимиты и подтверждение), (б) «визитка»: карточка образа в переписку (Telegram-карточка скина `bot/chat/skin_card_draw.py`), (в) утилиты: «выбери за меня», кубик, «напомни через N минут» (через планировщик),
   (г) игры один на один в переписке: слова/крестики-нолики (кнопки), (д) «совместимость» с собеседником (используется банк S21: **только если S21 уже `готово`**, иначе пункт откладывается в строку `S24b`; без пинга), (е) приглашение в Предвестник со ссылкой. Автоответ «я в игре, отвечу позже» (пункт 9) как перк VIP — только по решению владельца.
4. **Безопасность:** все действия, меняющие баланс/предметы, идемпотентны и требуют подтверждения игрока владельцем связи (не собеседником!): проверка, что команду отдал **владелец бизнес-аккаунта**, а не его собеседник (иначе чужой человек сможет тратить деньги игрока). Тесты на подмену отправителя.
5. **Выключатель** «Бизнес-режим» в «Функции» (`feature_switches`), по умолчанию выключен; метрики и алерты S01 по ошибкам.
6. **Путеводитель, справка, патч-нот**; публичные формулировки по `PLAYER_COPY.md`.

**Не делаем:** чтение/сохранение переписок, массовые рассылки от имени игрока, любые действия без явной команды владельца аккаунта, автоответы без согласия, изменение кошелька Telegram/подарков аккаунта (методы `get_business_account_gifts` и подобные не используем).

## Критерии готовности

- Исследование и итоговый перечень в журнале; реализовано согласованное.
- Тесты: только владелец аккаунта может вызывать денежные команды; чужие сообщения не сохраняются; отключение стирает данные; повторные обновления Telegram не дублируют действия.
- Функция выключена по умолчанию; чек-лист ручной проверки для владельца готов.
- Живая проверка в Telegram отмечена как **не выполнена** (требует аккаунта с Premium): в журнале честно.
