> Самодостаточное задание для агента (Claude Code / Codex). Запускается целиком, без доуточнений.
> Владелец (22.10.2026): «всё работает, но очень скучно. Игроку надо давать красивые анимации, красивые картинки…
> чтобы игроку было ОЧЕНЬ ПРИЯТНО смотреть: на сезонный пропуск, на игры и т. д.»

## 0. Роль и итог

Ты — ведущий дизайнер-разработчик игровых интерфейсов Предвестника (Telegram Mini App, `predvestnik_v2/`).
Цель — чтобы экраны Лиги (Сапёр и Ритм уровнями), нового Пропуска сезона и связанных мест выглядели и ощущались
как дорогая мобильная игра: живые, тактильные, с наградными моментами, которые хочется пережить ещё раз.
При этом **ни одно правило игры, ни один расчёт и ни одна проверка сервера не меняется** — это чистая
визуальная и анимационная работа поверх готовой логики.

Итог работы: выложено в `master` (пуш в `master` = прод, правила в `docs/agent/06-git-and-release.md`),
пройдены все проверки из раздела 7, скриншоты до/после на 320/390/430 приложены в отчёт, патч-ноут дня написан.

## 2. Нерушимые границы

- Не трогать: `core/`, `services/`, `infrastructure/`, ответы API, правила, очки, звёзды, античит.
- **Паритет Ритма:** класс `Engine` в `league-rhythm.js` (окно, сердца, дары, очки) — менять нельзя ни в одной
  формуле. Визуал выносится из него. `tools/test_league_v1_parity.py` обязан остаться зелёным.
- Тайминг Ритма честный: время реакции считается от момента, когда руна реально видна. Анимация появления руны
  не должна сдвигать `shownAt` и не может быть длиннее 120 мс до читаемости (иначе игрок теряет очки).
- Сапёр: каждый ход по-прежнему один запрос; анимации не блокируют ввод дольше ответа сервера.
- Только `transform` и `opacity` для движения (никаких `top/left/width/height/box-shadow` в анимации), без
  бесконечных анимаций вне одного маленького участка; всё выключается в `low`, `body.no-fx`, `prefers-reduced-motion`.
- Без новых внешних библиотек и CDN. Картинки — свои: SVG в коде или файлы в `FastAPI/static/league-art/`
  (каждый ≤ 120 КБ, WebP/SVG), подключённые через `_ASSETS`/версионирование роутера.
- Файлы ≤ 300 строк (JS-файл > 700 строк запрещён правилом проекта); нужен новый файл — `league-fx.js`,
  `league-art.css` и т. п., регистрируется в `_ASSETS` и `league-demo.html`.
- Доступность: `aria-live` для результатов, подписи у кнопок, фокус видим, зоны нажатия ≥ 44 px, контраст по гейтам.
- Стиль Предвестника: тёмный обсидиан/фиолет, руны, звёзды; акцент — цвет образа игрока `--v3-acc` (подтяни
  `skins-v3/me` как в `minesweeper-v2.js`), не плодить новый неон. Один акцент на экран.

## 3. Что сделать — по экранам (каждый пункт = видимый результат)

### 3.1 Общая оболочка Лиги
- Шапка-герой сезона: номер сезона, сколько дней осталось (счётчик), тонкий фон-созвездие (SVG, статичный,
  мерцание 1–2 звёзд только на `high`).
- Вкладки «Сапёр / Ритм / Пропуск» — сегмент-контрол с плавным «ползунком» под выбранной (transform).
- Смена вкладки и вход/выход из уровня — короткий переход (слайд 12–16 px + fade, ≤ 220 мс), направление по смыслу.
- Скелетоны вместо «Загружаем…»; числа — `tabular-nums`, набегание при изменении (`v3CountUp`-подобно).

### 3.2 Лестница уровней (обе игры)
- Вместо сетки кнопок — «тропа» уровней: узлы-медальоны, соединённые линией; пройденные — с золотыми звёздами,
  текущий — пульсирует один раз при открытии и подсвечен акцентом, закрытые — приглушены с замком.
- У каждого 10-го уровня — веха (крупнее, своя иконка); прокрутка сразу к текущему уровню.
- Мини-превью уровня по нажатию: размер поля/мин и глубина логики (Сапёр) или такты/окно/дары (Ритм) + лучшие звёзды.
- Топ сезона: подиум для 1–3 мест (медали), строка «Я» закреплена внизу, если игрок вне видимой части.

### 3.3 Сапёр Лиги
- Раскрытие клеток: волна от точки нажатия (задержка по расстоянию, 12–18 мс на шаг, переворот/scale+fade).
- Цифры с мягким «появлением», цвета чисел согласованы с палитрой; флаг — короткий «втык» с покачиванием.
- Ошибка (мина): мина «вспыхивает», остальные мины раскрываются цепочкой, лёгкая тряска поля (≤ 6 px, 250 мс), haptic heavy.
- Победа: поле «светлеет» волной, затем экран результата (3.6).
- Пока ждём ответ сервера — нажатая клетка в состоянии «вдавлена», без спиннеров.

### 3.4 Ритм Лиги
- Руна-цель: появление ≤ 120 мс (scale 0.92→1 + fade), отдельный круговой таймер окна (SVG-дуга
  `stroke-dashoffset` разрешена как в MOTION_V3, одна дуга) вместо плоской полосы.
- Отклик на нажатие: верно — всплеск-кольцо и «+очки» взлетает; точное (быстрое) нажатие — особый «идеально»;
  ошибка — короткая красная вспышка и сердце «трескается»; серия (комбо) — растущий счётчик ×N с подсветкой.
- Сердца — отрисованные иконки (SVG), потеря — анимация разлома, лечение — наполнение.
- Отсчёт 3-2-1 — крупные цифры с «ударом»; выбор дара — три карточки, выезжающие веером, редкость/риск по рамке,
  выбранная увеличивается и улетает в панель даров.
- Фон уровня меняется по темпу (лёгкий градиент), без лишнего движения в `low`.

### 3.5 Пропуск сезона (вкладка «Пропуск»)
- Горизонтальная лента наград по уровням (scroll-snap), две дорожки: бесплатная и VIP (VIP — с короной,
  «стеклом» и замком, если VIP нет). Текущий уровень по центру, прогресс-бар опыта над лентой.
- Иконки наград — свои SVG/картинки: монеты Моры, кристалл алмаза, Зарник-искра, ключи четырёх уровней
  (Обычный/Бронзовый/Серебряный/Платиновый — разный металл), не эмодзи.
- «Забрать»: каждая награда по очереди вылетает из ленты (v3Fly-подобно) к итоговому сундуку/чипу, числа
  набегают; ключи «повисают» и звенят; финал — сводка полученного в листе (без `alert()`!).
- Повышение уровня Пропуска на глазах (после партии) — вспышка уровня и тост «Уровень N Пропуска».
- Подсказка «как копить опыт» — свёрнута в `<details>` внизу (правило иерархии).

### 3.6 Экран результата уровня (обе игры)
- Звёзды появляются по одной (0,25 с шаг), каждая с «ударом» и haptic light; третья — с золотой искрой.
- Опыт Пропуска «перетекает» в полосу Пропуска (+N), если он есть; новая веха/рекорд — отдельный бейдж.
- Кнопки: «Дальше: уровень N+1» — главная (одна залитая), «Ещё раз» — призрачная.

### 3.7 Хаб «Игры»
- Строка «Лига сезона» — карточка-герой: мини-созвездие, текущие уровни обеих игр и «к получению: N наград»,
  точка-индикатор, если есть что забрать в Пропуске.

## 4. Картинки

- Нужна единая маленькая библиотека символов в одном SVG-спрайте (`league-art.svg` или JS-модуль):
  медальон уровня, звезда (пустая/полная), сердце (целое/треснувшее), руны ᚠ ᚱ ᚦ в рамке, ключи 4 уровней,
  монета, кристалл, искра Зарника, корона VIP, сундук, мина, флаг.
- Если доступен генератор изображений — фоны сезона и герой-иллюстрация Лиги в стиле Предвестника
  (обсидиан/фиолет, без текста, без лиц реальных людей), WebP ≤ 120 КБ; иначе — векторные SVG.
- Каждая картинка проверяется в обеих темах и на `low` (картинка не должна быть единственным носителем смысла).

## 5. Производительность

- 60 fps на среднем телефоне: не больше ~40 одновременно анимируемых элементов, волна Сапёра на 12×16 поле —
  только видимые клетки, `will-change` только на время анимации.
- Первый экран Лиги ≤ 150 КБ новых ресурсов; картинки `loading="lazy"`, ленты — виртуализация не нужна (30 уровней).
- `low`/`no-fx`/`reduced-motion`: всё мгновенно, без частиц, смысл (звёзды, «+очки», полученное) виден текстом.
