# Предвестник и Ирис: сравнение актуальных функций

14 октября 2026. Предвестник: локальный checkout `049d81d2`. Соперник: именно Telegram `@iris_cm_bot`. Одноимённые Discord-боты, MAX-боты, криптопроекты и сторонние «клоны Ириса» исключены из доказательств.

## Основной вывод

Для администрации сильнее всего выглядит связка **панель основных действий + переключатель своих чатов + индивидуальная чистка по досье**. Для участника — **визуальный конструктор профиля + графические игры на реакцию/логику + общий прогресс**. Это причины предпочесть конкретный пользовательский сценарий, не универсальное превосходство над Ирисом.

«Топы среди всех» сами по себе не выделяют продукт: у соперника есть общие рейтинги. «Сайт полностью заменяет все команды» пока слишком широко: обнаружен разрыв срочного варна. «Полный контроль чистки» нужно понимать как решение по каждому кандидату и возможность закрыть сессию, а не изменение любых параметров и откат уже выполненных действий.

## Границы проверки

1. Использованы подключённые роутеры, фактически отдаваемые JS-файлы, параметры API и вызываемые сервисы. Список API-вызовов для 94 функций — [IRIS_SOURCE_TRACE](IRIS_SOURCE_TRACE_2026-10-14.json); полный исходный инвентарь — [INVENTORY](COMPETITOR_FUNCTION_INVENTORY_2026-10-14.json).
2. У Предвестника проверка исходников; у Ириса — публичная документация. Ирис не установлен в тестовый чат и не испытан под административной учётной записью. Не подтверждены закрытые интерфейсы и свежие возможности, которых нет в доступных материалах. Нельзя приравнивать «не найдено» к «не существует».
3. Production-версия и live-флаги Предвестника не прочитаны. Игры/сундуки условно доступны; косметический магазин проверяет `tab_cosmetics`. Каталожные количества ниже относятся к текущему исходнику, не к снимку открытого магазина пользователя.
4. Даты создания статей Ириса могут быть старыми, даже если страницы обновлялись. Документированное поведение не равно текущему испытанию. Рекомендации о преимуществах основаны на найденных различиях и отдельно помеченных предположениях.
5. Скорость, число касаний от первого открытия Telegram, конверсия, удержание и предпочтение игроков не измерялись. Код исполнения не доказывает успешный ответ Telegram.

## 1. Чистка: две кнопки для запуска и отдельное решение по человеку

**Цепочка Предвестника:** `app.07.js:294–372` → `/admin/{chat_id}/purge/*` в `admin.py:699–803` → `services/purge.py` → `purge_sessions` и Telegram. JS включён в выдаваемый bundle через `FastAPI/main.py:299`.

| Проверка | Текущее поведение Предвестника | Результат сравнения |
|---|---|---|
| Задать критерии | Даты и норма в форме; по умолчанию последние 7 дней / 50 сообщений | Соперник также поддерживает критерии (I-CLEAN). Отличие в форме и рабочем процессе, не в возможности считать сообщения |
| Начать | Из открытой панели кнопка → подтверждение | «Запуск в два нажатия» верно при этом условии. Число действий до открытия панели и изменение формы не включены |
| Собрать кандидатов | Проверка присутствия, периода, рангов и защиты; пользователи ниже нормы становятся целями сессии | Удобный сценарий отбора. Нельзя обещать охват всех участников Telegram: бот опирается на собственные данные |
| Рассмотреть человека | Веб-таблица: имя, сообщения, варны и решение. Дни в чате также есть в досье/API | Сессионная карточка/таблица — сильный кандидат на преимущество перед командным массовым удалением |
| Варн/кик/пропуск | Одно нажатие в открытой сессии | Администратор выбирает действие по человеку |
| Бан | Кнопка → отдельное подтверждение | Предохранитель от случайного нажатия присутствует |
| Контролировать ход | Число досье/решений и распределение результатов; продолжение той же сессии на сайте/в чате | База хранит одну сессию; это не два независимых сценария |
| Завершить раньше | Кнопка → подтверждение; цели без решения остаются без действия | Админ может закончить разбор, не применяя санкцию ко всем |
| Изменить период/норму после старта | Нет публичного update-session | Для новой нормы нужна новая сессия после завершения прежней |
| Отменить вердикт внутри чистки | Нет: запись решения повторно не принимается, кнопки исчезают | Разбан/снятие варна — отдельные действия, не откат всей чистки |
| Проверить исполнение | Вердикт фиксируется до Telegram-действия; при его ошибке записанное решение сохраняется | Не обещать гарантированное исполнение или автоматический откат. UI сообщает о записи вердикта |

**Что сравниваем с Ирисом:** I-CLEAN описывает как массовое удаление, так и предварительные списки. Поэтому неверно, что админ Ириса «не может посмотреть кандидатов». У нас подтверждён организованный процесс просмотра, действий и завершения в одном интерфейсе. Превосходство в числе касаний требует одинакового теста на обоих ботах.

**Рекламный смысл:** «Бот подготовит список. Кого оставить, предупредить или исключить — решаете вы».

## 3. Несколько чатов: единое место работы, не массовое действие

**Цепочка:** `loadAdmin` → `/admin/my-chats` (`admin.py:110`) → список доступных групп → `renderAdminChatSel` / `onAdminChatChange` (`app.07.js:30–43`). Каждый endpoint адресует один `chat_id`.

- Видны действующие группы, где есть запись членства и соответствующий локальный ранг. Роль администратора в Telegram не должна обещаться как автоматический доступ без регистрации роли Предвестника.
- При переключении меняются участники, настройки, журнал и чистка выбранной группы.
- Не нужно строить сетку между независимыми чатами, чтобы выбрать их из персонального списка.
- Одновременный бан/чистка/изменение настроек всех выбранных чатов не реализованы в этой панели.

I-NET подтверждает, что соперник умеет связывать чаты и выполнять сеточные операции. **У нас преимущество-кандидат в персональном визуальном переключении**, у Ириса — документированный охват массовых сеточных действий. Это разные удобства.

**Сюжет:** админ работает в трёх разных сообществах: выбирает первое, разбирает нарушение, переключается во второе, открывает чистку. Подпись «Ваши чаты — в одной панели».

## 5. Топы: сравнивать конкретную метрику

`bot/handlers/stats.py:79–106` поддерживает три области: участники текущего чата, все игроки бота, чаты. Периоды: календарный день, текущая неделя, текущий месяц, всё время. Локальный день учитывает пояс чата; общие таблицы используют UTC. Кнопки меняют область/период, есть страницы. Статистика охватывает собранные ботом данные, не все чаты Telegram.

I-STAT и справочник подтверждают рейтинги соперника; факт общего топа не преимущество. Наш конкретный повод для ролика — **сравнение живой активности сообщества по сообщениям**. Оно отличается от отдельных рейтингов по вложенной валюте; это не доказательство, что у Ириса нет иных рейтингов активности.

Кнопочный топ сообщений подтверждён в Telegram. Полноценная единая графическая страница всех таких топов в сайте этим исследованием не подтверждена. Не обещать сайт для каждой команды статистики.

**Сюжет:** партнёрский флуд поднимается в рейтинге активности Предвестника за неделю. Показывать только реальное место и период; не обещать, что установка автоматически поднимет чат.

## 6. Миниигры: визуальный опыт вместо превосходства «над любой игрой»

| Игра | Подтверждённое текущее поведение | Причина предпочесть этот опыт |
|---|---|---|
| Ритм | Три сигнала, комбо, жизни, ускорение; выбор двух плюсов/двух минусов в отдельном режиме; рейтинги разделены | Непрерывная реакция и видимая цена настройки забега |
| Сапёр | Визуальное поле, касания/флаги, безопасный первый ход с соседями, три сложности; рейтинг побед по времени | Логическая задача с непосредственным управлением полем |
| Мафия | Групповая игра через чат и личные кнопки; Mini App читает историю/статистику | Социальная игра уже остаётся чатовой; её нельзя продавать как полностью графическую |

`rhythm-v2.js`, `minesweeper-v2.js` и подключённые API являются текущими, но игровые флаги проверяются сервером. I-GAME описывает полноценные игровые решения соперника, а не только текстовую случайность. Наше различие — поле/анимация/прямое управление и свой темп; оно не доказывает, что текстовая социальная игра хуже для любой аудитории.

Результаты текущих игр связаны с заданиями и достижениями. Питомцы/косметика не меняют исходы этих трёх режимов по их правилам. Серверная проверка не даёт основания обещать отсутствие всех способов накрутки или невозможность автокликера.

**Сюжет:** показать именно управление и смену темпа. Подпись «Играй внутри Telegram — на игровом поле, а не через очередь команд» подходит для Сапёра/Ритма, но не описывает Мафию.

## Проверки и следующий шаг

Независимая read-only проверка подтвердила цепочку чистки, включение интерфейса в bundle, переключение чатов и разрыв срочного варна. Обнаруженное при критике предположение о временном бане было перепроверено: ссылка относилась к муту, поэтому оно не используется как доказательство.

Приложение не изменено, публикаций нет. Перед рекламой подтвердить текущую версию/live-флаги и пройти согласованные сценарии. Для окончательного утверждения превосходства провести один и тот же сценарий на двух тестовых чатах: измерить касания/время, проверить ограничения, подтверждения и итоговое состояние. Сейчас результат — подробное сравнение реализации и документации, а не акт испытания двух live-продуктов.
