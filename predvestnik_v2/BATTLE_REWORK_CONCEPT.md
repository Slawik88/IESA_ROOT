## 0. Решения пользователя (зафиксировано)
- Механика: **вариант А «Руны отряда»**, дожатый по слабым местам (см. §2).
- Противник: **отряд врагов (обычно 3) + иногда босс** (Бездна/ивенты).
- Порядок хода: **игрок первый, враг отвечает** (2 читаемые фазы).
- Ресурс давления: **«Фокус» 🧿, один пул — два способа траты** (переброс руны / гарантированный крит).
- Позиции: **мягкий перехват** — фронт перехватывает удары по тылу с шансом, не жёсткая стена.
- QTE: **только на ультах и критах** — обычные руны без тапа (не кликер).
- Ярость: от нанесённого И полученного урона, полученный — с кривой камбэка (см. §5).
- Телеграф: враг показывает намерения следующего хода ДО выбора порядка рун.

## 1. Разделение сущностей
- **Мирные питомцы** (10 видов) — только экономика: экспедиции, бафы, копилка.
  Боевой слой (hp/stamina/лечение за мору/участие в боях) ПОЛНОСТЬЮ выпиливается.
  В CP дают маленький пассивный «бонус коллекции» (×0.1 от старого pet_cp).
- **Боевые юниты** — новая сущность, вкладка **«Казарма»**. Все боевые режимы
  (Врата, Бездна, Войны, Дуэли, Рейды) — только на юнитах. У юнитов НЕТ
  персистентного HP — каждый бой с полными силами (лечение за мору умирает как механика).

## 2. Ядро боя (движок services/battle3.py, server-authoritative)
- **Отряд до 3 юнитов**, позиции: фронт/фланг/тыл. Собирается в Казарме до боя.
- **Колода** = 3 руны с каждого юнита (⚔️ удар / 🛡 защита / ✨ навык) = до 9 рун.
  Сыгранные уходят в сброс; колода пуста → сброс тасуется обратно. Игрок видит
  счётчик «осталось в колоде». Смерть юнита → его руны изымаются отовсюду.
- **Раунд**: рука 3 случайных руны → игрок выбирает ПОРЯДОК и цели → фаза игрока →
  фаза врага (по телеграфу). Порядок решает: «щит → удар» ≠ «удар → щит».
- **Фокус 🧿**: старт 1, +1 в начале раунда, кап 4. Траты: переброс одной руны
  руки = 1 🧿; гарантированный крит на выбранную руну-атаку = 2 🧿 (без QTE-риска).
- **Криты**: руна-атака имеет шанс крита (15%, DD 20%). Прок → QTE-кольцо:
  perfect ×1.75 / good ×1.4 / miss ×1.0. Форс-крит за 🧿 = ×1.75 без тапа.
  Максимум 1 крит-QTE за раунд (первый прок), чтобы не утомлять.
- **Ярость** (шкала 0–100 на ОТРЯД, у обеих сторон):
  за нанесённый урон +12/удар, за полученный +8/удар с камбэк-кривой:
  HP отряда >50% ×1.0, 25–50% ×1.5, <25% ×2.0. Кап +25 за один удар (нельзя
  «наесться» одним большим ударом). 100 = доступна ульта любого живого юнита
  (выбор игрока), расход 100. Ульта = QTE: perfect ×1.3 / good ×1.0 / miss ×0.6.
  Враг копит так же и телеграфирует свою ульту заранее.
- **Позиции/перехват**: атака по тылу перехватывается фронтом 60% (танк на фронте:
  +15%); по флангу — 30%. Фронт мёртв → перехватывает фланг (35%). Перехват =
  урон уходит перехватчику. Симметрично для обеих сторон, цель выбирается свободно.
- **Телеграф**: в начале раунда сервер заранее роллит намерения врагов
  (иконка над каждым: ⚔️ цель / 🛡 / 💚 / 💥 ульта) — игрок планирует против них.
- **Анти-затяжка**: с 6-го раунда обе стороны получают +10% урона за раунд (кап +60%).

## 3. Стихии (пентагон)
🔥 > ❄️ > ⚡ > 🗿 > 🌑 > 🔥. По слабой +30%, по сильной −20%.
Синергии отряда: 2 юнита одной стихии — пассив стихии (🔥 +8% урон, ❄️ враг −8% урон,
⚡ +10% шанс крита, 🗿 +10% HP, 🌑 +6% вампиризм); 3 разных стихии — «Триада»:
раз в бой бесплатная AoE-комбо-руна (120% средней атаки по всем врагам).

## 4. Ростер 16 юнитов (5 стихий × 3 роли + легендарный)
См. таблицу §4 прежней версии (git) — состав не менялся:
Саламандра-Головня, Вепрь Пепелища, Феникс-Недоросль (🔥), Ледяной Голем,
Снежная Стрига, Олень Инея (❄️), Грозовой Змей, Штормовой Скорпион, Буревестник (⚡),
Кремневый Страж, Обсидиановый Аспид, Корнеплёт (🗿), Пожиратель Снов, Вдоводел,
Плакальщица (🌑), Порождение Бездны (легендарный, меняет стихию под слабость врага).
Редкости: 9 rare / 5 epic / 2 legendary. Статы по роли (rare L1):
ДД 30 atk/10 def/140 hp · Танк 16/22/260 · Саппорт 20/14/180; epic ×1.35, leg ×1.8;
уровень ×(1+0.12×(L−1)), макс L10. CP юнита = atk×4+def×3+hp×0.5.

## 5. Получение и прокачка (закрывает валюту-тупик 💠)
- Призыв в Казарме: **25 💠** → случайный юнит (rare 78% / epic 18% / leg 4%).
  Дубль → осколки юнита (rare 10 / epic 15 / leg 25).
- Прокачка уровня: осколки юнита + 🪙 (таблица в constants).
- Таргет-дроп осколков: босс Бездны 3–5, Врата эт.5–6 — 1–2.
- Стартовый подарок: выбор 1 из 3 rare-юнитов при первом входе в Казарму.
- Компенсация за старых «боевых» питомцев: одноразово 💠 = Σ pet_cp/50 (мин. 25)
  каждому, у кого есть питомцы (маркер schema_migrations).

## 6. Режимы (все переводятся одним релизом)
- **Врата**: этажи 1–6, враги — отряды 2–3 со стихиями по этажу; награды прежние.
- **Бездна**: монстр = отряд, босс = одиночный «босс-формат» (2 действия/раунд,
  AoE каждый 3-й раунд). Открытие клетки: вместо стамины питомца — дневной лимит
  открытий (6 + радар/2). UI боя — полноэкранная арена (редизайн «ужасного»).
- **Войны**: стена = цель без атак, отряд ломает сегмент; лимиты прежние.
- **Дуэли**: сила = Σ CP отряда × rand(0.85–1.15) вместо питомца; усталость питомцев
  из дуэлей убирается.
- **Рейды**: урон боссу = f(Σ atk отряда), без контр-урона питомцу; лимит атак/день.

## 7. CP (новая формула)
уровень×100 + Σ CP юнитов отряда + 0.25×Σ CP юнитов вне отряда
+ 0.1×Σ pet_cp коллекции мирных + сет косметики + реликвии.

## 8. UI
- **Казарма**: вкладка Арены; карточки юнитов (стихия/роль/уровень/осколки),
  сборка отряда drag-lite (тап по слоту), призыв, прокачка.
- **Арена**: полноэкранный оверлей (не тесный модал): враги сверху (карточки
  с HP/стихией/телеграфом), отряд снизу, рука рун по центру, счётчики 🧿/ярости,
  QTE-кольцо на карте, всплывающие цифры урона. CSS-only, уважает no-fx.
- Чат-паритет: «бот казарма» / «бот отряд» / «бот призыв» + диплинки в мини-апп.
