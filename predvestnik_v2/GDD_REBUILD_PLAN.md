# ШАГ 1 — МАТЕМАТИКА ЭКОНОМИКИ И ПРОГРЕССИИ (План на 1.5 года)

## 1.1 Новая кривая уровней

**Формула (утверждена):** `XP_req(L→L+1) = 1000 × 1.2^(L−1)`.
Кумулятив до уровня L: `C(L) = 5000 × (1.2^(L−1) − 1)`.

| Уровень | XP до следующего | Всего XP (кумулятив) |
|---|---|---|
| 1→2 | 1 000 | 0 |
| 5 | 2 074 | 5 368 |
| 10 | 5 160 | 20 799 |
| 15 | 12 839 | 59 196 |
| 20 | 31 948 | 154 740 |
| 25 | 79 497 | 392 484 |
| 30 | 197 814 | 984 068 |
| 35 | 492 224 | 2 456 118 |
| 40 | 1 224 810 | 6 119 048 |
| 50 | 7 583 700 | 37 913 490 |

**Скорость набора XP (после ребаланса, §1.2):** мидкор ≈ 700 XP/день → **L23–24 за год, L25–26 за 1.5 года**. Хардкор с софт-капом ≈ 2 000 XP/день → L29–30 за год. Разрыв хардкор/мидкор ≈ 6 уровней = 600 CP — ощутим, но не «×1000».

**Софт-кап XP за сообщения (новый, анти-флуд):**
- 1–100 сообщений в день: ×1.0 (10 XP)
- 101–250: ×0.5 (5 XP)
- 251+: ×0.2 (2 XP)
Счётчик — по дню чата (`timezone_offset`), хранится в `user_chat_stats.messages_today` (уже есть).

**Награда за уровень (заменяет плоские 500🪙+1💎):** `мора = 200 × L`, `алмазы = 1` (+5💎 бонусом на каждом 5-м уровне). Амортизированный доход от уровней у мидкора ≈ 160🪙/день на первом году — уровневый faucet больше не главный.

### Миграция (честная математика — ВАЖНО)

`account_xp = SUM(user_xp по всем чатам)` (утверждено «берём total_xp»), `account_level = C⁻¹(account_xp)`.

⚠️ **Флаг для решения при внедрении:** «мгновенный скачок уровня» верен только для игроков с total_xp < ~33 000 (старый L≈12). Выше — кривые пересекаются, и номер уровня у ветеранов **упадёт** (пример: 250 000 XP = старый L84 → новый L22). XP не теряется, но цифра в профиле уменьшится. Варианты:
- **(A) Как утверждено** — пересчёт в лоб, в анонсе объяснить «уровни стали дороже, XP сохранён»;
- **(B) Floor-защита** — `new_level = max(recalc, old_max_level_capped_at_25)`, добивка account_xp до C(level): никто не падает, но ветераны получают «бесплатный» XP.
Рекомендация: **(A)** + разовый «Пакет Обновления 2.0» всем (2000🪙, 5💎, 🎟×3) — дешевле для экономики, честнее к формуле. Ретро-выплат наград за «конвертированные» уровни **нет** (иначе всплеск инфляции: ветеран получил бы 84 уровня × награды).

## 1.2 Балансовая карта валют: краны (faucets) и сливы (sinks)

### 🪙 Мора — рабочая валюта (bottleneck: ранний этап, 1–2 мес.)

| Краны (день, мидкор) | Сливы (день, мидкор) |
|---|---|
| Экспедиции ×2–3 ≈ 700 | Корм питомцам ≈ 500–800 |
| Квесты дневные ≈ 800 (+бонус) | **Лечение после Боёв 2.0 ≈ 200–500 (новый)** |
| Уровни (аморт.) ≈ 160 | **Взнос в мини-игры (EV −4…−10%) (новый)** |
| Стрик ≈ 150 | **Листинг-фи аукциона 1% min_bid (новый)** |
| Продажи на аукционе | Комиссия аукциона 5% (есть) + налог казны узла |
| Доход узла клана (в казну) | **Объявление войны 5 000🪙 из казны (новый)** |
| ИТОГО ≈ +2 000–2 500 | ИТОГО ≈ −1 500–2 200 |

Профицит ≈ +300–800/день — накопления на реликвии/аукцион идут неделями, гиперинфляции нет. Старые мини-игры (чистый faucet при удаче + кап 15 000) заменены скилл-играми с **отрицательным** матожиданием (§R7) — мини-игры впервые становятся сливом.

### 💎 Алмазы — премиум-прогрессия (bottleneck: мид-гейм, 3–9 мес.)

Краны: уровни (1/ур + бонусы), квесты (~12💎/нед), ачивки, гача-дропы, обменник (кап 300/день, спред 33%). Мидкор ≈ **8–15💎/день**.
Сливы: алмазная гача 8💎/крутка (главный), слоты питомника, докупка уровней БП, алмазное лакомство.
**Математика долгого хвоста (уже в коде, сохраняем):** Lv10-легендарка = 104 дубля; с pity (hard 35) ожидание ≈ 130–160💎/дубль → **~14 000–17 000💎 за одну Lv10-легендарку** → при 10–15💎/день это 2.5–4 года на одну, ~1.5 года до Lv7–8 (сильный, но не капнутый питомец). Это и есть главный CP-грайнд эндгейма — намеренно.

### 🌑 Тёмная Мора — рисковая валюта (bottleneck: параллельный трек)

Краны: **Врата 2.0 (бой, не пассив): этаж N платит 3+2N 🌑 за победу, 3 входа/день** ≈ 15–40🌑/день у актива; Контрабанда (без изменений); Ритуал (без изменений). Пассивный фарм 4–20🌑/ч **удаляется** — теперь 🌑 зарабатывается руками.
Сливы: реликвии (500–400🌑, есть), теневые темы (100–350🌑, есть), **новое: чёрный рынок расходников за 🌑** (ротация 3 слотов/нед: зелья удачи, ускорители — то, что сейчас гача-эксклюзив).

### 💠 Осколки Бездны — НОВАЯ валюта клановой прогрессии (bottleneck: эндгейм, 6–18 мес.)

Добыча: **только Бездна клана** (сундуки 2–6💠, монстры 3–8💠, босс этажа 15–25💠). Сплит: **70% в казну клана, 30% лично игроку**.
Норма: активный игрок ≈ 40💠/нед (казна+лично), клан из 15 активных ≈ **420💠/нед в казну**.
Сливы: здания клана (казна) — полная отстройка 4 зданий до L10 ≈ **34 500💠 ≈ 80 недель ≈ 1.5 года** (расчёт §1.3); личные 💠 — крафт `summon_token` (25💠, заменяет мёртвый путь через Осколки Души), лечение в Бездне со скидкой.

### Софт-капы (диминушинг для хардкора)
1. XP за сообщения — ступени ×1.0/×0.5/×0.2 (§1.1).
2. Врата 2.0 — 3 входа/день (жёсткий).
3. Бездна — вклад одного игрока в казну учитывается до **90💠/нед** (сверх — всё идёт лично, казну не разгоняет один человек).
4. Мини-игры — существующий `GAMBLE_DAILY_CAP` 15 000🪙 чистого выигрыша остаётся.
5. БП XP-капы — без изменений (уже есть).

## БЛОК R1 — Индекс Силы (⚡ CP) — ✅ ГОТОВО 2026-07-02 (`services/combat_power.py`, кеш users.combat_power, UI-брейкдаун)

**Формула:** `CP = account_level×100 + pet_cp(active) + 0.5×Σ pet_cp(passive) + set_bonus + relic_power×20`
`pet_cp = (atk×4 + def×3 + hp_max×0.5 + stamina_max×0.1) × (1 + 0.08×(lvl−1))` — из существующих `COMBAT_BASE_*`.
Ориентиры: common L1 ≈ 125, legendary L10 ≈ 1 539. Сет-бонус косметики (все 6 слотов надеты): по **минимальной** редкости из надетых — common +60 / rare +120 / epic +200 / legendary +320 / mythic +500.

**Backend:**
- `services/combat_power.py` (новый): `calculate_cp(db, user_id) -> dict` (полный брейкдаун), `refresh_cp(db, user_id)` (пишет кэш `users.combat_power`).
- Инвалидация кэша по событиям: level-up, перемещение/левел питомца, equip/unequip косметики, покупка реликвии — во всех этих местах уже есть единые сервисные функции, добавляем `refresh_cp`.
- `/profile/me` и `/profile/u/{id}` отдают `combat_power` (+брейкдаун для своего). CP публичен.
- Gatekeeper-хелпер: `require_cp(db, user_id, min_cp)` — используют Врата 2.0 и Бездна.

**Frontend:** бейдж ⚡CP в hero-блоке профиля и в чужом профиле; модалка брейкдауна (откуда цифра) по тапу.
**Migration:** batch-скрипт первичного пересчёта CP всем (внутри `migrate_account_levels.py`, вторым шагом).

## БЛОК R2 — Боёвка 2.0 (Hybrid: Stats + QTE) + Врата 2.0

**Архитектура (server-authoritative, анти-чит):**
1. `POST /combat/battle/start` → сервер создаёт `battles`-строку, генерит `qte_seed`, отдаёт state + параметры первого QTE-окна (тип, длительность кольца, размер perfect-окна — зависят от сложности этажа).
2. `POST /combat/battle/{id}/action {stance, tap_offset_ms}` → **сервер сам** определяет grade из `tap_offset_ms` против своего окна (клиент шлёт сырой тайминг, не оценку): perfect ≤120мс → ×1.0, good ≤350мс → ×0.7, miss → ×0.3. Стойки: Атака (урон ×1.0), Блок (входящий ×(1−block_eff): perfect 100% / good 60% / miss 20%), Концентрация (+25% max stamina, пропуск атаки).
3. Урон: `dmg = atk × stance × qte_mult − enemy_def×0.5` (min 1). Стамина: −8% max за ход; при 0 доступна только Концентрация. Контр-ход противника — авто по простому ИИ (атака/блок по паттерну, для стен — только «стоит»).
4. Анти-чит: rate-limit 1 action/1.5 сек; perfect-rate > 95% на 20+ боях → флаг в admin-лог; тайминги вне физически возможного (0мс N раз подряд) → good принудительно.
5. Мёртвые константы `COMBAT_MEDKIT_*` — удалить; лечение после боя: **2🪙/HP** (снижено с 4 — боёв стало много, это регулярный слив).

**Врата 2.0 (замена пассивного дрейна):** солло-лестница этажей 1–6 с CP-гейтом (500/1200/2500/4000/6000/8000). Вход = 1 бой-волна (1–3 монстра подряд на одном HP/стамине питомца). Победа: `3+2N` 🌑 + шанс 20% на 1–3💠 лично. **3 входа/день.** Старый пассивный фарм и «сгорание лута» удаляются (`shadow_gates.py` → рефактор в PvE-лестницу; `SHADOW_GATE_*` константы заменяются `GATES2_*`).

**Frontend:** экран боя — карточки питомца/врага с HP/стамина-барами, 3 кнопки стоек, QTE-кольцо (CSS-анимация scale + серверный тайминг, `Telegram.WebApp.HapticFeedback` на perfect), лог боя. Никакого WebGL — только CSS/DOM (перф-бюджет слабых телефонов).
**Migration:** питомцы с `placement='gates'` на момент деплоя — принудительный collect по старым правилам (начислить накопленное, вернуть на склад) один раз в стартап-скрипте.

## БЛОК R3 — Кланы 2.0 (Государство)

**3.1 Снос Доски + роли.** Endpoints `clans/request/*` удаляются; конверсия `clan_coins`: **10🎖 → 3💠 личных** (скрипт, идемпотентный лог).
