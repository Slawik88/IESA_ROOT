## ✅ Блок 1 — Откат кастылей + правильный фикс конфликтов алиасов

**Проблема:**
Предыдущий фикс конфликта "снять варн" vs "снять" был сделан переименованием:
- `"снять"` → `"вывести"` в marriage.py  
- убрали `"дать"` из economy.py  
- убрали `"дать ранг"` из admin.py  

**Правильное решение (без кастылей):**
Изменить порядок регистрации роутеров в `bot/handlers/__init__.py`.
Роутер с ДЛИННЫМ алиасом должен стоять раньше роутера с коротким.

| Конфликт | Решение |
|---|---|
| `"снять"` (marriage) vs `"снять варн"` (mod) | mod_router поставить ДО marriage_router |
| `"дать"` (economy) vs `"дать ранг"` (admin) | admin_router поставить ДО eco_router |

**Логика:** aiogram проверяет хендлеры по порядку регистрации. Если mod_router идёт первым, `"снять варн @user"` → mod перехватывает (совпадение "снять варн"). Если не совпало — передаёт дальше → marriage перехватывает "снять" как одиночное слово.

**Файлы:**
- `bot/handlers/__init__.py` — изменить порядок в `include_routers()`
- `bot/handlers/marriage.py` — вернуть `"снять"` в алиасы `cmd_family_withdraw`
- `bot/handlers/economy.py` — вернуть `"дать"` в алиасы `cmd_pay`
- `bot/handlers/admin.py` — вернуть `"дать ранг"` в алиасы `cmd_setrank`

## ✅ Блок 13 — Защита от ложных совпадений ("бот X Y" запускает "X")

**Проблема:**
`"бот чистка открыть"` → TextCmd сматчил `"чистка"` и передал `text_args="открыть"` → чистка запустилась.

**Корень:** TextCmd фильтр матчит `alias + " " + ЧТО_УГОДНО`. Слово после алиаса всегда становится аргументом.

**Реализовано: Вариант 2 — Разделитель двоеточие.**
Временный guard из `cmd_purge_start` удалён — больше не нужен.

---

### Варианты полного решения

#### Вариант А — `strict=True` в TextCmd (для команд без аргументов)
Добавить параметр в фильтр:
```python
TextCmd(["баланс", "кошелек"], strict=True)
```
При `strict=True` матчить только точное совпадение (`clean_text == alias`), не `startswith`.
- ✅ Просто, ноль изменений в хендлерах
- ✅ Решает "бот баланс проверить", "бот профиль открыть" и т.д.
- ❌ Не помогает командам с аргументами (чистка принимает даты)

#### Вариант Б — `args_pattern` в TextCmd (для команд с типизированными аргументами)
```python
TextCmd(["чистка"], args_pattern=r"^(\d|$)")
```
TextCmd матчит только если `text_args` пустой ИЛИ соответствует паттерну.
- ✅ Полностью решает проблему на уровне фильтра
- ✅ Документирует допустимый формат аргументов прямо в хендлере
- ❌ Нужно добавить паттерн к каждой команде с аргументами

#### Вариант В — Валидация в теле хендлера (уже применено для чистки)
Каждый хендлер сам проверяет `text_args` на допустимый формат.
- ✅ Не нужно трогать TextCmd
- ✅ Гибко: хендлер знает что ожидает
- ❌ Нужно добавить проверку в каждый хендлер вручную
- ❌ Нет единого места — можно забыть

#### Вариант Г — TextCmd возвращает `matched_alias`
```python
return {"text_args": args, "matched_alias": alias}
```
Хендлеры получают в сигнатуре `matched_alias: str`. Можно диспетчеризировать по нему.
- ✅ Открывает возможность мёрджа связанных хендлеров в один
- ❌ Требует изменения сигнатуры у всех хендлеров

---

### Рекомендация

**Комбо: Вариант А + Вариант В**
1. Добавить `strict=True` в TextCmd → применить к ~15 командам без аргументов (баланс, профиль, зоопарк, пара, ...)
2. Для команд с аргументами (чистка, мут, варн, ...) — добавить input-валидацию в тело, как сделано для чистки

Это минимальные изменения с максимальным покрытием.

**Файлы под изменение:**
