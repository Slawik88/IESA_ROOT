## 🎯 5 ЗАПОВЕДЕЙ — как применяем в коде

1. **Близость** — развод внутри карточки брака; кормёжка в модалке питомца; крафт у инвентаря.
2. **1 клик** — промокод и наказания = модалки, не страницы. Валюты = модалка с описанием.
3. **Иерархия** — `.btn-gold`/`.btn-teal` = primary (залитые); `.btn-ghost` = secondary; `.btn-red` = опасное.
4. **Feedback** — hover/active на всех картах/кнопках (сделано в CSS v4); скелетоны при загрузке; toast после действий.
5. **Empty states** — компонент `.empty-state` с иконкой + заголовком + CTA везде (брак 💔, инвентарь 🎒, дуэли ⚔️, аукцион 🏛).
