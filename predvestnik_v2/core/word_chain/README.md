# Словарь игры в слова

Источник: https://github.com/Harrix/Russian-Nouns
Версия: `6f0ae9f0619cf0401c6935b7cbba1165bf4c7f19`. MIT, Sergienko Anton; полный текст лицензии рядом.
Исходный SHA-256: `661949699919aa968dd0033f7bdd8abbe4db09d161b565f3f0181283fd0d0da7`.

Сохранены 50851 уникальных существительных: строчные русские буквы, длина 2–32,
без пробелов и дефисов. Для игры «ё» приведена к «е».
Словарь поставляется вместе с приложением: игра не обращается к внешним сервисам.

С 27.10.2026 этот список задаёт слова бота, но не ограничивает ответы игрока:
`services/word_chain_lexicon.py` также проверяет точное наличие в словаре
OpenCorpora через уже установленный `pymorphy3`. Принимаются словоформы,
глаголы, прилагательные и словарные слова с дефисом; предсказания анализатора
для неизвестных слов не принимаются. Нормализация Ё/Е общая. Новейшие слова,
отсутствующие в обоих словарях, могут потребовать дополнения словаря.
Бот случайно выбирает ответ: 2/3 выборов из знакомых слов, 1/3 — из полного
списка, с исключением повторов и ответов без возможного продолжения.

Область партии: chat_id плюс id настоящей темы форума. Поле message_thread_id
без is_topic_message бывает у обычных цепочек ответов и не создаёт новую тему.
Общий `bot.chat.framework.topic_of` используется в командах, ответах,
подсказках и подписи кнопок исправления. Регрессия PostgreSQL воспроизводит
«сирень → Наркотик»: старый raw id теряет партию, исправленный путь принимает ход.
Явный ход `бот слово, арбуз` поддерживается наравне с ответом на сообщение игры.

Ответ на сообщение игры обрабатывается до обычных команд без слова «бот»:
«чай», «торт», «письмо» и другие существительные продолжают цепочку, а не вызывают
одноимённое действие. Явные команды («бот слова, стоп», @имя_бота помощь)
сохраняют обычный приоритет. Выключенная игра не превращает ответ в действие.
Проверка всего маршрута: `python tools/test_word_chain_routing.py`;
правила/гонки/повторы: `test_word_chain_ux.py`, `test_word_chain_pg.py`.
