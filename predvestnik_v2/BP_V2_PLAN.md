# 🎉 БП v2 ПОЛНОСТЬЮ ЗАКРЫТ
A (анти-абуз/дневные потолки) · B (конструктор весов, БД-оверрайды) · дев-UI ·

Всё через единый `add_xp`/`services` → паритет бот↔сайт. Без комита (по запросу).

## A. Анти-абуз притока XP  ← выбрано: дневной потолок НА ДЕЙСТВИЕ
- Дневной лимит XP БП с каждого типа действия (настраиваемый в админке).
- Главная дыра: вош-трейд через аукцион ради `auction_sales` XP — закрывается потолком.
- Дефолты (примерные, правятся в конструкторе): gacha 60/д, auction_sales 36/д,
  eggs 40/д, expeditions 48/д, duel_wins 50/д, gamble_wins 24/д, прочее — без лимита.
- Реализация: счётчик `bp_xp_daily(user_id, date, metric, xp_today)`; в `add_xp`
  усекать прибавку до остатка лимита (после применения веса).

## B. XP-конструктор (дев-консоль) ← выбрано: полный, БД-оверрайды
- Таблица `bp_xp_weight_overrides(metric, weight, enabled, daily_cap, label)`.
- `add_xp` читает оверрайды (как награды БП): БД > `BATTLE_PASS_XP_WEIGHTS`.
  `enabled=false` → действие не даёт XP. `daily_cap` → лимит из раздела A.
- Кастомные действия: добавлять метрику (для метрик, у которых есть точка инкремента).
- Дев-UI: список всех действий (вес / cap / вкл-выкл / ярлык), править + добавлять,
  рядом с конструктором наград.

## C. Страница БП у игрока (переработка + фидбек) ← выбраны все + extra
1. **Живая справка «за что сколько XP»** — список действий и их XP (из весов, всегда актуально).
2. **Сочный левел-ап** — анимированный прогресс-бар до след. уровня, «осталось Y XP»,
   вспышка/конфетти при апе.
3. **Превью следующей награды** (Free + VIP) + дорожка наград с прокруткой.
4. **Таймер сезона** — до конца + % пройдено + «успеешь ли домакситься при текущем темпе».
5. **💎 Открыть следующий уровень за алмазы** (по просьбе пользователя) — мгновенный
   +1 уровень за 💎. Цена растёт с уровнем (напр. base × level),抗-абуз: не выше
   `max_level`. ⚠️ ЦЕНУ согласовать (баланс премиум-валюты).
6. **🎁 «Забрать всё»** — клейм всех доступных наград одним тапом (сейчас по одной).
7. **⚡ Weekend XP Boost** (опц.) — +50% XP БП в сб/вс, вовлечение (флаг в конструкторе).
