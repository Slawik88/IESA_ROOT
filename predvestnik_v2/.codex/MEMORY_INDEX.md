# Memory index

Этот файл — короткий индекс проектной памяти. Полные исторические сведения не
загружаются автоматически.

## Topics

- `../BASE_PROMPT.md` — архитектура, ключевые файлы и критические контракты;
  читать только для общей архитектурной задачи.
- `../AUTONOMOUS_MODE.md` — полный автономный цикл; читать перед автономной
  волной, если задача требует этого режима.
- `../AUTONOMOUS_AGENT_POLICY.md` — матрица качества и отказов; читать для
  cross-stack, экономики, миграций и release-задач.
- `../docs/audits/AUTONOMOUS_RELEASE_BACKLOG.md` — текущая очередь; читать,
  когда задача выбирается из автономного backlog.
- `CURRENT_STATE.md` — единственный обязательный handoff текущей работы.

## Правила памяти

- Не переносить в постоянную память полную переписку, логи или большие diffs.
- Сохранять только стабильные решения, активные риски и следующий шаг.
- Закрытые задачи удалять из `CURRENT_STATE.md` и не дублировать в новых записях.
- Если внешний `MEMORY.md` доступен, сначала искать в нём по теме и читать только
  найденный фрагмент, не загружать весь файл.
