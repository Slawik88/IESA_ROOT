## ПЛАН СНИЖЕНИЯ РАСХОДА ТОКЕНОВ

### Причины
1. `app.js` — 1825 строк. Read = ~9k токенов. Мы читаем его целиком когда надо найти строку.
2. `app.css` + `index.html` — ещё ~3k строк в сумме.
3. `CONTEXT_PROMPT.md` / `AUDIT_V3.md` загружаются при каждой сессии через систему памяти.

### Правила работы (применять всегда)
- **Никогда не читать весь app.js** — только `grep -n` нужная функция, потом `Read offset+limit`.
- **Edit без предварительного Read** если уже знаем контекст из grep.
- **Параллельные вызовы** (несколько Bash/Read в одном шаге).
- `CONTEXT_PROMPT.md` сократить до ключевых фактов (сейчас много лишнего текста).
- Для крупных блоков — писать код снаружи AUDIT_V3 сразу в файлы, не в ответе чата.

### Блок-план сокращения (TD-5)
1. Убрать из `CONTEXT_PROMPT.md` секции которые уже описаны в AUDIT_V3 (дубликаты).
2. Переименовать `CONTEXT_PROMPT.md` → `BASE_PROMPT.md` и обрезать до 60 строк.
3. В memory/MEMORY.md убедиться что ссылки актуальны (stale entries тоже кушают).
