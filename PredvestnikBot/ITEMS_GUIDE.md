## 1. Гача — механика молитв

### Баннеры

| Баннер | ×1 | ×10 |
|---|---|---|
| 🎴 Стандартный | 80 🪙 | 700 🪙 |
| ✨ «Одиночный» | 70 🪙 | 650 🪙 |

### Шансы выпадения

| Редкость | Шанс | Цвет |
|---|---|---|
| 📦 Мусор (Junk) | **75%** | Серый |
| ⚔️ Обычный (Common) | **17%** | Зелёный |
| 🌟 Редкий (Rare) | **6%** | Синий |
| ✨ Легендарный (Legendary) | **2%** | Золотой |

> **Пити (Гарант):** каждые **50 круток** гарантирован легендарный предмет вне зависимости от удачи.
> Счётчик пити не сбрасывается между сессиями и сохраняется в базе данных.
>
> Талант **Память пустоты** (Tier 2) снижает порог пити на 1 за каждый уровень таланта (макс. −5 крутки).
> Кристальный предмет **Двойное везение** даёт ×2 скорость накопления пити на 7 дней.

### Как крутить

```
бот гача          — одиночная крутка (80 🪙)
бот гача 10       — ×10 (700 🪙)
бот гача одиночный   — баннер «Одиночный» ×1 (70 🪙)
бот гача одиночный 10 — баннер «Одиночный» ×10 (650 🪙)
```

## 3. Инвентарь — что надеть, что использовать, что продать

### Слоты предметов (поле `slot`)

| Слот | Что означает | Действие |
|---|---|---|
| `weapon` | Оружие | Надевается, даёт ATK/Крит |
| `armor` | Броня | Надевается, даёт DEF/HP |
| `artifact` | Артефакт | Надевается, даёт смешанные бонусы |
| `potion` | Зелье | Используется (`бот использовать`) |
| `consume` | Расходник | Используется мгновенно (XP, Мора) |
| `coupon` | Купон | Используется — применяет эффект |
| `flair` | Флэр | Применяется — отображается в Mini App |
| `None` | Мусор | Только продажа |

### Краткое правило:

```
✅ Надеть можно:  weapon, armor, artifact
✅ Использовать:  potion, consume, coupon
✅ Продать всё:   junk (мусор), potion, consume, coupon, и некоторые legendary
❌ Нельзя продать: lego_* снаряжение (sell=0), flair, frame, theme
❌ Нельзя надеть: junk, potion, consume, coupon, flair
```

## 4. Слоты экипировки и боевые статы

Каждый персонаж имеет **3 слота**. Одновременно можно надеть по одному предмету в каждый:

```
[ Оружие  ] ← weapon   — ATK, Крит-шанс
[ Броня   ] ← armor    — DEF, HP
[ Артефакт] ← artifact — смешанные (ATK, DEF, HP, Крит)
```

> Нельзя надеть два оружия или два артефакта одновременно.

### Боевые параметры

| Параметр | Описание |
|---|---|
| **ATK** | Урон по боссу и в боевых проверках |
| **DEF** | Защита от входящего урона |
| **HP** | Очки здоровья (влияют на боевые события) |
| **Крит-шанс** | Вероятность критического удара (суммируется) |

### Команды экипировки

```
бот инвентарь             — посмотреть весь инвентарь
бот экип [ключ предмета]  — надеть предмет
бот снять [ключ предмета] — снять предмет
бот профиль               — посмотреть профиль с надетой экипировкой
бот продать мусор         — продать все предметы с slot=None
бот продать [ключ]        — продать конкретный предмет
```

## 10. Система боссов

### Параметры босса

| Параметр | Значение |
|---|---|
| Максимальное HP | **500 000 HP** |
| Лимит урона в день (на пользователя) | **50 000 урона** |
| Формула награды в море | `max(5, урон ÷ 20)` |

> При лимите 50 000 урона в день максимальная награда за день: **2 500 🪙**

### Механика атаки

1. Игрок атакует командой `бот босс атака [урон]`
2. Урон считается с учётом **таланта «Боевое мастерство»** (atk_bonus): `урон × (1 + atk_bonus/100)`
3. Мора начисляется сразу после удара
4. По достижении 0 HP босс «умирает» — рассылаются итоговые награды
5. Ежедневно счётчик урона сбрасывается, HP босса восстанавливается

### Команды боссов

```
бот босс                — статус текущего босса (HP, топ-атакующих)
бот босс атака [урон]   — нанести урон боссу
```

### Достижение «boss_damage»

Система достижений отслеживает суммарный урон по боссам. Проверяется после каждого удара.
