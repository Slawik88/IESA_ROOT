# 📋 Система предметов Предвестника — Полное руководство

## 🎯 Обзор

Система предметов включает полный набор игровых предметов от обычных расходников до легендарных артефактов.

### Категории предметов:

1. **Кристаллы (💎 Crystals)** — валюта для микротранзакций
2. **Осколки (🗡️ Shards)** — материалы для крафта
3. **Оружие (⚔️ Weapons)** — боевое снаряжение (RARE+)
4. **Броня (🛡️ Armor)** — защитное снаряжение (RARE+)
5. **Зелья (🥤 Potions)** — расходники с эффектами
6. **Купоны (🎯 Coupons)** — специальные действия
7. **Рамки (🖼️ Frames)** — декоративные предметы профиля
8. **Коллекционные (📦 Collectibles)** — материалы, артефакты, книги
9. **Лут квестов (🏺 Quest Rewards)** — награды за боевые миссии

## 💎 Кристаллы (`crystals.py`)

Система Telegram Stars → Кристаллы для монетизации.

| Ключ | Название | Раритет | Stars | Crystals | Бонус | Цена |
|------|----------|---------|-------|----------|-------|------|
| `crystal_starter` | Стартовый пак | COMMON | 50 | 100 | 0% | — |
| `crystal_basic` | Базовый пак | COMMON | 150 | 330 | 10% | — |
| `crystal_advanced` | Продвинутый пак | RARE | 500 | 1200 | 20% | — |
| `crystal_premium` | Премиум пак | EPIC | 1000 | 2600 | 30% | — |
| `crystal_ultimate` | Легендарный пак | LEGENDARY | 2500 | 7000 | 40% | — |

### Механика:
```
Бонусные кристаллы вычисляются:
bonus_crystals = base_amount * bonus_pct / 100
total_crystals = base_amount + bonus_crystals
```

## 🎮 Примеры использования в коде

```python
from items import get_item_by_key, get_items_by_category

# Получить конкретный предмет
sword = get_item_by_key("legendary_excalibur")
print(f"{sword.emoji} {sword.name}: +{sword.atk} ATK")

# Получить все оружие
weapons = get_items_by_category("Weapon")
for weapon in weapons:
    print(f"{weapon.emoji} {weapon.name}")

# Получить все предметы определённого раритета
from items.registry import ItemRarity
all_items = list_all_items()
rare_items = [item for item in all_items if item.rarity == ItemRarity.RARE]
```
