### Проблемы
- **14 вкладок** — переполнение таббара на мобиле (требует горизонтального скролла).
- Три финансовые вкладки (Банк + Биржа + Долги) разобщены.
- "Шпион" — единственное действие, не заслуживает отдельной вкладки.
- "Парный Босс" и "Узы" — оба про пару, стоит объединить.
- Нет явной вкладки "Профиль" — профиль загружается в preload-зону над табами (не очевидно).
- Магазин слишком тяжёлый: содержит и разовые покупки (VIP), и расходники (зелья), и чат-баффы.

## 2. Предлагаемая структура — 8 вкладок

```
[📊 Стат] [🎒 Рюкзак] [🛒 Магаз.] [💰 Деньги] [📋 Задачи] [🤝 Семья] [🎮 Игры] [🛠 Дев]
```

| Новая вкладка | ID | Что входит | Убирается из |
|---|---|---|---|
| 📊 Статистика | stat | Профиль + Лидерборд (топ) + Календарь (чекин) | calendar, glory |
| 🎒 Рюкзак | bag | Инвентарь + Использовать зелья + Экспедиции питомца | inventory, expedition |
| 🛒 Магазин | shop | Гача + Рамки / Косметика + VIP + Еда питомца + XP-баф | shop (упростить) |
| 💰 Деньги | finance | Баланс + Банк + Биржа облигаций + Переводы + Займы + Казна | bank, bonds, transfers |
| 📋 Задачи | activity | Квесты + Шпион | quest, spy |
| 🤝 Семья | family | Узы (брак) + Парный Босс + Подарок партнёру | union, couple_boss |
| 🎮 Игры | games | Казино (монетка + лотерея) + Соло-босс + Будущие мини-игры | casino |
| 🛠 Дев | dev | Без изменений | dev |

**Итого: 14 → 8 вкладок.** Таббар помещается в одну строку на экране 360px+.

## 3. Детальный план по новым вкладкам

### Tab `📊 Статистика`
- **Верх:** карточка профиля (имя, уровень, XP, Мора, ранг, рамка, питомец).
- **Секция чекина** (перенести из calendar целиком).
- **Лидерборд** (перенести из glory): selector (XP / Мора / Сообщ.) + список.
- Маленькая ссылка на публичный профиль.

### Tab `🎒 Рюкзак`
- Список предметов по категориям (расходники, инвентарь, хлам).
- Кнопки "Продать хлам" / "Использовать зелье" прямо в карточке.
- Секция питомца: статус, усталость, кнопки "Прогулка" / "Покормить".
- Секция экспедиций: активная экспедиция + «Отправить» / «Вернуть» + статус буста.

### Tab `🛒 Магазин`
- Убрать зелья → они в "Рюкзаке" после покупки.
- Убрать еду питомца → в "Рюкзаке" / "Магазине Питомца" внутри Рюкзака.
- Добавить: **Chat XP Buff** (уже реализован в Block 8).
- Упростить навигацию: аккордеон или табы внутри карточек (Гача / VIP / Косметика / Баф).

### Tab `💰 Деньги`
- **Строка баланса** (личный + семейный кошелёк).
- Банк: депозит, вывод, APY.
- Биржа облигаций: таблица позиций, купить/продать.
- Переводы: пикер пользователя + сумма + комментарий.
- Займы: активные займы, создать, погасить.
- История кошелька (последние 30 операций).

### Tab `📋 Задачи`
- Ежедневные квесты с прогресс-баром.
- Кнопка "Перереролл" (если доступна).
- Мини-секция "🕵️ Шпионаж" внизу: пикер пользователя + кнопка.

### Tab `🤝 Семья`
- Статус брака: профиль партнёра или предложение.
- Семейный кошелёк (баланс + пополнить / снять).
- Парный Босс: статус + начать / атаковать.
- История предложений.

### Tab `🎮 Игры`
- Казино: монетка (ставка + бросить), лотерея.
- Соло-босс: статус + начать / атаковать.
- Будущие мини-игры (placeholder секция).

## 4. Улучшения адаптива (общие)

### Таббар
```css
/* Текущее: обычный flex с overflow */
/* Проблема: при 14 вкладках таббар не помещается */

/* Рекомендация: */
.tabs-bar {
  overflow-x: auto;
  -webkit-overflow-scrolling: touch;
  scrollbar-width: none;       /* Firefox */
  scroll-snap-type: x mandatory;
  white-space: nowrap;
}
.tabs-bar::-webkit-scrollbar { display: none; }
.tab-btn { scroll-snap-align: start; flex-shrink: 0; }
```
После сокращения до 8 вкладок таббар помещается в 360px без скролла.

### Карточки на мобиле
- Убрать `padding: 16px` → `padding: 12px` на ≤ 400px.
- `.card-title` — уменьшить до `14px` на мобиле.
- Таблицы — `overflow-x: auto` с горизонтальным скроллом (уже реализовано в dev-панели).

### Кнопки
- Минимальный tap-target `44×44px` (WCAG 2.1).
- Сгруппировать кнопки в пары `display:grid;grid-template-columns:1fr 1fr` вместо flex-row.

### Шрифты
- На ≤ 380px уменьшить base `font-size` до `13px`.
- Modal-диалоги: `max-height: 80vh; overflow-y: auto`.

## 6. Примечания разработчику

- Каждое перемещение вкладки = перенос HTML-секции + обновление `switchTab()` + возможный `loadXxx()` вызов.
- Не удалять старые `tab-content` div'ы сразу — переименовать ID и перестроить поэтапно.
- JS-инициализация каждой вкладки вызывает `loadXxx()` только при первом открытии (lazy load) — паттерн уже есть, сохранить.
- `chatId` и `uid` глобальные переменные — не изменятся при реструктуризации.
- Логика прав доступа (к dev-панели, к модерации) уже работает через `profileData.role` — сохранить показы/скрытия при tab switch.
