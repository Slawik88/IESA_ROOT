# Аватарка Домового

Знак объединяет дом и учётный журнал. Крыша даёт контекст дома, парные строки —
операции, знаки +/− — поступления и расходы. Валютный символ не привязан к знаку.

- `avatar.svg` — оригинал без шрифтов, внешних изображений, теней и фильтров.
- `avatar-1024.png` и `avatar-512.png` — квадратные копии для загрузки.
- Весь смысловой знак остаётся внутри круглого кадрирования с запасом.

Тёмный фон включён в изображение, чтобы знак одинаково читался в светлом и тёмном
списке чатов. Тот же знак используется в шапке сайта. Профиль бота автоматически
не меняется: файлы подготовлены для установки владельцем.
