Сделано (bot v1, без веб-части):

- роли и гранулы прав (владелец + выдача прав), скрытый супер-доступ `/dev_*`;
- график «свой день недели»: версии, перераскладка будущих дней, «Убрался»
  (в т.ч. за просроченный день с фактической датой), отмена дня, история месяца;
- Баланс Квартиры: взносы произвольной суммой с подтверждением владельцем,

  категории (дефолт + свои), баланс и помесячная история;
- напоминания: утро в день уборки, вечер пока день не закрыт, месячный отчёт —
  идемпотентно (scheduler_log), время и каналы (личка/чат/выкл) настраиваются;
- настройки дома из реестра: подтверждение взносов, часы напоминаний, повтор

Ещё не сделано (см. §11): веб-часть (мини-приложение), распознавание чеков AI,
шаблоны графика 2–3 (очередь, несколько человек в день), экспорт.

## 1. Видение

Платформа домашних хозяйств: **один бот + одно веб-приложение**, внутри которых
каждый **Дом** — изолированное пространство со своими людьми, графиком уборки,
балансом и настройками.

- Сейчас пользуется одна семья (3 человека), но продукт рассчитан на любое
  количество независимых домов («квартира», «общага», «дом»).
- Бот не привязан жёстко к одному чату: подключается к любому чату или личке,
  можно переносить.
- Один человек может состоять в нескольких домах и переключаться между ними.
- Девиз гибкости: почти всё настраивается на уровне дома, а уведомления —
  на уровне каждого человека.

## 2. Ключевые решения (согласовано с владельцем)

| Тема | Решение |
|---|---|
| Платформа | Бот (Telegram) + веб-часть (FastAPI) |
| Мультидоменность | Да: каждый дом изолирован, домов неограниченно |
| Вход в веб | Мини-приложение Telegram (вход по аккаунту, без паролей); доступ с компьютера — кандидат в v2 |
| Взносы | Произвольная сумма каждый месяц, без нормы; фиксирует жилец, **подтверждает владелец** |
| Отметка уборки | Сам жилец; подтверждение владельцем — опциональная настройка дома |
| Пропуск уборки | Пометить в истории + напоминать, пока день не закрыт или владелец не отменит |
| Чеки | Фото (несколько) к трате; бот **сам распознаёт сумму и категорию** (AI), результат — черновик, человек правит вручную |
| Категории трат | Готовый набор из коробки + свои у каждого дома |
| Права | Владелец дома раздаёт права каждому участнику; гибкая настройка процессов дома |
| Уведомления | Персональный центр настроек: каждый включает сам, что и куда получает |
| Супер-доступ | Разработчик имеет скрытые полные права поверх всех домов (публично не афишируется) |

## 3. Роли и права

- **Владелец дома** — создаётся вместе с домом. Раздаёт права, подтверждает
  взносы (если включено подтверждение), может редактировать всё в своём доме.
- **Жилец** — отмечает уборку, заявляет взносы, добавляет траты и чеки.
- **Права (гранулы)** — настраиваются владельцем на каждого участника:
  - управление графиком уборки;
  - подтверждение взносов;
  - редактирование/удаление чужих трат;
  - управление категориями;
  - управление настройками дома;
  - управление участниками (приглашение, права).
- **Разработчик** — служебный супер-доступ поверх всех домов: техподдержка,
  исправление ошибок. В интерфейсах обычных пользователей не светится.

## 4. Уборка

### График
Шаблоны графика (у дома один активный, можно менять):
1. **Свой день недели у каждого** — основной сценарий (пн — Аня, ср — Борис...).
2. **Очередь по кругу** — жильцы убирают по очереди через N дней.
3. **Несколько человек в день** — в заданные дни убирают двое/все.

- График хранится **версиями**: при изменении создаётся новая версия с датой
  начала действия. История и прошлые месяцы всегда показываются по той версии,
  которая действовала тогда.
- Правка графика — в вебе (один экран, drag/select), из бота — только просмотр
  и простые переносы.

### Факты уборки
- Жилец жмёт **«Убрался»** → день закрыт. Можно указать фактическую дату
  («убрался 23-го вместо 22-го») — в истории фиксируется и запланированный день,
  и фактический.
- **Пропуск**: день остаётся непомеченным — бот напоминает (частота настраивается),
  пока жилец не закроет день или владелец не отменит его («перенести/отменить день»).
- Владелец может вручную отметить день за другого (закрыть чужой день) —
  это фиксируется, кто закрыл.

### Просмотр
- «Сегодня»: чей сегодня день + кнопка «Убрался».
- Календарь месяца: отметки сделанного/пропущенного/перенесённого.
- История по жильцу: сколько убрался, сколько пропустил (v1 — статистика).

## 5. Баланс Квартиры

### Взносы
- Никакой фиксированной нормы: жилец заявляет «скинулся X ₽» (за месяц M).
- Владелец **подтверждает** получение → взнос зачтён. Отклонить/поправить можно.
- В подтверждении указывается, как получено (наличные/перевод) — необязательно.

### Траты
- Любой жилец добавляет: сумма, дата, категория, описание + **фото-чеки (1..N)**.
- Два режима траты:
  - **Из котла** — списывается с баланса дома;
  - **За свои** — платил из личных денег; бот показывает, сколько каждому
    скинуться платившему (деление поровну на всех жильцов — уточнить, см. §10).
- Фото чека: бот сжимает/хранит, отправляет в AI-распознавание; распознанные
  сумма/категория/дата/продавец подставляются как **черновик**, человек
  подтверждает или правит. Ошибки распознавания — норма, ручная правка всегда
  доступна и это главный путь.

### Баланс и отчёты
- Текущий баланс котла: сумма подтверждённых взносов − траты из котла.
- По жильцу: сколько внёс за месяц, сколько добавил трат.
- По категориям: на что уходит (месяц/год).
- **Ежемесячный отчёт** 1-го числа: итоги месяца + «пора скидываться» (если включено).
- Экспорт в Excel — v2.

## 6. Уведомления (персональный центр настроек)

События, по умолчанию и настраиваемо каждым участником для себя
(куда: в личку / в чат дома / выключено):

| Событие | По умолчанию |
|---|---|
| Утром в мой день уборки | личка |
| День не закрыт к вечеру — повторять | личка |
| Кто-то отметил уборку / пропустил | в чат дома |
| Добавлена трата (коротко) | в чат дома |
| Я заявил взнос → владельцу на подтверждение | владельцу, личка |
| Мой взнос подтверждён | личка |
| Ежемесячный отчёт по балансу | личка |

Частоты, время напоминаний, тихие часы — настройки дома/человека.

## 7. Интерфейсы: что где

**Бот (aiogram 3)** — быстрые действия и пуши:
/start → выбор дома (или создание), меню: «Сегодня», «Убрался», «Скинулся»,
«Добавить трату» (можно просто прислать фото чека), «Баланс», «Открыть
приложение», «Настройки». Приглашение в дом — ссылкой.

**Веб (FastAPI, мини-приложение Telegram, мобайл-фёрст)** — просмотр и правка:
- Главный экран: сегодня (уборка) + карточка баланса.
- Календарь уборки на месяц.
- Траты: список с фильтрами (месяц/категория/жилец), карточка траты с галереей
  чеков и правкой.
- Взносы: список статусов по жильцам за месяц; подтверждение для владельца.
- Настройки дома: график (редактор), категории, права участников, режимы.
- Настройки уведомлений — персональные.

## 8. Модель данных (черновик)

- `User` — Telegram-аккаунт (tg_id, имя, часовой пояс).
- `House` — дом (название, валюта, настройки, владелец).
- `Membership` — участие: человек × дом, права (гранулы), отображаемое имя,
  статус (активен/покинул).
- `ScheduleVersion` — версия графика дома (тип шаблона, слоты, дата начала
  действия).
- `CleaningDay` — запланированный день (дата, жилец, версия графика) и его факт
  (статус: сделан / сделан с фактической датой / отменён владельцем; кто закрыл).
- `Contribution` — взнос (жилец, сумма, месяц, статус: заявлен → подтверждён/
  отклонён; кто подтвердил).
- `Expense` — трата (сумма, дата, категория, кто платил, режим: из котла / за
  свои, описание, признак «данные распознаны AI»).
- `ReceiptPhoto` — фото чека (файл, статус распознавания, распознанные данные).
- `Category` — категория трат (дом, название, порядок; сидится дефолтным набором).
- `NotificationSetting` — человек × дом × тип события → канал/выключено.
- `HouseSettings` — подтверждение взносов (вкл по умолчанию), напоминать пока не
  закрыто, время утреннего напоминания, валюта, старт недели.

## 9. Технологии и структура

- Python 3.11+, **aiogram 3** (бот), **FastAPI** (веб), **PostgreSQL**.
- Отдельный проект: `domovoy/` в корне IESA_ROOT, рядом с `predvestnik_v2/`.
  Тот же сервер, свой процесс и своя БД — ничего общего с Предвестником, кроме
  машины и подходов.
- Слои как в Предвестнике (CLEAN_CODE.md): `core/` (константы, реестры) →
  `services/` (логика) → `infrastructure/` (SQL) → `bot/`, `web/` (тонкие
  адаптеры). Зависимости направлены внутрь.
- Фото чеков: файлы на диске сервера + сжатие при загрузке.
- Распознавание чеков: AI vision через провайдера, используемого в проектах
  IESA (конкретного провайдера выбрать на этапе v1).
- Конфиги/секреты: `.env` по образцу существующих проектов.

## 10. Открытые вопросы

1. **Имя бота** — «Домовой» рабочее; финал при создании токена (@-адрес проверить
   в BotFather).
2. **Деление траты «за свои»** — поровну на всех жильцов? А если в доме есть
   «наблюдатели», которые не участвуют в деньгах?
3. **Общаги** — нужны ли шаблоны под «общежитие» (много людей, короткие циклы)
   или сейчас хватит «квартирных» сценариев?
4. **Наблюдатели** — бывают ли в доме люди «только смотреть» (например, дети)?
5. **Валюта** — рубль по умолчанию; нужна ли сменная валюта на дом (считаю:
   да, поле в настройках, символ настраиваемый)?
6. Хранение чеков: сколько хранить, лимит фото на трату (предлагаю до 10,
   сжатие до ~1600px по длинной стороне).

## 11. Дорожная карта

- **MVP** — можно пользоваться каждый день:
  дом + приглашения; график «свой день недели»; отметка «убрался» (в т.ч.
  фактической датой), пропуски с напоминаниями; взносы с подтверждением
  владельцем; траты с фото-чеками (без распознавания); базовые уведомления;
  веб: сегодня, календарь, список трат, подтверждение взносов.
- **v1** — распознавание чеков; гибкие права; центр уведомлений; отчёты и
  статистика; редактор графика в вебе.
- **v2** — шаблоны графика 2–3; режимы «за свои с возвратом» в полный рост;
  экспорт; доступ с компьютера; мульти-дома со свитчером в полный вид.
