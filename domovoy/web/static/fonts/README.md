# Onest

Локальная переменная гарнитура с кириллицей.
Источник: [Google Fonts](https://github.com/google/fonts/tree/main/ofl/onest).
Лицензия SIL OFL 1.1 приведена в `OFL.txt`.

`onest.woff2` — подмножество оригинала для сайта: начертания 400–700 (`fontTools.varLib.instancer`),
символы латиницы (включая французские и немецкие), кириллицы (включая украинские), валют, типографики
и стрелок (`fontTools.subset`, функции `kern`, `liga`, `calt`, `tnum`, `lnum`, `case`, `ccmp`, `locl`).
Размер 32 КБ вместо 189 КБ. Нужен другой символ — собрать подмножество заново из оригинала, не правя файл руками.
Браузер загружает шрифт с закрытого маршрута без сторонних запросов.
