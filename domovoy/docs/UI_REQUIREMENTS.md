# Домовой — стандарт интерфейса и чек-лист приёмки

Документ задаёт, **каким должен быть интерфейс Домового**, и как это проверить. Он нужен, чтобы
не возвращаться к правкам «по кругу»: любое изменение сайта (и бота) перед коммитом проходит этот
список. Нарушенный пункт — дефект, а не «вкусовщина».

Метки способа проверки:

- **[A]** — автоматически: `python tools/ui_check.py` (стенд + Playwright, см. раздел 15);
- **[T]** — тест pytest / Node (`python -m pytest tests -q`);
- **[V]** — глазами по сценарию из раздела 15 (скриншоты на нужных размерах);
- **[R]** — ревью кода.

Найденные дефекты и состояние работ — в [`AUDIT_2026-11-03_UI.md`](AUDIT_2026-11-03_UI.md).
Инструменты проверки — `tools/demo_server.py` и `tools/ui_check.py` (раздел 15).

## 0. Принципы (если пункт ниже спорный — решай по ним)

1. **Один экран — одна задача.** Главная отвечает «что с деньгами и что мне сделать сейчас»;
   История — «найти и разобрать запись»; Дом — «настроить». Остальное не лезет на экран.
2. **Частое — под большим пальцем, редкое — спрятано, но найдено.** Расход, взнос, «Готово» — не глубже
   одного касания от Главной. Файлы, права, валюта — в «Дом»/«История», но с понятной подписью.
3. **Читается без усилий.** Нет текста мельче 13 px, нет серого на сером, суммы крупные и выровнены.
4. **Прощает ошибки.** Опасное — только через понятное подтверждение; ввод не теряется; ошибка говорит,
   что делать дальше.
5. **Отвечает сразу.** Любое касание даёт видимый отклик за 100 мс; ожидание всегда показано.
6. **Как родное в Telegram.** Цвета шапки, кнопка «Назад», безопасные зоны, вибро-отклик, закрытие
   с подтверждением — настроены; ничего «браузерного» (системные confirm/alert, английские подписи).
7. **Один компонент — один вид.** Кнопка, поле, строка списка, лист, переключатель выглядят и ведут себя
   одинаково везде. Новый экран собирается из готовых компонентов, а не рисуется заново.
8. **Деньги не врут.** Сумма, знак, валюта, статус записи читаются однозначно; формат — по языку.

- 1.31 Убрать жильца из дома — 3 касания и подтверждение. [V][T]
- 1.32 Вернуть день уборки из «Убрано»/«Пропущено» в ожидание, переименовать категорию, удалить фото чека. [A][T]

## 2. Информационная архитектура и навигация

- 2.1 Три раздела: Главная, История, Дом. Подписи не меняются, текущий отмечен `aria-current`. [A]
- 2.2 Название дома всегда видно (Главная — заголовок; остальные экраны — над заголовком). Нет кнопки,
  которая на разных экранах называется по-разному. [A][V]
- 2.3 Переключение дома — отдельная кнопка с иконкой и именем для скринридера, открывает лист со списком. [A]
- 2.4 Язык переключается из шапки и из экрана входа; список показывает названия языков на них самих. [V]
- 2.5 «Назад»: кнопка Telegram и стрелка на экране ведут одинаково — лист → подэкран «Дома» → Главная. [A]
- 2.6 Глубина навигации не больше 2 (Дом → подэкран). Листы не открываются из листов, кроме подтверждений. [R]
- 2.7 После выхода из подэкрана и при переключении раздела прокрутка возвращается вверх, фокус ставится
  на заголовок. [A]
- 2.8 Текущий раздел и подэкран восстанавливаются после смены языка. [A]
- 2.9 Один и тот же термин везде называется одинаково (см. словарь, раздел 8.6). [R]
- 2.10 Выбранный дом запоминается между открытиями (последний использованный), а не всегда первый. [A]

## 3. Экраны: что где находится

### 3.1 Шапка и оболочка
- 3.1.1 Шапка: слева знак и название приложения; справа язык и смена дома. Высота ≤ 64 px. [V]
- 3.1.2 Шапка не показывает обрезанное название дома. [A]
- 3.1.3 Нижняя навигация закреплена, не перекрывает контент (нижний отступ страницы ≥ высоте навигации
  + безопасная зона + 16 px). [A]
- 3.1.4 Баннер «нет сети» закреплён под шапкой, не сдвигает вёрстку скачком и снимается сам. [V]
- 3.1.5 На широком экране навигация переезжает в шапку, нижней панели нет. [A]

### 3.2 Главная
- 3.2.1 Порядок сверху вниз: дата и название дома → баланс → быстрые действия → «Нужно подтвердить»
  (если есть) → уборка → последние записи. [V]
- 3.2.2 Баланс: подпись, крупная сумма и валюта рядом на одной строке, ниже «Внесено» и «Потрачено». [V]
- 3.2.3 Отрицательный баланс выделен цветом и пояснён; нулевой выглядит нормально. [V]
- 3.2.4 Подпись суммы объясняется по кнопке «i» (иконка, имя для скринридера). [A]
- 3.2.5 Быстрые действия: Расход (главное), Взнос, История; иконки передают смысл. [V]
- 3.2.6 «Уборка»: сегодняшний день важнее просроченных; просрочки считаются и разворачиваются; кнопка
  «Готово» всегда справа и одного вида. [V]
- 3.2.7 Если у меня нет дней — показано, кто убирает сегодня или ближайший день дома. [V]
- 3.2.8 «Нужно подтвердить» видно сразу, без раскрытия: имя, месяц, сумма, «Принять»/«Отклонить». [V]
- 3.2.9 Черновик (незаконченная запись) показан отдельной карточкой с «Продолжить» и «Удалить». [V]
- 3.2.10 Последние записи — 5 штук; пустое состояние предлагает действие. [V]
- 3.2.11 Тап по записи открывает карточку записи, а не раскрывает строку в списке. [A]
- 3.2.12 Если есть личные траты без возврата, под быстрыми действиями — строка «Дом должен жильцам: сумма» с пояснением
  «Из них вам: …»; нажатие открывает историю с фильтром «Ждут возврата». [A]

### 3.3 История
- 3.3.1 Верх: заголовок и две кнопки с подписями — «Файлы» и «Расход» (иконка без слова не считается подсказкой). [V]
- 3.3.2 Месяц меняется стрелками и выбором из листа-календаря месяцев; рядом «Весь период». [A]
- 3.3.3 Быстрый тип (Все / Расходы / Взносы) и быстрые фильтры (Мои, Ждут возврата) — одной строкой чипов. [A]
- 3.3.4 «Фильтры» — лист с остальным (кто, категория, источник, порядок); на кнопке виден счётчик. [A]
- 3.3.5 Итоги выбранного — одна строка под чипами; «Подробнее» открывает разбор по категориям и жильцам. [V]
- 3.3.6 Список сгруппирован по дням: «Сегодня», «Вчера», дата. Заголовки дня закреплены при прокрутке. [V]
- 3.3.7 Продолжение списка — кнопка «Показать ещё», а не «← 1/2 →». [A]
- 3.3.8 Пустой дом и пустая выборка — разные тексты; у выборки есть «Сбросить фильтры». [A]
- 3.3.9 Первая запись видна на телефоне без прокрутки (шапка списка ≤ 280 px). [A]

### 3.4 Дом
- 3.4.1 Верх: карточка «Вы» (имя, роль) и название дома. [V]
- 3.4.2 Пункты: Жильцы, График уборки, Деньги и категории, Скачать и загрузить записи, Уведомления, Настройки дома — с иконкой,
  названием и одной строкой пояснения (не «Правила, время и мой профиль»). Отдельной группой ниже — «Управление домом». [V]
- 3.4.3 Внизу: «Другой дом / создать или вступить», «Обновить данные». [V]
- 3.4.4 Каждый подэкран: стрелка «назад», заголовок, содержимое группами. [V]
- 3.4.5 **Жильцы:** список с аватарами и ролями; «Пригласить» — кнопка «Поделиться» (Telegram) и
  «Скопировать»; права — лист с переключателями и пояснением у каждого. [V]
- 3.4.6 **График:** на каждого жильца — семь кнопок дней (Пн–Вс) в один ряд; «Сохранить график» появляется
  при изменении; ниже история месяца со статусами. [V]
- 3.4.7 **Деньги и категории:** валюта (с подтверждением), список категорий с переименованием и удалением, добавление в строку. [V]
- 3.4.8 **Уведомления:** для каждого события три варианта одним касанием; сохраняется само. [V]
- 3.4.9 **Настройки дома:** название, моё имя, переключатели и выборы — сохраняются сами. Выход, передача и удаление дома здесь
  не лежат: они в «Управлении домом» (3.4.11). [V]
- 3.4.10 Нет кнопки «Сохранить» у каждой строки; единственное явное сохранение — график и поля с текстом. [R]
- 3.4.11 **Управление домом.** Жилец: «Выйти из дома». Владелец (выйти не может): «Передать дом» — выбор жильца и подтверждение;
  «Удалить дом» — перечень последствий, «Сначала выгрузить записи» и лист, где кнопка «Удалить дом навсегда» включается только
  после точного набора названия. В списке жильцов у каждого, чьи права можно менять, в листе прав есть «Убрать из дома». [A][V]

### 3.5 Формы и листы
- 3.5.1 Расход: сумма (крупно, валюта рядом), «Из котла / За свои», категории чипами, описание, дата, «Записать». [V]
- 3.5.2 Взнос: сумма, месяц (Этот / Прошлый / Другой), «Внести деньги». [V]
- 3.5.3 «Недавнее» — ряд чипов вверху формы, одно касание подставляет сумму/категорию/источник. [V]
- 3.5.4 Дата видна всегда («Сегодня», «Вчера», «Другая…»), а не спрятана в раскрывающемся блоке. [A]
- 3.5.5 «Записать ещё» и «Записать и добавить чек» — вторичные действия под главной кнопкой. [V]
- 3.5.6 Кнопка сохранения всегда видна над клавиатурой. [V]
- 3.5.7 Ошибка показывается у поля, поле подсвечено и в фокусе. [A]
- 3.5.8 Закрытие формы с введённым — не теряет черновик (в памяти), показано в «Главной». [A]
- 3.5.9 Лист: ручка сверху, заголовок, крестик ≥ 44 px, закрытие по фону/Esc/кнопке «Назад»; на широком экране — окно по центру. [A]
- 3.5.10 Карточка записи: крупная сумма, статус, категория, кто, дата, источник, описание; действия сгруппированы,
  «Удалить» отделена и красная. [V]
- 3.5.11 Подтверждение (confirm) — собственный лист: заголовок-вопрос, пояснение последствий, кнопка с глаголом
  («Удалить», «Выйти»), «Отмена». Системный `window.confirm` не используется. [A][R]
- 3.5.12 Недоступное действие над записью не исчезает молча: рядом коротко сказано, почему (возвращённый расход, подтверждённый
  взнос, чужая запись) и что сделать («сначала отмените возврат»). [A]
- 3.5.13 «Отменить возврат» стоит в карточке возвращённой траты рядом с пояснением; после отмены запись снова можно изменить. [A]
- 3.5.14 Форма правки взноса говорит о последствии для остатка котла, если взнос уже подтверждён. [A]

### 3.6 Файлы
- 3.6.1 Один лист «Записи и файлы»; открывается кнопкой «Файлы» в истории и строкой «Скачать и загрузить записи» в разделе «Дом». [A]
- 3.6.2 Формат выбирается один раз вверху (Excel по умолчанию, CSV, TSV, JSON) и действует и на записи, и на шаблон;
  под выбором — одна строка о том, что это за формат. [A]
- 3.6.3 Главный путь файла — «Отправить в чат с ботом»: файл приходит документом в личный чат; после отправки видно подтверждение
  и кнопка «Открыть чат». На телефонах Telegram (ios/android) скачивания на устройство нет — оно не сохраняет файлы из страницы. [A]
- 3.6.4 На компьютере кроме чата есть «Скачать на устройство»; если файл не появился, подсказка предлагает чат. [A]
- 3.6.5 Загрузка из файла — три нумерованных шага: шаблон → заполнить и сохранить → выбрать файл; технические детали
  (колонки, ID жильцов) убраны в «Как заполнять таблицу». [A][V]
- 3.6.6 После выбора файла видно его имя, итог проверки (новых, дублей, ошибок, изменение котла) и ошибки с номерами строк;
  записи добавляются только по кнопке «Добавить записи». [A]

## 4. Визуальная система

### 4.1 Цвет
- 4.1.1 Все цвета — переменные в одном месте (`:root`), поверхности — 3 уровня, акцент один (фиолетовый). [R]
- 4.1.2 Интерфейс всегда тёмный (решение владельца), `color-scheme: dark`. [R]
- 4.1.3 Контраст основного текста ≥ 7:1, второстепенного ≥ 4.5:1, крупного (≥ 24 px) ≥ 3:1. [A]
- 4.1.4 Границы полей и значки без подписи ≥ 3:1 к фону. [A]
- 4.1.5 Статус никогда не передаётся одним цветом: рядом слово или значок. [V]
- 4.1.6 Зелёный — «пришли деньги», янтарный — «ждёт», красный — «ошибка/удаление», фиолетовый — «главное действие». [V]
- 4.1.7 Белый текст на главной кнопке ≥ 4.5:1. [A]

### 4.2 Типографика (шрифт Onest, локальный)
- 4.2.1 Шкала размеров: 13 · 14 · 16 · 17 · 20 · 26 · крупная сумма 40–56 px. Другие значения не вводятся. [R]
- 4.2.2 **Ни одного текста мельче 13 px**; ввод — 16 px (iOS не приближает экран). [A]
- 4.2.3 Суммы — табличные цифры, выровнены вправо в списках. [R][V]
- 4.2.4 Заголовок — один `h1` на экран, листы — `h2`; уровни не пропускаются. [A]
- 4.2.5 Межстрочный интервал ≥ 1.4 для текста, ≥ 1.2 для крупных чисел. [R]
- 4.2.6 Длинные слова/имена не ломают вёрстку (`overflow-wrap`), числа не переносятся (неразрывный пробел перед валютой). [A]
- 4.2.7 Шрифт — один файл woff2 ≤ 40 КБ, `font-display: swap`, без внешних запросов. [A]

### 4.3 Отступы и форма
- 4.3.1 Шкала отступов 4/8/12/16/20/24/32; поля страницы 20 px (16 px на ширине ≤ 360). [R]
- 4.3.2 Радиусы из шкалы 10/14/20/28 px; у карточек одинаковый радиус. [R]

## 15. Как проверять

**Стенд.** `python tools/demo_server.py` поднимает сайт с демо-данными на `127.0.0.1:8011`, подменяет
`telegram-web-app.js` и подписывает вход. Адрес: `http://127.0.0.1:8011/?u=1001` (владелец),
`?u=1002` (жилец без прав), `?u=1004` (дом без данных), `?u=1005` (нет домов); `&theme=light` и
`&platform=android` меняют среду Telegram (на `ios` и `android` файлы уходят только в чат, на `tdesktop` — ещё и на устройство;
бот в стенде — заглушка, она принимает «отправку в чат»). Нужны `playwright` и Chromium
(`python -m pip install playwright && python -m playwright install chromium`).

**Автопроверка.** `python tools/ui_check.py` — запускает стенд, проходит все экраны на размерах из 5.1,
считает нарушения пунктов с меткой [A], снимает скриншоты в `data/ui-check/` и выходит с ненулевым кодом, если есть нарушения.

**Граничные данные (обязательно есть в демо-доме):**
название дома 32 символа; описание 200 символов; сумма 9 999 999,99; отрицательный баланс; пустой дом;
больше 20 записей (постраничность); категория из 24 символов; имя из 32 символов; просроченные дни уборки;
ожидающий взнос; личная трата, ждущая возврата; возвращённая трата.

**Ручной проход (после автопроверки, 10 минут):** сценарии 1.1–1.22 на 390 px и 1280 px; смена языка на de и
fr (длинные подписи); альбомный телефон; отключение сети в DevTools; вход после часа бездействия.
