## P0 — СЛОМАНО (видит живой пользователь, чинить первым)

### V1. У анонима внутрь поста рендерится ВСЯ страница логина
- **Где:** [post_detail.html:191](blog/templates/blog/post_detail.html#L191) (`hx-get` лайк-кнопки, `hx-trigger="load"`) и [post_detail.html:232](blog/templates/blog/post_detail.html#L232) (комментарии).
- **Что происходит:** оба партиала под `@login_required`. Для анонима Django отвечает 302 → HTMX послушно
  вставляет **страницу логина целиком** (навбар + форма + футер) прямо в тело статьи. Скриншот-репро локально;
  механика не зависит от данных — на проде у разлогиненных то же самое.
- **Фикс:** в декораторе/middleware для запросов с заголовком `HX-Request` отдавать `204` или `HX-Redirect`,
  а лайк/комменты для анонима вообще не грузить триггером `load` (`{% if user.is_authenticated %}` вокруг hx-атрибутов
  + статический счётчик для гостей). Проверить ВСЕ `hx-get` под login_required по сайту (их много: подписка, лайки комментов).

### V2. Карта партнёров не работает: CSP блокирует Leaflet
- **Где:** [security_middleware.py:24-41](IESA_ROOT/security_middleware.py#L24) — в `script-src`/`style-src` нет `unpkg.com`,
  а [partners_map.html](core/templates/core/partners_map.html) грузит Leaflet именно с unpkg.
- **Что происходит:** браузер блокирует leaflet.js/leaflet.css → карта никогда не инициализируется. Заголовок CSP
  одинаковый локально и на проде ⇒ на проде карта тоже мертва.
- **Фикс (лучший):** положить leaflet 1.9.4 в `static/vendor/leaflet/` (никакой CDN-зависимости, как уже сделали с Bootstrap).
  Либо добавить `https://unpkg.com` в CSP. Плюс тайлы OSM уже разрешены в `connect-src` — проверить `img-src` для тайлов.

### V3. Контент скрыт до JS-reveal — без фолбэка
- **Где:** `[data-reveal]{opacity:0}` + IntersectionObserver; 12 шаблонов: index, post_list, event_list, gallery,
  products, benefits, profile, user_calendar, 404 (!), фрагменты списков.
- **Что происходит:** весь контент ниже hero по умолчанию невидим; появляется только когда JS добавит `.revealed`.
  Нет JS (боты, реадер-мод, печать, сбой скрипта выше по файлу) → страница = чёрная пустота. Замер: на главной
  обсервер инициализируется поздно — при быстром скролле видны пустые секции. Reveal на **странице 404** — совсем лишний.
- **Фикс:** прятать только при работающем JS: в `<head>` `document.documentElement.classList.add('js')`,
  CSS — `.js [data-reveal]{opacity:0} [data-reveal].revealed{opacity:1}`. Инициализировать обсервер сразу после DOM,
  не в конце. С 404 reveal убрать.

- **Где:** [_footer.html:5](templates/partials/_footer.html#L5) — `row g-5` (гаттер 3rem) внутри контейнера

### V5. Мобильное бургер-меню накладывается на контент страницы
- **Где:** `#iesa-nav-collapse` ([_navbar.html:47](templates/partials/_navbar.html#L47)); скриншот-репро: пункты
  «How it works»/«Register» читаются ПОВЕРХ hero-заголовка, текст страницы просвечивает сквозь меню.
- **Причина (вероятная):** stacking — элементы hero с высоким z-index/transform рисуются над фоном коллапса
  (у homepage.css есть свои z-index 9999/10000+), фон меню не перекрывает всю высоту выпадения.
- **Фикс:** непрозрачный фон на `.navbar-collapse.show` во всю высоту, ревизия z-index hero-декора (свести к шкале `--z-*`),
  проверить на длинных пунктах и во всех языках.

### V6. Пустые карточки: «дыры» вместо текста (подтверждено на проде)
- **Команда на главной:** `mc-pos` (должность) пуст на **iesasport.ch** в EN и RU — карточки «имя + More» с дырой.
- **События/посты/бенефиты:** `title_en/uk/fr/de` у Post/Event часто не заполнены → на этих локалях карточки без
  заголовков и описаний (тела карточек пустые, «Learn more» под пустотой). Президент — красный круг с буквой
  (фото `president_face_photo.jpg` лежит в корне репо и не используется).
- **Фикс (3 слоя):**
  1) `MODELTRANSLATION_FALLBACK_LANGUAGES` в settings — незаполненный язык падает на заполненный;
  2) в шаблонах прятать пустые строки: `{% if member.position %}<div class="mc-pos">…{% endif %}` (везде: mc-pos, mc-desc, ev-desc, b-desc);
  3) заполнить данные в админке (должности команды, фото президента).

### V7. «PARTNERS HIPS» — заголовок секции рвётся посреди слова
- **Где:** `.hp-label` ([index.html:15](core/templates/core/index.html#L15)); «PARTNERSHIPS» с letter-spacing

- **Фикс:** `white-space:nowrap` на `.hp-label` (декор-линии ::before/::after не мешают) + проверить на 390px.

### V8. Нулевые прогресс-бары + выдуманные цифры доната
- **Где:** донат-блок главной ([index.html:964](core/templates/core/index.html#L964)): «CHF 4,500 / 10,000» и «142 donors»

  Кэпасити-бары в списке событий — так же.
- **Фикс:** ширину заполнения рендерить сервером (`style="width:{{ pct }}%"`), JS оставить только для анимации.
  Фейковые «142 donors» убрать или заменить честным текстом — это репутационный риск.

### V9. Профиль: ~840px пустоты перед футером

### V10. Баннер «Sign in or register» на блоге/событиях: невидимые кнопки

### V11. Мёртвый файл с контраст-фиксами — подключить или удалить
